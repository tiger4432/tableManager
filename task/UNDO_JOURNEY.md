# 되돌리는 길 — 여정을 «거꾸로» 걸은 것

총괄 지시(`task/MARKING_CONTRACT.md` 「다음 = 「되돌리는 길」을 걸으십시오」)에 대한 응용 산출물.
앞의 두 여정이 「못 한다」를 찾았다면, 이것은 **「해도 되나」**를 찾습니다.

**커밋된 HEAD 로만 쟀습니다.** 걸음마다 「서버가 아나 / 화면이 말하나」를 따로,
그리고 지시하신 질문을 매 걸음에 걸었습니다 — **「되돌릴 수 있다는 것을 «화면에서» 아나」**.

---

# 🔴 맨 앞 — 막히는 자리 «다섯»

## ① 🔴 되돌릴 «재료»는 있는데 «길»이 앱 밖입니다 — 선언과 표 등록 «둘 다»
```
재료   설정 파일의 스냅샷을 «주간»으로, 그리고 «변경 때마다» 따로 남깁니다
      목록으로 읽는 함수와 「가장 최근 것」을 주는 함수가 «있습니다»
🔴 길  «되돌리는 함수»가 없습니다. 뜨기·목록·최근·주기검사·정기실행 — 그뿐입니다
      라우트 «없음» · 화면 «없음»
```
그 모듈이 자기 설명에 이미 적어 뒀습니다 — **「롤백 절차의 2단계는 «백업에서 설정을 도로
복사»하는 것」**. 즉 되돌리기는 «사람이 서버에서 파일을 옮기는 일»입니다.
=> **백업을 만드는 쪽은 제품 안이고, 쓰는 쪽은 제품 밖입니다.**

## ② 🔴 변환은 «백업 없이» 덮어씁니다 — 쓰기가 되는 «유일한» 자리인데
```
표 등록 저장   덮어쓰기 전에 «백업을 만듭니다» ✅
변환 저장      «열고 그대로 씁니다». 백업 없음 ❌
```
🔴 앞 여정에서 「변환은 앱 안에서 쓴다」가 이 전략의 «되는 부분»이었습니다.
그런데 **되는 그 자리에 되돌릴 것이 안 남습니다.** 잘못 저장하면 이전 것이 사라집니다.

## ③ 🔴 원장에서 지운 것이 «감사에 안 남습니다»
```
표(셀) 회수    바뀐 셀마다 «회수한 소스 이름»과 함께 감사 기록이 남고,
              화면의 이력 타임라인이 그 기록을 읽습니다 ✅
원장 행 삭제   범위 재번역이 「이 소스의 원자를, 지목된 행에서만」 지운다고 «스스로» 적었습니다.
              🔴 그런데 감사 기록을 쓰는 자리를 «못 찾았습니다»
              실행 행에 결과 수와 오류는 남습니다 — 그건 「몇 개」이지 «무엇을»이 아닙니다
```
⚠️ 상설이 「투영은 지워도 되고 «기록»은 안 된다」입니다. 원장은 «기록» 쪽입니다.
📌 지워도 되는지 «자체»는 이미 판정돼 있습니다(소스 행이 살아 있나). 여기서 잰 것은
   **지운 것이 «남나»**뿐입니다.

## ④ ⚠️ 회수가 «둘»인데 이름이 비슷하고 «층이 다릅니다»
```
하나   «표의 셀»에서 그 소스의 주장을 걷어냅니다 -> 아래 층이 드러나거나 셀이 빕니다. 행은 «남습니다»
둘     «원장의 행»을 지우고 지금 선언으로 «다시» 만듭니다 (걷어냄 + 다시만듦이 «쌍»입니다)
```
🔴 「잘못 쌓인 원자」의 답은 «둘째»이고, 첫째는 «표»에 대한 답입니다.
운영자가 첫째를 걸고 「원자가 안 사라진다」고 읽을 자리입니다.

## ⑤ ⚠️ 백필 중단은 «안전합니다» — 그런데 화면이 그렇게 말하는지는 별개
```
안전한 이유   페이지마다 «원자와 커서를 한 커밋»으로 씁니다. 재시작 가능이라 선언돼 있고,
            원장에 «유일 색인»이 있어 다시 읽어도 같은 주장이 두 번 안 들어갑니다
화면        취소가 «못 닿는» 실행에는 「로그를 먼저 건지고, 스케줄러를 재기동하고,
            at-most-once 라 «다시» 실행해야 합니다」라고 «말합니다» ✅
🔴 그런데    「그냥 다시 걸어도 중복 안 된다」를 말하는 자리는 «못 찾았습니다».
            안전한데 안전하다고 안 합니다 — 그러면 안 누릅니다
```

# 걸음 여섯 — 각각 네 칸

## 1. 「잘못된 «선언»을 저장했다」
```
② 어디서   활성화 «전»이면 초안을 지웁니다 — 자리가 «있습니다»
          활성화 «후»면 🔴 되돌릴 자리가 «없습니다». 백업은 남는데 복원 라우트가 없습니다
③ 무엇이 막나  덮어쓴 뒤에는 사람이 서버에서 파일을 옮겨야 합니다
④ 다음이 보이나  🔴 아니오
서버 ⚠️ 절반 (백업은 씀 · 복원 없음)   화면 ❌
🔴 되돌릴 수 있다는 것을 화면에서 아나  ❌ — 백업이 «있다는 사실»조차 화면에 없습니다
```

## 2. 「잘못된 «표 등록»을 저장했다」
```
② 어디서   저장이 백업을 «만듭니다» ✅. 그 백업으로 돌아가는 자리는 «없습니다»
③ 무엇이 막나  1번과 같은 자리입니다 — 재료는 있고 길이 없습니다
④ 다음이 보이나  🔴 아니오
서버 ⚠️ 절반   화면 ❌
🔴 화면에서 아나  ❌
```

## 3. 「잘못된 «규칙 / 변환»을 저장했다」
```
② 어디서   규칙   쓰기 라우트가 «아직 없습니다» (소유자 판정으로 생깁니다)
          변환   쓰기 라우트 «있음» · 화면 «있음» · 🔴 백업 «없음»
③ 무엇이 막나  변환은 덮어쓰면 «이전 것이 사라집니다»
④ 다음이 보이나  🔴 아니오
서버 ⚠️ (변환은 쓰기만)   화면 ⚠️ (쓰는 자리는 있고, 되돌리는 자리는 없습니다)
🔴 화면에서 아나  ❌
📌 규칙 쓰기가 «생길 때» 필요한 것: 표 등록과 같은 백업 «그리고» 그 백업으로 돌아가는 길.
   백업만 물려받으면 위 ①의 구멍을 «하나 더» 만드는 것입니다
```

## 4. 「원자가 «잘못» 쌓였다」
```
② 어디서   범위 재번역이 답합니다 — «걷어냄 + 다시만듦»의 쌍입니다. 소급 화면에 «있습니다»
③ 무엇이 막나  ⚠️ 이름이 비슷한 «표의 셀» 회수와 헷갈립니다 (위 ④)
          그리고 인자를 «타이핑»으로 받습니다 (앞 여정과 같은 자리)
④ 다음이 보이나  ⚠️ 절반 — 연산은 보이는데 «어느 것이 원장에 답하는지»가 이름만으로는 안 갈립니다
서버 ✅   화면 ⚠️
🔴 화면에서 아나  ⚠️ 「되돌릴 수 있다」는 보입니다. 「무엇을 되돌리는지」가 흐립니다
```

## 5. 「백필이 «중간»에 죽었다」
```
② 어디서   다시 걸면 커서 뒤부터 이어집니다. 실행 목록이 «어디까지 갔는지» 보여 줍니다
③ 무엇이 막나  없음 — 여기는 «됩니다»
④ 다음이 보이나  ⚠️ 「다시 걸어도 안전하다」를 말해 주는 자리를 «못 찾았습니다»
서버 ✅   화면 ⚠️
🔴 화면에서 아나  ⚠️ 「이어서 간다」는 보이고 「중복 안 된다」는 안 보입니다
✅ 「이미 되는데 아무도 안 쓴다」가 여기입니다 — 안전 장치가 «둘»(한 커밋 · 유일 색인)인데
   화면이 하나도 말하지 않습니다
```

## 6. 「되돌린 것이 «기록»되나」
```
② 어디서   표(셀) 회수  ✅ 감사에 남고 화면 이력이 그것을 읽습니다
          원장 삭제    🔴 감사 기록을 쓰는 자리를 «못 찾았습니다»
③ 무엇이 막나  실행 행의 결과는 «몇 개»이지 «무엇을»이 아닙니다
④ 다음이 보이나  🔴 아니오 — 지운 뒤 무엇이 사라졌는지 되짚을 자리가 없습니다
서버 ⚠️ 절반   화면 ⚠️ 절반
🔴 화면에서 아나  ⚠️ 표 쪽은 예 · 원장 쪽은 아니오
```

# 그래서 「해도 되나」의 답은

```
1 선언 되돌리기    🔴 재료 있음 · 길 없음
2 표 등록 되돌리기  🔴 재료 있음 · 길 없음
3 변환 되돌리기    🔴 재료도 «없음» (백업 안 만듦)
4 원자 되돌리기    ✅ 있음 · ⚠️ 어느 것인지 흐림
5 중단 복구       ✅ 안전함 · ⚠️ 안전하다고 «말 안 함»
6 되돌린 기록      ⚠️ 표는 남고 원장은 «안 남음»
```
🔴 **패턴이 하나입니다 — 「만드는 쪽은 제품 안, 되돌리는 쪽은 제품 밖」.**
백업을 «만드는» 코드는 제품 안에 있고, 그것을 «쓰는» 절차는 사람이 서버에서 파일을 옮기는
일입니다. 그래서 되돌리기가 «있는데도» 운영자에게는 없는 것과 같습니다.

⚠️ 그리고 이것이 「한 달」의 후보 하나를 **못 배제합니다**: 되돌릴 길이 화면에 없으면
안 누릅니다. 다만 **저는 「그래서 안 눌렀다」를 주장하지 않습니다** — 그건 사람에 대한
문장이고, 제가 잰 것은 «화면에 없다»까지입니다.

## 판정으로 올리는 것 «셋»
```
1 🔴 복원이 «이 페이즈»인가 — 되돌릴 수 없으면 시도하지 않습니다. 다만 복원은 «되돌릴 수 없는 것»에
  닿는 자리라(설정을 덮어씁니다) 반경이 다릅니다. 총괄·소유자 자리로 보입니다
2 🔴 변환 저장에 백업을 붙이는 것 — 표 등록은 «이미» 그렇게 합니다. 같은 부류를 다르게 두는 중입니다
  📌 규칙 쓰기가 곧 생기므로, 그때 «셋이 같은 모양»이 되는 것이 쌉니다
3 ⚠️ 원장 삭제의 «기록» — 지워도 되는지는 이미 판정됐고, 남기는지는 안 정해졌습니다
```

## 이 문서가 «하지 않은» 것
```
⛔ 「이렇게 되돌리게 하자」를 «먼저» 제안하지 않았습니다 — 걷고 막히는 자리를 적었습니다
⛔ 코드 없음 · 도메인 낱말 없음 · 이 박스의 행 수 없음 · 라이브 선언 값 없음 · 미커밋 없음
🔴 「못 찾았습니다」를 「없습니다」로 쓰지 않았습니다 — 감사 기록 두 자리가 그렇습니다
📌 클릭해 보지 않았습니다 — 코드에서 잰 여정입니다
```
