# 「0 이 거짓말하는 부류」가 다른 탭에도 있나

보드가 응용에 지목한 물음(`docs/process/PROJECT_STATUS.md`).
판별식도 보드가 줬습니다 — **「한 탭이면 화면 일, 여럿이면 «부품»」**.

```
잰 방법   어드민 화면을 «열어» 탭을 돌았습니다 (127.0.0.1:8080, 2026-09-04 22:4x)
🔴 못 본 것  관리자 토큰이 거부돼 «수»는 못 봤습니다. ⛔ 토큰은 입력하지 않았습니다
          그래서 아래는 «칸과 문장»이고 «값»이 아닙니다
```

---

# 🔴 답 — **«여럿»입니다. 그러니 «부품»입니다**

넷을 찾았습니다. 넷 다 같은 모양입니다 — **어떤 수가 0(또는 «—»)인데, 그 0 이
「할 일 없음」과 「못 읽음/실패로 빠짐」 중 «어느 쪽인지» 옆에 안 적혀 있습니다.**

| 탭 | 그 수 | 0 이 뜻할 수 있는 것 둘 |
|---|---|---|
| Chain | 대기열 | 밀린 게 없다 ↔ 🔴 실패해서 «큐에서 빠졌다» |
| File Ingestion | 진행 중 | 도는 게 없다 ↔ 못 읽었다 (같은 묶음에 「상태 조회 실패」가 붙어 있습니다) |
| Auto Update | 산출물 인제션 실패 | 실패가 없다 ↔ 수집기는 성공인데 «데이터가 안 왔다» |
| Enrichment | 결손 | 채울 게 없다 ↔ 규칙이 «안 돌았다» |

## 🔵 그리고 이 부류를 «이미 알고 있는» 자리가 둘 있습니다
```
Auto Update   패널이 자기 부제에 적어 뒀습니다 — 「수집기 SUCCESS ≠ 데이터 도착」
Chain 대기열   못 읽으면 「조회 실패(HTTP 401). 수를 그리지 않습니다」라고 «말하고 0 을 안 그립니다»
```
🔴 **둘 다 «그 패널이 자기 손으로» 해결했습니다.** 패널마다 자기 문장을 쓰고 있고,
   나머지 둘은 아직 안 썼습니다. 그게 「부품이 아니라 화면 일」로 두면 생기는 모양입니다.

---

# 🔵 그런데 그 부품이 «이미 서버에 있습니다» — 읽는 화면이 «0» 입니다

```
있는 것   소급 연산이 수마다 «부재 어휘»를 값으로 함께 냅니다 (닫힌 목록 여섯)
         아직 · 전수가 아님 · 가리킬 수 없음 · 정말 없음 · 이미 빠져 있음 · 해당 없음
         🔴 그중 둘은 「0 인데 «일감이 있다»」입니다 — 코드가 그렇게 적어 뒀습니다
읽는 곳   소급 화면 «0» · 체인 대기열 패널 «0» · 원장 소스 패널 «0»
=> 「이미 되는데 아무도 안 쓴다」 부류입니다. 부품을 «만드는» 라운드가 아니라 «잇는» 라운드입니다
```
📎 그 여섯 낱말은 제 `task/APPLICATION_RUN_WORDS.md` 가 정본이고, 코드가 그 목록을
   「닫힌 목록」으로 들고 있습니다 — 연산이 «고르기만» 하면 화면이 말하게 되어 있습니다.

---

# 그래서 이 문서의 결론 «둘»

```
① 부류는 «넷»이고 탭이 다릅니다  -> 화면마다 문장을 쓰면 넷째 다섯째가 또 생깁니다
② 부품은 «이미 있습니다»         -> 새로 정의할 것이 없습니다. 값을 «내는 쪽»과 «읽는 쪽»을 잇는 일입니다
```
⛔ 어느 패널을 어떻게 고칠지는 «적지 않았습니다» — 그건 지시서이고 총괄 자리입니다.
⛔ 코드 없음 · 도메인 낱말 없음 · 이 박스의 행 수 없음.
🔴 값을 못 봤다는 것을 그대로 적었습니다 — 위 표는 «칸이 있다»는 말이지 «0 이더라»가 아닙니다.

---

# 🔴 «네 탭 밖»에도 있나 — **있습니다. 그리고 부류가 «셋»으로 늘었습니다** (2026-09-05 12:1x)

총괄 큐 3번. **저는 «찾기»만 합니다** — 고치는 것은 클라 레인입니다.

```
잰 방법   남은 세 탭을 «열었습니다» (개요 · 표 · 온톨로지 탐색기, 12:0x)
         그리고 부재 부품을 «안 쓰는» 파일을 심볼로 골라 그 안의 「없음/없습니다/0개」를 봤습니다
🔴 못 본 것  토큰이 또 거부돼 «수»는 못 봤습니다 — 🔵 그런데 이번엔 그게 «시약»이 됐습니다.
         못 읽는 화면이 무엇을 그리는지가 이 문서가 재려던 것입니다
```

## 🔴 부류가 하나가 아니라 «셋»입니다 — 같은 병의 세 모양

```
① 0 으로 거짓말     못 읽었는데 «0» 을 그립니다              <- 앞 절의 네 탭
② 문장으로 거짓말   못 읽었는데 「없습니다」라고 «말합니다»    <- 오늘 찾은 것
③ 수로 거짓말      «0 이 아닌 수»가 반대를 말합니다          <- 오늘 아침 리플레이 절의 셋째
```
🔴 **②가 ①보다 나쁩니다.** 0 은 「이상한데?」를 부르지만, 「없습니다」는 «질문을 닫습니다».

---

# 찾은 자리 «둘» — 탭 밖

## ⓐ 개요 — 「없음」을 «단언»하는 두 줄
```
화면에서 본 것   재교정률 «—» · 「최근 7일간 사람이 고친 셀 없음」
                교정 공수 «—» · 「최근 7일간 사람이 고친 교정 없음」
같은 화면 옆     「관리자 토큰이 거부되었습니다」가 «세 자리»에 붙어 있었습니다
```
🔴 즉 **못 읽은 화면이 「없음」이라고 말하고 있었습니다.** 그리고 그 문장의 「7일」은 응답이
없을 때 쓰는 «기본값»이라, 안 읽은 창의 길이까지 «지어서» 말합니다.
```
🔵 자리는 «있습니다»   서버가 「왜 못 준다」를 주면 그것을 그립니다 (전용 칸이 있습니다)
🔴 빈 자리의 기본값이  「없음」입니다 — 그게 이 줄의 결함입니다
=> 「없다」와 「못 읽었다」가 «같은 픽셀»입니다
```

## ⓑ 온톨로지 탐색기 — **실패를 «알면서» 0 을 그립니다**
```
화면에서 본 것   「요청 실패 (401)」  ×2
                바로 아래  「선언 · 0개」 · 「표시할 정의가 없습니다」
                오른쪽    「이 정의를 사용하는 곳 · 0」 · 「상위 참조가 없습니다」
```
🔴 이 화면은 실패를 «압니다» — 오류 문구를 자기가 그립니다. 그런데 «수는 그대로 그립니다».
   목록이 비었을 때 갈리는 상태가 «둘»(불러오는 중 / 없음)뿐이고, «못 읽음»이 없습니다.

🔵 **그리고 같은 화면 «아래»에 옳은 것이 있습니다** — 소스 상태 패널:
```
「소스 상태 조회 실패 (HTTP 401). 수를 그리지 않습니다.」  + 값은 «—»
```
🔴 **한 화면 안에서 옳은 것과 틀린 것이 나란히 있습니다.** 그리고 옳은 쪽은 부재 부품을 «씁니다».
   판별이 사람의 주의가 아니라 «어느 부품을 쓰나»로 갈립니다.

---

# ✅ 밖인데 «맞게» 하고 있는 곳 — 세어서 같이 적습니다

```
표 등록 탭      「표 등록 조회 실패 (HTTP 401)」 + «—»                    ✅
개요 · 설정 반영 · 소급   토큰 거부를 «문장으로» 말하고 값은 «―»            ✅
개요 · Running  못 읽은 출처를 «이름 대어» 답니다 (「… unreachable」)       ✅
             ⚠️ 다만 그 수 «자체»가 부류 ③ 입니다 (오늘 아침 절)
```
🔵 부품을 «쓰는» 파일이 지금 여섯입니다. 위의 ✅ 는 전부 그 여섯 안이고,
   ⓐ·ⓑ 는 전부 그 «밖»입니다. 🔴 이게 이 문서의 실질적인 답입니다 —
   **부류가 화면마다 생기는 게 아니라 «부품을 안 쓴 화면»마다 생깁니다.**

---

# 그래서 이 절의 결론

```
① 「네 탭 밖에 있나」   -> 예. «둘» 더 (개요 두 줄 · 탐색기 네 자리)
② 새 부품이 필요한가    -> 아니오. 부품은 있고, 이 둘이 «안 쓰고» 있습니다
③ 앞 절과 달라진 것     -> 부류가 «셋»입니다. ②(문장)와 ③(0 아닌 수)이 새로 나왔습니다
```
⛔ 어느 자리를 어떻게 고칠지는 «적지 않습니다» — 클라 레인 몫입니다.
⛔ UI 설계 없음 · 코드 없음 · 이 박스의 행 수 없음.
🔴 값을 못 봤다는 것을 그대로 적었습니다. 위는 «무엇이 그려졌나»이지 「수가 얼마더라」가 아닙니다.
📌 밖에서 «이미 자기 문제를 적어 둔» 자리가 하나 있습니다 — 데스크톱 빌드 버튼이
   「빌드가 서는 날 이 버튼이 「없습니다」라고 말한다」를 «주석으로» 들고 있습니다.
   새로 찾은 것이 아니라 «이미 알려진» 것이라 위 둘에 안 셌습니다.
