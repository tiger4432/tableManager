# 「0 이 거짓말하는 부류」가 다른 탭에도 있나

보드가 응용에 지목한 물음(`docs/process/PROJECT_STATUS.md`).
판별식도 보드가 줬습니다 — **「한 탭이면 화면 일, 여럿이면 «부품»」**.

```
잰 방법   어드민 화면을 «열어» 탭을 돌았습니다 (127.0.0.1:8080, 2026-09-04 22:4x)
🔴 못 본 것  관리자 토큰이 거부돼 «수»는 못 봤습니다. ⛔ 토큰은 입력하지 않았습니다
          그래서 아래는 «칸과 문장»이고 «값»이 아닙니다
```

---

# 🔴 답 — **«여럿»입니다. 그러니 «부품»입니다**

넷을 찾았습니다. 넷 다 같은 모양입니다 — **어떤 수가 0(또는 «—»)인데, 그 0 이
「할 일 없음」과 「못 읽음/실패로 빠짐」 중 «어느 쪽인지» 옆에 안 적혀 있습니다.**

| 탭 | 그 수 | 0 이 뜻할 수 있는 것 둘 |
|---|---|---|
| Chain | 대기열 | 밀린 게 없다 ↔ 🔴 실패해서 «큐에서 빠졌다» |
| File Ingestion | 진행 중 | 도는 게 없다 ↔ 못 읽었다 (같은 묶음에 「상태 조회 실패」가 붙어 있습니다) |
| Auto Update | 산출물 인제션 실패 | 실패가 없다 ↔ 수집기는 성공인데 «데이터가 안 왔다» |
| Enrichment | 결손 | 채울 게 없다 ↔ 규칙이 «안 돌았다» |

## 🔵 그리고 이 부류를 «이미 알고 있는» 자리가 둘 있습니다
```
Auto Update   패널이 자기 부제에 적어 뒀습니다 — 「수집기 SUCCESS ≠ 데이터 도착」
Chain 대기열   못 읽으면 「조회 실패(HTTP 401). 수를 그리지 않습니다」라고 «말하고 0 을 안 그립니다»
```
🔴 **둘 다 «그 패널이 자기 손으로» 해결했습니다.** 패널마다 자기 문장을 쓰고 있고,
   나머지 둘은 아직 안 썼습니다. 그게 「부품이 아니라 화면 일」로 두면 생기는 모양입니다.

```

         아직 · 전수가 아님 · 가리킬 수 없음 · 정말 없음 · 이미 빠져 있음 · 해당 없음

=> 「이미 되는데 아무도 안 쓴다」 부류입니다. 부품을 «만드는» 라운드가 아니라 «잇는» 라운드입니다
```

   「닫힌 목록」으로 들고 있습니다 — 연산이 «고르기만» 하면 화면이 말하게 되어 있습니다.

# 찾은 자리 «둘» — 탭 밖

## ⓐ 개요 — 「없음」을 «단언»하는 두 줄
```
화면에서 본 것   재교정률 «—» · 「최근 7일간 사람이 고친 셀 없음」
                교정 공수 «—» · 「최근 7일간 사람이 고친 교정 없음」
같은 화면 옆     「관리자 토큰이 거부되었습니다」가 «세 자리»에 붙어 있었습니다
```
🔴 즉 **못 읽은 화면이 「없음」이라고 말하고 있었습니다.** 그리고 그 문장의 「7일」은 응답이
없을 때 쓰는 «기본값»이라, 안 읽은 창의 길이까지 «지어서» 말합니다.
```
🔵 자리는 «있습니다»   서버가 「왜 못 준다」를 주면 그것을 그립니다 (전용 칸이 있습니다)
🔴 빈 자리의 기본값이  「없음」입니다 — 그게 이 줄의 결함입니다
=> 「없다」와 「못 읽었다」가 «같은 픽셀»입니다
```

## ⓑ 온톨로지 탐색기 — **실패를 «알면서» 0 을 그립니다**
```
화면에서 본 것   「요청 실패 (401)」  ×2
                바로 아래  「선언 · 0개」 · 「표시할 정의가 없습니다」
                오른쪽    「이 정의를 사용하는 곳 · 0」 · 「상위 참조가 없습니다」
```
🔴 이 화면은 실패를 «압니다» — 오류 문구를 자기가 그립니다. 그런데 «수는 그대로 그립니다».
   목록이 비었을 때 갈리는 상태가 «둘»(불러오는 중 / 없음)뿐이고, «못 읽음»이 없습니다.

🔵 **그리고 같은 화면 «아래»에 옳은 것이 있습니다** — 소스 상태 패널:
```
「소스 상태 조회 실패 (HTTP 401). 수를 그리지 않습니다.」  + 값은 «—»
```
🔴 **한 화면 안에서 옳은 것과 틀린 것이 나란히 있습니다.**

## 🔴 다섯째의 «판별식» — 한 줄
```
「이 0 을 «채울 수» 있나」
   ✅ 채울 수 있다  ->  ①~④ 중 하나입니다. 「없다」와 「못 읽었다」를 가르면 됩니다

                     그 둘을 안 가르면 운영자가 선언이 «금지한» 것을 채우러 갑니다
```
📎 이 판별식은 앞의 넷과 «묻는 것이 다릅니다» — 앞의 넷은 「이 0 이 어디서 왔나」를 묻고,
   다섯째는 「이 0 이 «채워질 수» 있나」를 묻습니다. 출처가 아니라 «가능성»입니다.
