## 모르는 것

- **빈도 전부.** 같은 칸을 사람과 체인이 «몇 초 안에» 같이 쓰는 일이 운영에서 얼마나 되는지 안 쟀습니다. 위험 1 의 크기는 그 수가 정합니다.
- 운영이 단일 프로세스 모드(`DECOUPLED` 꺼짐)인지 — W7 의 크기가 갈립니다. 코드는 둘 다 됩니다.
- L18 커서 · L20 동시 CREATE 는 판정 못 했습니다.
- 탐색 셈 중 제가 직접 연 것: 위 «직접 엶» 표시 줄, `table_locks.hold` 부르는 곳 둘, 플러시 잠금, 미리 읽기, 게이트, 거두기의 자리, 와처 통지 상한, LLM 재시도 창, 소급 자식의 감시 없음, 표 선언 저장의 `changed()` 없음. 나머지 줄은 함수 이름까지 적힌 탐색 셈입니다.
