# [Task] 작성 화면 — 무엇을 통과라 부를 것인가

> **성격:** 검수 **기준**. 화면이 착지하기 «전에» 못 박는다.
> **왜 미리 쓰나:** 다 된 화면을 보고 기준을 정하면 그 화면이 기준이 된다.
> **원 지시:** 소유자 2026-08-19 「구현자 화면 검수 잘해 불편한점 없게」
> **재는 대상:** [`ontology_setup_friction_observed.md`](ontology_setup_friction_observed.md)의
> 실측 — 2026-08-18 밤 2시간, 저장 20회, **거절 40건, 그중 사람의 판단은 다섯 남짓.**

## 0. 통과 조건은 하나다

**거절 40건 중 «사람이 판단해야 했던 다섯»만 남는다.** 나머지 35건은 화면에서 **일어날 수
없어야** 한다 — 「거절문이 친절해졌다」는 통과가 아니다. 그건 ④(가장 약한 수단)이고
친절한 거절도 왕복이다.

두 숫자로만 채점한다.

| | 어젯밤 | 통과선 |
|---|---|---|
| 거절당한 저장 | 40 | **≤ 5** |
| 사람의 실제 판단 | ~5 | **~5 (줄면 안 된다)** |

두 번째가 중요하다. 판단까지 사라졌으면 화면이 **대신 골라 준** 것이고, 그건 어젯밤
`basis`가 12건을 만든 것과 **같은 기제**다 — 엔진이 말없이 골랐고 그 침묵이 데이터가 됐다.

## 1. 검수 방법 — 코드 리뷰가 아니다

**내가 화면으로 `dt_log`를 처음부터 다시 선언한다.** 어젯밤 소유자가 걸은 그 여정을,
같은 순서로, 빈 상태에서.

읽기만 하는 검수는 「불편한지」를 못 잰다. 불편은 **왕복 횟수**로만 드러난다.

측정 규약:
- 저장 시도 1회 = 1왕복. 거절되면 사유를 그대로 적는다.
- 「어젯밤에도 났던 거절인가 / 새 거절인가」를 나눈다. **새 거절은 회귀다.**
- 각 층(낱말→엔터티→팩→프로필→매퍼→소스)에서 **손으로 친 문자 수**를 센다.
  타이핑이 남아 있는 자리가 다음 오타의 자리다.

## 2. 항목별 — 무엇을 «반증»할 것인가

각 항목은 「있다」가 아니라 **「틀릴 수 없다」**로 잰다. 존재는 확정이 아니다.
그래서 통과 판정마다 **내가 고의로 틀리게 해 본다.**

| 항목 | 수단 | 통과 = 이게 안 돼야 한다 |
|---|---|---|
| §1 `__occurred_at` | ① 구조 | 매퍼가 시각 컬럼 «이름»을 물을 자리 자체가 없다. `source_plan.driver.occurred_at`을 읽는 매퍼가 0개 (grep으로 센다) |
| §2 컬럼 드롭다운 | ③ 제약 | **없는 컬럼 이름을 타이핑해 저장할 수 없다.** 자유 입력이 남아 있으면 실패 — 드롭다운이 «있는» 것과 자유 입력이 «없는» 것은 다르다 |
| §2 값 개수 표시 | ③ 계측 | 값이 0%인 컬럼을 «모르고» 고를 수 없다. 후보 옆 숫자가 라이브 실측인지 확인 — 하드코딩·캐시면 실패 |
| §8 유일성 실측 | ③ 계측 | 유일하지 않은 조합을 business_key로 골랐을 때 백필 «전에» 안다 |
| §3 유도 | ② 유도 | 다른 선언에서 계산되는 칸이 사람에게 안 물린다. **단, 유도값은 근거와 함께 보인다**(§3 아래) |
| §9 전수 보고 | ④ 진단 | 작성 경로에서 문제 3개를 심으면 **3개가 다 나온다**(첫 개에서 안 멈춘다) |

## 3. 🔴 유도한 것은 «값과 근거»를 같이 보인다

②(유도)는 강한 수단이지만 **①과 달리 위험이 있다.** 칸을 없애는 게 아니라 **말없이
채우는** 것이라서다.

어젯밤의 결함이 정확히 이 모양이었다: `basis`가 그룹에서 무엇을 뜻하는지 아무도 안 정했고,
**엔진이 조용히 골랐고**, 그 침묵이 원장에 12건으로 앉았다. 화면이 유도한 값을 근거 없이
보여 주면 **같은 결함을 UI 규모로** 재생산한다.

**규칙: 파생된 칸은 «값»과 «어디서 왔는지»를 같이 렌더한다.** 그리고 사람이 그걸
**덮어쓸 수 있어야** 한다 — 덮어쓸 수 없으면 그건 유도가 아니라 강제이고, 강제라면
파일에서 빼야 한다(①).

## 4. 검수 결과가 나올 형식

라운드마다 이 표만 낸다. 산문 없이.

```
층        왕복  타이핑  새 거절
낱말        n     n자      -
엔터티      n     n자      -
팩          n     n자      -
프로필      n     n자      -
매퍼        n     n자      -
소스        n     n자      -
─────────────────────────
합계        n     n자      n건
```

**합계 왕복 ≤ 5, 새 거절 0이면 통과.** 아니면 그 자리를 §2 표의 수단 등급으로 되돌린다.

## 5. 비범위

- 시각 디자인·색·간격 — `ui-designer` 소관. 여기서 재는 것은 **마찰**이지 미감이 아니다
- 삭제·이름변경 경로 — 판정 5건이 아직 열려 있다(보드 구현자 레인 절)
- 성능 — 왕복이 5회면 1초가 늦어도 어젯밤보다 낫다
