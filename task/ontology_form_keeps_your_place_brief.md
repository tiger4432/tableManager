# 화면이 «내 자리»를 잃지 않는다 — 셋 (소유자 판정 2026-08-21 13:0x)

> 소유자: 「아 이거 맞아 고쳐 **하는 김에 저장버튼 맨 아래 말고 좀 스크롤 어디든 떠있게**
> 그리고 **저장 후 뷰는 현상태 유지**되어 있게
> (**충돌 해소 결과를 바로바로 보면서 셋업하고 싶음**)」

---

## 🔴 도착지 — 소유자가 이유를 같이 말했다. 그것이 합격 기준이다

```
설정을 채워 나가는 «동안»,
   내가 고른 값이 화면에 남고
   저장을 누르러 «자리를 뜨지 않아도» 되고
   누른 «뒤»에도 보던 자리가 그대로여서
→ 거절이 줄어드는 것을 «보면서» 셋업할 수 있다
```
**셋은 따로가 아니라 한 병이다** — 화면이 사람의 자리를 잃는다.
```
① 드롭박스 되돌아감   내 «값»을 잃는다
② 저장 버튼이 맨 아래   저장하려면 «자리를 떠야» 한다
③ 저장 후 뷰 초기화     내 «자리»를 잃는다
```

---

## ① 드롭박스 되돌아감 — 원인은 이미 특정됐다

**구현자 진단 (실측, 진짜 키보드 입력으로 재현):** 반쯤 친 글자를 보호하는 가드가 있는데,
**선택 상자는 고른 뒤에도 포커스가 남아** 그 가드에 걸려 값이 갱신되지 않는다.

**총괄 정량 (재검증 걷기, 2026-08-21 10:5x):**
```
선택 상자 6개 중 «4개»가 첫 시도에 안 먹고 옛 값으로 돌아갔다
글자 칸 2개는 «멀쩡»했다        ← 선택 상자만의 병이라는 증거
```
⚠️ **가드 자체를 없애지 말 것.** 그 가드는 「타이핑 중에 재렌더가 글자를 먹는 것」을 막으려고
있다. **가드가 «선택 상자»에는 안 걸리게 하는 것**이 이 수리다. 글자 칸의 보호는 그대로 남는다.

---

## ② 저장 버튼 — 스크롤 어디서든 닿는다

```
지금    편집 패널 «맨 아래». 트리가 길어지면 저장하러 끝까지 내려가야 한다
목표    스크롤 위치와 무관하게 «항상» 닿는다
```
🔴 **새 영역·새 모드·모달을 만들지 말 것.** 같은 버튼을 «자리만» 바꾼다
(소유자 상설: 「절대 복잡하면 안 됨」). `Delete` 가 옆에 있으면 같이 따라간다 —
둘이 떨어지면 그게 더 나쁘다.

⚠️ 떠 있는 버튼이 **트리의 마지막 행을 가리면 안 된다.** 가리면 그 행을 못 읽는 것이고,
①②③이 고치려는 병과 같은 부류가 된다.

---

## ③ 저장 후 «보던 자리»가 그대로

```
지금    저장하면 뷰가 초기화된다 — 스크롤이 올라가고 보던 자리를 잃는다
목표    저장 «후»에도 스크롤 위치·선택·펼침이 그대로여서
        거절이 줄어드는 것을 «그 자리에서» 본다
```
✅ **펼침 상태는 `879ad8ef` 가 이미 고쳤다.** 이번에 남은 것은 **스크롤 위치와 선택**이다.
그 커밋이 「상대값으로 저장해서 기준이 움직이면 뜻이 바뀐다」를 고친 것과 **같은 계열**이니,
같은 자리에 같은 방식으로 붙는지 먼저 볼 것.

---

## ⛔ 멈춤 조건 — «하나»다

> **저장이 뷰를 초기화하는 이유가 「패널을 통째로 다시 만들기 때문」이면 → 멈추고 보고.**

그건 렌더러 구조 이야기라 다른 라운드다. 위치를 기억했다 복원하는 것으로 되면 그것이 최소 수정이다.

나머지는 진행하면서 재고, 숫자는 나오는 대로 한 줄씩. **「못 쟀다」도 답이다.**

## 🔴 받아들이는 시험 — 소유자의 문장을 그대로 시험으로 만든다

```
1  새 소스를 폼만으로 만들되, «중간에 여러 번» 저장한다
      저장할 때마다 스크롤·선택·펼침이 «그대로»여야 한다
      그리고 거절 수가 줄어드는 것이 «그 자리에서» 보여야 한다
2  긴 트리에서 스크롤을 «중간»에 두고 저장 버튼이 닿는가
      그리고 그 버튼이 마지막 행을 가리지 «않는가»
3  선택 상자 여섯을 «한 번씩만» 골라도 전부 먹는가
      총괄 실측은 6 중 4가 안 먹었다. 이 수가 «0»이어야 한다
4  글자 칸은 여전히 «타이핑 중에 안 먹히는가»  ← 가드가 살아 있다는 확인. 없애면 안 된다
5  거절 0 · active 까지 여전히 간다 · 편 횟수 0 유지
6  기존 라이브 설정 회귀 없음: 거절 0 · missing 0 · 「4 layers · complete」
```
⚠️ **4번을 빼지 말 것.** ①을 「가드를 없애서」 고치면 1·3은 통과하고 **글자 칸이 조용히 망가진다.**
[[a-fixture-both-rules-agree-on-decides-nothing]] — 선택 상자만 보면 두 수리가 같은 답을 낸다.
