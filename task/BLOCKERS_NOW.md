```
             «복원» 이름의 함수도 라우트도 «0»                        -> 막힘 그대로
  Ⅲ-2 감사   원장 쪽 되돌리기가 내는 것을 봅니다 — 걷어낸 수·시도 수·쓴 수.
             «무엇을»이 아니라 «몇 개»입니다. 감사 쓰는 자리는 이번에도 «못 찾았습니다»
             (심볼로 훑었습니다)                                      -> 막힘 그대로
  Ⅲ-3 회수 둘 두 연산의 «선언된 이름»을 봅니다. 둘 다 그대로입니다     -> 막힘 그대로
  Ⅲ-4 재실행 그 값을 쓰는 자리를 셉니다 — «확인창 색» 하나뿐입니다.
             「다시 걸어도 중복 안 된다」는 여전히 «안 말합니다»        -> 반쪽 그대로
  Ⅳ-4 인자   닫힌 목록을 «쓰는» 인자를 셉니다 — «하나»(속도)뿐입니다.
             소스 인자는 여전히 «도움말»만 답니다                      -> 반쪽 그대로
  Ⅳ-5 거르기 읽기 칸에서 «행을 거르는» 자리를 셉니다 — «0»            -> 막힘 그대로
  Ⅳ-1 만들 때 미리보기 라우트는 «있습니다». 다만 «선언에 붙인 뒤»에 돕니다 —
             그게 이 줄이 말하던 바로 그 순서입니다                    -> 막힘 그대로
  Ⅱ-4 자리표 그 글자를 봅니다. 그대로입니다                            -> 반쪽 그대로

🔴 이번에 «안 잰» 것 «둘» — 그래서 상태를 안 옮겼습니다
  Ⅱ-5 두 어휘  오늘 착지가 이 경계를 안 건드렸습니다. 다만 Ⅱ-2 를 재다가
              «접히는 자리»를 봤고, 그것이 이 줄의 반대쪽입니다
  Ⅴ-1 맥락    소유자 판정 대기입니다. 제가 옮길 자리가 아닙니다
```
🔴 **오늘 옮긴 넷 중 «셋»이 「서버는 되는데 화면이 안 읽는다」였습니다** (Ⅰ-1 · Ⅱ-1 · Ⅳ-3).
   Ⅱ-1 만 화면이 «따라와서» 닫혔습니다. 남은 둘은 그 부류로 목록에 «남습니다».

# 이 목록을 «다시» 재는 법
```
각 줄의 「세는 법」이 그것입니다 — 커밋 번호가 아니라 «세는 방법»입니다
🔴 그리고 지우기 «전»에 두 칸을 «둘 다» 보십시오. 서버만 보고 지우면 이번처럼 «셋»이 되살아납니다
⚠️ 이 방법으로 «못 가르는» 것 셋: 번들이 청크로 갈릴 때 · 화면이 움직이는 중일 때 ·
   토큰이 «값으로» 도착할 때(소스에서 영원히 0)
🔴 그리고 「못 쟀다」를 적을 땐 «그 방법»을 같이 적습니다 (총괄 판정 `b44f2e39`) —
   「없다」는 못 바꾸고 「못 본다」는 접근으로 바뀌지만, 「못 쟀다」는 «방법»으로 바뀝니다.
   이번 Ⅱ-5 가 그 칸에서 «막힘»으로 옮겨 온 것입니다
⛔ 제안 없음 · 코드 없음 · 도메인 낱말 없음 · 새 조사 없음
```
