# 지금 막는 것 — 명세 여섯의 「막히는 자리」를 하나로

총괄 지시(`task/MARKING_CONTRACT.md` 「막히는 자리를 «하나의 목록»으로. 그리고 «지금» 상태로」).
**새 조사 없이**, 여섯에 있던 것을 모으고 겹친 것을 합치고 **오늘 HEAD 에 대고 다시 쟀습니다.**

```
모은 곳   ATOM_ROW_SHAPE · REFUSAL_VOCABULARY · OPERATOR_JOURNEY
         INTERNAL_TOKENS · CHAIN_AUTHORING_JOURNEY · UNDO_JOURNEY
모은 수   26  ->  합쳐서 «18»  ->  다시 재서 남은 것 «14»
정렬     심각도가 아니라 «DoD 의 어느 절반을 막나»
```
> DoD: 「운영자가 소스를 «선언»하고 «활성화»하면 원자가 쌓인다 **·** 「들어갔나 · 왜 안
> 들어갔나」를 «화면에서» 안다」

# ✅ 먼저 — 이제 «안 막는» 것 «넷». 재서 지웁니다

| 무엇 | 무엇이 고쳤나 | 어떻게 확인했나 |
|---|---|---|
| 목적어가 «글자»여야 할 때 | 판정 `183eaf1d` | 새 종류를 만들지 않고 «엔티티»로. 코드 변경 0 이고 판별식은 운영자가 답합니다 |
| 선언 거절의 «주소»가 버려짐 | `a1814dc6` | 거절이 코드·경로를 «전부» 나르고, 자르면 「몇 개 중 몇 개」를 말합니다 — 코드에서 확인 |
| 변환 저장이 «백업 없이» 덮어씀 | `1541aa5a` | 저장 경로가 백업을 만들고, 임시 파일에 쓴 뒤 «바꿔치기»합니다 — 코드에서 확인 |
| 거절 «이유»가 서버에 없음 | `d917117b` | 서버 절반만 해소. 🔴 화면 쪽은 «여전히 0» 이라 아래 B-1 에 «반쪽»으로 남깁니다 |

⚠️ 넷 중 하나(거절 이유)는 **절반만** 해소됐습니다. 「고쳤다고 들었다」로 지우지 않았습니다.

# 🔴 A. DoD «전반부»를 막는 것 — 「선언하고 활성화하면 원자가 쌓인다」

## A-1 표 등록에 «화면»이 없습니다
```
출처   운영자 여정 ① · 체인 여정 1
지금   서버 ✅ (라우트 있음)    화면 ❌ (소스 «0» · 번들 «0»)
확인   그 경로를 읽는 클라 파일 수를 셌습니다
막는 것 여정의 «첫 걸음»이 앱 밖입니다
```

## A-2 🔴 규칙을 «앱 안에서 못 씁니다» — 전략의 마지막 걸음
```
출처   체인 여정 ①
지금   서버 ❌ (읽기 라우트만, 쓰기 «없음»)    화면 ❌ (목록만)
확인   규칙 경로의 라우트를 셌습니다 — GET 하나
막는 것 「체인이 표를 만든다」가 «명세»에서 «되는 것»으로 못 넘어갑니다
📌 소유자 판정 나왔고 구현자 큐에 있습니다
```

## A-3 대상 표가 «먼저» 등록돼야 하는데 아무도 안 알려 줍니다
```
출처   원자 행 명세 맨 앞 ③ · 체인 여정 ②
지금   서버 ⚠️ (표가 없으면 «조용히» 식별자 없는 쓰기)    화면 ❌
막는 것 순서를 모르고 지나가면 «조용히» 틀립니다
📌 A-2 가 열리기 전에는 이걸 «말해 줄 자리»가 안 생깁니다. 순서가 있습니다
```

## A-4 「이 표가 원자 행 표인가」를 «만들 때» 확인할 자리가 없습니다
```
출처   체인 여정 ④
지금   서버 ❌    화면 ❌
막는 것 만든 사람이 «나중에» — 선언에 붙여 시험을 돌린 뒤에 압니다
```

## A-5 시각 컬럼의 «타입»이 준비 경계까지 사는지 «미검증»
```
출처   원자 행 명세 맨 앞 ④
지금   실행이 필요합니다. 제가 «안 쟀습니다»
📌 구현자 큐에 있습니다. 결과를 «인용»할 자리입니다
```

## A-6 「고친 것이 반영되나」 — 구현자 측정 대기
```
출처   체인 여정 ⑤
지금   설정 다시 읽기 라우트 ✅ · 화면 ✅ · 「변환 파일 수정이 반영되나」는 «별개»
📌 구현자 큐(맵퍼 리로드). 화면·경로만 적고 결과는 인용합니다
```

## A-7 소급 실행이 인자를 «타이핑»으로 받습니다
```
출처   운영자 여정 ④ · 체인 여정 6
지금   서버 ✅ (연산 목록)    화면 ⚠️ (목록은 그리고, 인자는 운영자가 «칩니다»)
확인   그 인자의 도움말이 «다른 라우트를 직접 부르라»고 말합니다
막는 것 방금 선언한 사람이 자기 소스 이름을 «이미 알고» 있어야 합니다
📌 클라 큐
```

## A-8 바인딩된 컬럼이 «한 행»만 비어도 그 행이 거절됩니다 — 거를 자리가 없습니다
```
출처   원자 행 명세 맨 앞 ②
지금   선언의 읽기 칸 «여섯» 중 행을 거르는 것이 «없습니다»
확인   그 여섯을 셌습니다
막는 것 무효가 된 행이 표에 남아 «매번» 거절됩니다
📌 판정 대기 — 「이 행은 문장이 아니다」를 말할 자리
```

# 🔴 B. DoD «후반부»를 막는 것 — 「왜 안 들어갔나를 «화면에서» 안다」

## B-1 🔴 거절 «이유»를 그리는 화면이 없습니다 (반쪽 해소)
```
출처   운영자 여정 ② · 체인/되돌리기와 무관한 «단독»
지금   서버 ✅ `d917117b`    화면 ❌
확인   이유 관련 이름을 클라 소스·번들에서 셌습니다 — «0»
막는 것 DoD 후반부 그 자체입니다
📌 클라 큐
```

## B-2 선언 거절의 «주소»를 읽는 쪽이 없습니다
```
출처   거절 어휘 명세 ① · 운영자 여정 ③
지금   서버 ✅ `a1814dc6`    화면 ❌ (읽는 쪽 «0»)
확인   그 값을 소비하는 자리를 찾았고 «없었습니다»
✅ 다만 옆에서 «다른» 거절 하나가 이미 경로를 그립니다 — 그릴 자리는 «있습니다»
```

## B-3 봉투 거절 «여섯»에 코드도 경로도 없습니다
```
출처   거절 어휘 명세 ②
지금   서버 ❌ (문장뿐)    화면 ❌ (붙일 자리가 없습니다)
막는 것 원자마다 걸리는 부류인데 화면의 어느 칸도 못 가리킵니다
```

## B-4 같은 실패가 «시험»에서는 읽히고 «적재»에서는 안 읽힙니다
```
출처   운영자 여정 ⑤
지금   시험 ✅ · 적재 ⚠️ (수로만)
막는 것 운영자가 그 둘이 «같은 것인지» 모릅니다
📌 B-1 이 서면 절반이 같이 닫힙니다 — 따로 세지 않도록 여기 답니다
```

## B-5 실행이 «왜 도는지» 못 말합니다 — 재료가 창구에서 빠집니다
```
출처   내부 토큰 명세 ③
지금   표에 «인자 · 요청자 · 큐 시각»이 있고, 화면에 가는 줄에서 «셋 다» 빠집니다
확인   화면으로 가는 줄의 칸을 세어 표의 칸과 맞췄습니다 — 오늘도 그대로입니다
```

## B-6 자리표와 기본값이 «사람 말»처럼 읽힙니다
```
출처   내부 토큰 명세 ①②
지금   큐 행의 표 이름 칸에 자리표 · 요청자 자리에 기본값
📌 상수는 «판정하는 자리»가 있어 그대로 둡니다. 바꾸는 것은 «표시»입니다
```

# ⚠️ C. DoD 문장에는 없지만 «시도»를 막는 것 — 되돌리기

## C-1 🔴 복원이 «앱 밖»입니다 — 선언과 표 등록 둘 다
```
출처   되돌리기 여정 ①
지금   서버 ⚠️ (백업은 만듦 · 되돌리는 함수 «0»)    화면 ❌
확인   그 모듈의 함수를 세었습니다 — 뜨기·목록·최근·주기검사·정기실행. 복원 «없음»
막는 것 되돌릴 수 없으면 «시도하지 않습니다»
```

## C-2 원장에서 지운 것이 «감사»에 안 남습니다
```
출처   되돌리기 여정 ③
지금   표(셀) 회수 ✅ 남음 · 원장 행 삭제 🔴 쓰는 자리를 «못 찾았습니다»
⚠️ 「없다」가 아니라 「이 방법으로 못 찾았다」입니다
```

## C-3 회수가 «둘»인데 층이 다릅니다
```
출처   되돌리기 여정 ④
지금   하나는 «표의 셀» · 하나는 «원장의 행». 이름이 비슷합니다
막는 것 운영자가 첫째를 걸고 「원자가 안 사라진다」고 읽을 자리입니다
```

## C-4 백필 재실행은 «안전한데» 화면이 안 말합니다
```
출처   되돌리기 여정 ⑤
지금   안전 장치 «둘» (페이지마다 원자와 커서를 한 커밋 · 유일 색인)
      화면이 그중 «하나도» 말하지 않습니다
✅ 「이미 되는데 아무도 안 쓴다」 부류입니다
```

# 목록에서 «뺀» 것 — 막는 것이 아니라서

```
변환 파일이 «그 서버에서만» 산다   성질입니다(운영자의 코드). 여정의 사실로 명세에 남깁니다
한 행 = 한 원자의 선언 조건 셋     조건이지 막는 것이 아닙니다. 원자 행 명세가 정본입니다
```
