### D1 — 상단 바가 자기 컨트롤을 덮는다 (심각도 «높음» · 상시)

**무엇이 가려지나 — `elementFromPoint(버튼 중심)` 이 «다른 것»을 돌려줍니다 = 클릭이 그 버튼에 안 갑니다.**

```
1440×900 · 표 ledger_events      못 닿는 컨트롤 4 / 9
   🗑️ Row            <- Table 고르개를 감싼 요소가 가져감
   📁 폴더 업로드 · 💻 Desktop · Replay chain   <- 「Loaded 1000 rows in …」 알약이 가져감
1440×900 · 표 dt_log (쓰기 가능)  못 닿는 컨트롤 4 / 10
   📁 폴더 업로드 · 💻 Desktop   <- Table 고르개
   Re-translate · Replay chain  <- 같은 알약
1280×800                         겹치는 쌍 7 · 못 닿는 컨트롤 «6 / 9» (🔄 Refresh 포함)
1024×768                         겹치는 쌍 8 + 아래 D3
```

**기제 (구조로):**
```
알약    `.log-indicator-area` 「Loaded 1000 rows in 336.7ms」  rect left=815 w=243  position: static · z-index: auto
버튼    Replay chain  left=924 w=69   ->  924..993 이 815..1058 «안»에 완전히 들어갑니다
=> 둘은 «같은 흐름의 static 형제»라 겹치면 «DOM 뒤쪽»이 이깁니다. 가리는 것은 z-index 가 아니라 «폭»입니다
=> 바의 넘침 전략이 «없습니다»: overflow-x: visible · scrollWidth 1241 > clientWidth 1024
   그래서 좁아지면 줄바꿈도 가로 스크롤도 아니고 «서로 위에» 그려집니다
```
🔴 **이건 「가린다」가 아니라 「먹는다」입니다** — 운영자가 Replay chain 을 눌렀다고 «생각»하는데 알약이 받습니다.
⚠️ 오늘 그 둘은 토큰이 없어 `disabled` 이므로 «지금은» 손해가 안 보입니다. 토큰이 있는 운영자에게는 보입니다.

**한 줄 재현** (콘솔에 붙여 넣기 — 못 닿는 컨트롤을 이름으로 셉니다):
```js
[...document.querySelectorAll('button')].filter(b=>b.getBoundingClientRect().top<60&&b.getBoundingClientRect().width>20).map(b=>{const r=b.getBoundingClientRect(),t=document.elementFromPoint(r.left+r.width/2,r.top+r.height/2);return[b.textContent.trim().slice(0,16),(t===b||b.contains(t))?'OK':'가림: '+t.textContent.trim().slice(0,24)]})
```

**무엇이 가려지나 (어드민 1440, 띠 안을 40px 격자로 찍어 «밑에 있는 것»을 셈):**

🔴 **그리고 클릭이 막힙니다** — `elementFromPoint(「탭 열기 →」 중심)` 이 토스트를 돌려줍니다.
컨테이너도 토스트도 `pointer-events: auto` 라, 토스트 «사이의 빈 여백»까지 클릭을 먹습니다.

**메인 그리드(1440)에서는 조금 다릅니다:** 덮이는 것이 «데이터»입니다 —
`ag-cell-value` 약 9행 · `ag-body-vertical-scroll-viewport` · `ag-body-horizontal-scroll-viewport`(가로 스크롤바).
푸터의 `Prev/Next/VIEW/Paging/Load All/Load CSV` 는 중심이 띠 «아래»라 이름 댄 막힘은 0 이었습니다 —
다만 띠의 아래끝(876)이 푸터 상단(865)을 «11px» 물고 있습니다. 문구가 한 줄만 길어지면 넘어갑니다.

**한 줄 재현:**
```js
['긴 거절 문장 1','긴 거절 문장 2','긴 거절 문장 3','긴 거절 문장 4'].forEach(m=>showToast(m,'error',{ttl:60000}))

### D5 — 셀 글자가 선에 «닿거나 넘는다» (심각도 «중간» · 상시)

Range 로 «실제 글자 상자»를 재고 테두리까지의 가로 간격을 봤습니다(간격 < 3px 이면 닿은 것):
```

📎 상설 「마진 좀 넣어」의 판별식 그대로 — 「글자가 선에 닿아 있으면 그 부품은 안 끝난 것」.
⚠️ 열은 «넓힐 수» 있으므로 「못 읽는다」가 아니라 「기본 폭이 내용을 안 받는다」입니다.

## 5. 📎 제안 표 — «짓지 않았습니다» (상설)

| 토스트를 상단 우측으로 | 하단 중앙은 두 화면 다 «내용과 컨트롤»이 있는 자리입니다(주석이 적은 옛 문제의 다음 판) | 작음 |
