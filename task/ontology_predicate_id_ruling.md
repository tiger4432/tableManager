# 원자의 `predicate` — 이름인가 «불변 id» 인가 (총괄 회신, 2026-08-21 14:4x)

> 응용 기획 세션이 판정을 올렸다. **총괄 회신이 메시지로 두 번 유실돼 이 파일이 정본이다.**
> 응용 세션 원문 근거: `task/ontology_arbitrary_question.md` · `task/ontology_application_algorithm.md`

## 올라온 제안

소유자 발화(2026-08-20): 「**원장에 has_wafer 이런 도메인 어휘 안 들어가고** 어떻게 할 수 있을지」

```
지금    원자에  predicate = "register"        도메인 이름이 그대로 저장된다
제안    원자에  predicate = <불변 id>          뜻은 선언이 답한다
```
얻는 것: 개명이 원자를 안 건드림 · 공장·팀마다 다른 이름이 한 id 를 공유 · 읽는 쪽이 다르게 해석.

## 🔴 총괄 정정 ① — 「재백필이 어차피 대기 중이라 비용 0」은 «절반만» 맞다

응용 세션 전제: 원장이 안 흐르고 재백필이 대기 중 → 지금 바꾸면 추가 비용 0.

**총괄 실측 (2026-08-21 14:2x, 라이브 DB):**
```
원장 전체            221,563
ledger-v2 원자           792   (0.36%)
커서 12개 중 v2           1개
   dt_job     ledger-v2:925655da…      ← «막혀 있지 않다». 오늘 재스탬프 끝나 재개 가능
   lot_event  lot_event/1/rules:…      ← v1 모양. 막힌 건 «이쪽»뿐
```
**커서 전역 지문 문제는 오늘 해소됐다**(`b100fb2a`, 소스별 지문). 그래서 「원장이 안 흐른다」는
이제 `lot_event` 에만 참이다.

**그러면 비용이 0이 아니다:**
```
이미 쌓인 792행이 «옛 모양»으로 남는다       소유자 원칙: 원장은 append, 갈아치우지 않는다
지우고 다시 넣으면                          = 갈아치우기. 소유자가 오늘 명시적으로 거절
그냥 다시 읽으면                            predicate 가 바뀌어 uq_ledger_atom 키가 달라짐
                                            → 같은 사실이 «중복 792행»
```
792는 작지만 부류가 같다. **「지금이 나중보다 싸다」는 여전히 성립한다. 「0」만 틀렸다.**

## 🔴 총괄이 더 무겁게 보는 대가 — 응용 세션 목록에 «없던» 것

```
④ 원장이 «자기 완결성»을 잃는다
      지금   원자 하나만 보면 predicate = "register" — 뜻이 그 «안»에 있다
      뒤엔   원자는 id 만 들고, 뜻은 «지금 살아 있는 설정 파일»에 있다
      → 선언이 바뀌거나 지워지면 «과거 원자가 안 읽힌다»
```
**뷰로 해소되지 않는다 — 뷰도 «지금» 설정을 보기 때문이다.**
원장은 핵심가치 ⑤(변경 이력 추적)의 근거인데, 그 근거가 «가변 파일»에 기대게 된다.
하려면 **「선언은 은퇴만 되고 삭제되지 않는다」**가 같은 라운드에 서야 한다.

⚠️ 응용 세션이 붙인 조건(**id 는 생성되면 불변** · `register@1` 은 이름을 포함하므로 조건 미달)은
옳다. 다만 그 조건만으로는 위 ④가 해결되지 않는다 — 불변 id 라도 «선언이 사라지면» 뜻이 사라진다.

## 판정

**총괄 소관이 아니다. 소유자 판정으로 올린다.**

이유: 오늘 하루 지운 것들(절 넷·선언 다섯)은 **저작 층**이라 되돌릴 수 있다.
이것은 **원장에 영구히 들어가는 모양**이고 쌓인 원자는 되돌릴 수 없다.
응용 세션이 「제가 판단하지 않는다」고 한 것은 **옳은 처신이다.**

## 순서 — 겹치지 않고 «도움이 된다»

소유자가 `packs`·`claims` 절 통째 삭제를 승인했다(`task/ledger_drop_packs_claims_brief.md`).
```
지금    claim.emit.predicate  +  mappings.use     ← 술어를 «두 곳»이 부른다
그 뒤   mappings.<sentence>.predicate             ← «한 곳»
```
**id 라운드를 하게 되면 그 뒤가 더 쉽다.** 고칠 자리가 하나로 줄어든다.
현재 순서(packs 먼저)를 바꿀 이유가 없다.

**급한 판정은 파일에도 같이 적을 것 — 파일이 정본이다.**
