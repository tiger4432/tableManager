소유자가 엣지에 클로드 확장을 깔았다. `mcp__claude-in-chrome__*`로 **소유자가 로그인한 화면**을

```
list_connected_browsers → tabs_context_mcp → navigate → read_page / computer / javascript_tool
tab : 839164602   ·   http://localhost:8080/admin.html#ontology → "Ontology Explorer"
```

**측정 전 반드시 둘:**
1. `[...document.querySelectorAll('script[src]')].map(s=>s.src)` 가 `dist/admin.html`이 가리키는
   해시와 같은가. 다르면 `location.replace('/admin.html?cb='+Date.now()+'#ontology')`
2. **서버 프로세스가 그 커밋 이후에 떴는가.** `Get-NetTCPConnection -LocalPort 8080` → `StartTime`.
   2026-08-19에 이 둘로 네 번 헛돌았다

🔴 **그리고 이건 «가끔»이 아니라 «항상»이다 (2026-08-20 실측).** 실행 명령을 읽어 보니
`python -m uvicorn main:app --host "" --port 8080` — **`--reload`가 없다.** 즉 파이썬을 고치면
**무조건** 재시작 전까지 안 들어간다. 「이번엔 괜찮겠지」가 성립하는 경우가 없다.

```powershell
(Get-CimInstance Win32_Process -Filter "ProcessId = <pid>").CommandLine
```

⚠️ **`/admin/reload-configs`로는 안 된다.** 그건 table_config·동적 매퍼 모듈·이름 붙은 캐시
몇 개를 비운다. **프로세스 시작 시점에 없던 «함수»는 캐시를 비운다고 생기지 않는다.**
5173 개발 서버도 구제해 주지 않는다 — 클라만 최신이고 API는 같은 낡은 프로세스다.

오늘 결함 둘이 보고서가 아니라 화면에서 나왔다.

## 브라우저 — 삭제 확인창이 내 자동화를 막는다 (2026-08-20 실측)

삭제는 **네이티브 `window.confirm`**(`ontology_explorer.js:377`)이다. 뜨는 순간 스크립트
주입이 막혀서 **screenshot·javascript_tool이 전부 5초 타임아웃**으로 죽는다. 화면이 굳은 걸로
착각하기 쉽다 — 굳은 게 아니라 대화창이 떠 있는 것이다.

```
Delete 클릭 → computer key Return   (← 이게 확인을 «누른다». 실제로 삭제가 파일까지 갔다)
            → navigate 로 재적재     (← 이래야 스크린샷이 다시 돌아온다)
```

**더 나은 방법 (2026-08-20 실측):** 누르기 «전에» 페이지 안에서 답해 둔다.

```js
window.confirm = () => true;   // 그다음 Delete 클릭 → 대화창이 애초에 안 뜬다
```

🔴 **이건 «내 시험 선언»에만 쓴다.** 확인창은 사용자를 위한 관문이고, 이걸 습관으로 만들면
소유자 데이터 앞에서도 관문을 지나치게 된다. 쓰는 이유는 편해서가 아니라 **계측기가 그
대화창 아래서 눈이 멀기 때문**이다.

🔴 **확인창이 떠 있는 동안 잰 「파일에 아직 없다」는 «부재»가 아니다.** 나는 이걸로 한 번
헛짚었다 — 삭제가 안 된 줄 알고 파일을 직접 고치러 갔는데, Return이 이미 눌러서 반영돼
있었다. [[an-empty-database-answers-every-question-with-absence]] 와 같은 병이다.

### 소유자에게 첫 마디로 물을 것 — 판정 두 개가 걸려 있다

1. **원본 JSON 편집기를 지울까요.** 조건(「JSON 없이 못 하는 것 0」)은 **닫혔다** —

   「맨 마지막」이라 했고 되돌리기 어려운 방향이라 한마디를 받고 한다.
2. **UI 목업.** 화면 정리(단계 막대 `Complete` × 6 · Reference Flow `active · valid` × 6 ·
   같은 JSON 두 탭 · 상단의 `Revision 0`과 64자 해시)와 Reference Flow 재설계는 **전부 목업이
   다시 정의할 표면**이라 일부러 안 건드렸다. 목업을 받고 **CSS만으로 되는 것 / 구조를 건드리는
   것**으로 갈라서 올린다.

### 목업 대조표 — 지금 화면 실측 (2026-08-20 03:40, 살아 있는 선언 보기 기준)

목업을 받으면 읽지 말고 **이 표에 겹친다.** 왼쪽이 지금이고, 각 줄이 「CSS만으로 되나 /
구조를 건드리나」의 판정 단위다.

```
단계 막대       Complete × 6            전부 같은 값 → 정보 0        [Rule 7]
Reference Flow  노드 12개                active · valid × 3
                                        resolved · active × 1        [Rule 7 · 집합으로]
편집기 탭       정의 · 작성 · 사용처 · 원본 JSON
                                        JSON이 두 곳에 있다          [Rule 7 · 같은 것 두 번]
상단            64자 해시 × 1            사람이 먼저 보는 자리        [Rule 7 · 기계값]
빈 통           None defined × 0         ✅ 이미 닫힘 (1503db1)
```

**갈라서 올리는 기준:** 색·간격·타이포·접기 여닫이는 CSS. **무엇을 «말할지»가 바뀌면**
(예: 균일 상태를 한 번만 말한다, 접힌 개수를 보인다, 탭 하나를 없앤다) 구조다 — 렌더러가
바뀌므로 목업만으로 확정하지 말고 소유자 판정을 같이 받는다.

⚠️ **Reference Flow는 CSS로 안 끝난다.** 「집합으로 보인다」는 무엇을 접고 무엇을 예외로
남길지의 문제이고, 그건 이 패널이 답해야 할 질문이 「닿는 경로 전부」인지 「누가 관여하나」인지에
달려 있다(보드 P1). **목업이 그 질문에 답하고 있는지부터 본다.**
