## 2. 채널 — 총괄과 «파일과 커밋»으로 통신합니다

> 소유자 지시: 「세션 간 메시지가 에러를 유발하는 것 같다. **지시문 커밋 기반으로** 통신 돌려」

워크트리는 **다른 브랜치**(`design`)라 파일이 자동으로 안 보입니다. 그래서 이렇게 합니다:

```
총괄 → 당신    task/DESIGN_ORDERS.md          «main» 에 올립니다
               받는 법:  git fetch origin && git merge origin/main
당신 → 총괄    task/design_session_report.md   «design» 브랜치에 커밋 + push
               git push -u origin design       총괄이 fetch 해서 읽습니다
```

```
일 시작 전     git fetch origin && git merge origin/main     ← 지시가 바뀌었을 수 있습니다
보고할 때      report 파일 «맨 위»에 적고 commit + push
판정 요청      보고 파일 맨 위에 「🔴 판정 요청」.  총괄이 DESIGN_ORDERS 에 답합니다
```
🔴 **커밋이 초인종입니다.** 총괄이 커밋을 감시합니다. push 안 하면 안 닿습니다.

⚠️ 급하면 소유자가 양쪽을 직접 깨웁니다. 그것이 유일한 대체 신호입니다.

## 3. 🔴 일하는 순서 — 목업 먼저, 코드는 그다음

```
1  대상 화면을 «직접 본다»       실제로 열어 본다. 추측 금지
2  무엇이 불편한지 «적는다»      관측으로. 「~할 때 ~가 안 보인다」
3  목업을 만든다                 task/design/<화면>_<주제>.html   한 파일
4  🔴 소유자에게 보여주고 «기다린다»
5  승인 후에만 client2/src 를 고친다
6  당신 워크트리에서 빌드·확인 -> 보고 -> 총괄이 «main 으로» 병합
```

**4번을 건너뛰지 마십시오.** 오늘 소유자가 「자기 혼자 막 한다」고 하신 것이 그것입니다.
그리고 **목업 한 장에 결정 하나만** 담으십시오 — 다섯 개를 한 장에 담으면 아무것도 못 정합니다.

```
✔  실제 데이터 모양 (진짜 컬럼명 · 진짜 길이의 로트 번호 · 진짜 개수)
✔  «전»과 «후»를 나란히 · 좁은 화면에서 어떻게 되는지
✖  lorem ipsum · 가짜 숫자 · 실제로 없는 기능
✖  「나중에 이렇게도 할 수 있습니다」   ← 지시받지 않은 것
```

## 4. 🔴 소유자 상설 — UI 원칙. 이 세션의 «헌법»입니다

```
🔴 절대 복잡하면 안 된다     새 영역 · 새 모드 · 모달 «금지».  읽기 무마찰, 쓰기 «1회 확인»
🔴 가독성이 «기능»이다       작은 글씨는 «없느니만 못하다».  줄이려고 작게 만들지 말 것
🔴 문구는 번역체 금지        기호 · 짧은 영어 · 명사형.  「~를 지지합니다」류 금지
🔴 칸 옆 문구는 «무엇을 하면 되는지»만
      설계 근거 · 미결 판정 · 파일 경로 · 에러 코드 원문 -> 화면에 내지 않는다
```

### 오늘 소유자가 실제로 하신 말 — 추상 규칙보다 이게 낫습니다
```
「이럴 거면 드롭박스를 하지, column 을 나열하는 게 무슨 의미」
   -> 후보가 «보이는데 못 고르는» 칸.  나열은 선택이 아니다
「dt_cell_key 쓰라는 거면 그냥 미리 넣어두면 되지, 뭐 저래 모호하게 적어놨어」
   -> 기본값은 «보여주는» 게 아니라 «들어가 있어야» 한다
「구조를 못 외우겠다」
   -> 사람이 «밖에서» 알아야 하는 것이 있으면 그건 화면이 덜 된 것이다
```
🔴 **총괄이 밤을 태운 오독도 적어 둡니다:** 「접힌 컨트롤은 «없는» 컨트롤이 아니다」 —
「없다」고 적기 전에 **다 펼쳐 보고** 적으십시오.

## 6. 🔴 되돌리는 명령 — 워크트리 안에서도 조심하십시오

```
✔  git add <경로>            경로를 «하나씩»
✔  git commit ... -- <경로>  🔴 commit 에도 경로를 붙입니다 (안 붙이면 인덱스 «전체»가 갑니다)
✔  커밋 전 git diff --cached --name-only 로 «담길 것»을 눈으로 셉니다
✔  백틱이 있는 커밋 메시지는 `-F` 파일로 (셸이 백틱을 «실행»합니다)
✖  git add -a / -A / 디렉터리째
```
🔴 **파일을 «프로그램으로» 자르거나 갈아 끼우면 «바뀐 줄 수»를 찍고 예상과 대조하십시오.**
오늘 총괄이 78줄 교체를 하려다 **643줄을 지웠습니다.** `git status` 는 「M 하나」로
똑같이 조용했고 `--name-only` 도 못 잡습니다 — 파일이 하나니까요.
