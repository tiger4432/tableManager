## 0. 재는 방법

```
대상   spotfire-style-ontology-rnd-view.zip 의 「웨이퍼 진단 화면.dc.html」 §2a
방법   dev 서버로 서빙 -> 브라우저로 «띄워 놓고» 보면서 + computed 실측
기준폭 1920 (목업 `.dv-card` 가 그 폭에 고정)
```

⚠ **중간에 캐처가 막혔고, 원인은 페이지가 아니었습니다.** 목업 페이지 탓인 줄 알고
섹션·스크립트·외부링크를 지워 봤는데 그대로였고, «앱 페이지도» 같이 실패해서 갈렸습니다 —
`visibility: hidden · outerWidth 0`, 즉 **창이 안 보이는 상태라 프레임을 안 그리고** 있었습니다.
창을 다시 띄우자 바로 챍혔고, 아래 §5·§7·§8·§9 는 그 뒤에 «본 것»으로 고쳐 썼습니다.

🔴 **보자마자 제 앞 명세가 틀린 게 나왔습니다** — computed 로만 재고 「맵 패널 하나에 캔버스 2」로
적었는데, 화면엔 **맵이 둘**입니다(본딩 맵=마킹1 · 코어 맵=마킹2). 그것이 「띄워 놓고 보라」의 이유입니다.

⚠ 계측기 오류 하나 더 — 색을 hex 로 바꾸는 제 코드가 `rgba(0,0,0,0)`(투명)을 `#000000`(검정)으로
읽었습니다. 그대로 썼으면 「패널 배경이 검다」는 없는 사실이 명세에 올라갔을 것입니다.

## 3. 부품 A — 머리 요약  (인스턴스 1)

**그리는 것.** 지금 무엇을 보고 있는지 한 줄. 씨앗(웨이퍼/로트), 그 씨앗이 선 공정 맥락,
그리고 걷기 결과의 «상태». 판정 문장은 쓰지 않습니다.

**상태 — 이 부품의 본체입니다.** 다섯 가지가 전부 「없음」인데 **하나도 고장이 아닙니다.**
서로 «다른 말»로 보여야 하고, 어느 것도 에러처럼 보이면 안 됩니다.

| 상태 | 뜻 | 쓰지 말 것 |
|---|---|---|
| `contrast: unexamined` | 또래를 **안 쟀다** | 「깨끗했다」 |
| `complete: false` | 예산에서 끊김 → 끊긴 후보는 **미검사** | 「없다」 |
| `state: empty` | 걷기가 물리량에 **안 닿음** | 「원인 없음」 |
| `tied` | 동률 — 순서가 **있는 척 금지** | 임의의 1·2위 |
| `incomparable` | 우열이 아니라 **종류가 다름** | 「더 낮음」 |

토큰: 배경 `--bg-header`, 아래선 `--border-strong`, 본문 `--text`, 보조 `--text-muted`.
상태 칩은 `--warning`/`--orange` 계열(미검사·동률)과 `--text-muted`(안 쟀음)로 가르되,
**`--danger` 는 쓰지 않습니다** — 다섯 중 어느 것도 오류가 아닙니다.

**최소 / 성장** (도출): 최소 높이 72px(실측), 최소 폭 720px — 그 아래에서는 씨앗 이름과
상태 칩이 같은 줄에 못 섭니다. 늘어나면 **가운데 여백만** 늘고 칩은 오른쪽에 붙습니다.

## 4. 부품 B — 제어  (인스턴스 1)

**그리는 것.** 축과 마킹의 «현재 값». 실측된 내부 구조는 213px 열에 이렇게 쌓입니다:

🔴 **대조군 «고르는» UI 는 만들지 않습니다.** 지금 원장에 진짜 대조군이 0장이라

선택된 값 `--accent`.

**최소 / 성장** (도출): 열 하나가 213px(실측)이므로 최소 폭은 213px + 여백.
늘어나면 **열이 늘지 않고 열 «개수»가 한 줄에 더 들어갑니다** — 각 열은 고정폭이 자연스럽습니다.

⚠ **정정 (2026-08-23 밤)** — 이 문장은 `/api/ledger/subgraph` 가 `{kind, sublabel, detail, color_role}` 을 준다는 전제에서 썼는데, **그 모양은 없습니다.** 제가 지시서를 믿고 재 보지 않은 채 썼고, 총괄이 같은 오류를 여덟 자리에서 정정했습니다. 지금 서버가 주는 것은 `{id, type, label, rank, top, tied, incomparable, evidence[]}` 뿐이고, 「실측 있음/이름뿐」은 **근거 홉에서 도출**합니다(경계 어댑터 — `api.js` 참조). 아래 문장은 기록으로 남깁니다.

## 9. 부품 G — 순위 리스트  (인스턴스 1)

**본 것.** 표이고, 머리에 두 문장이 «화면에 적혀» 있습니다:
`(마킹 2 연동)` 과 **`순위는 판정이 아니다 · 점수·확률 없음`**.

열(본 것): `순위 · 물리량·모델 · 홉 · 실측 · 상태`
```
1  delam / delam_formation        3  -            최상위
2  void / void_formation          3  -            동률
2  die_stress / delam_formation   4  -            동률
3  SYN-BD-02 챔버 파티큘 /
   사고 이력 · SYN-BD-02 · …      2  8/19 03:20   동률 · BONDING 겹침
4  bond_temp / void_formation     4  °C · 1,962   동률 · 마킹 2
4  bond_pressure / delam_formation 4 MPa          동률 · 방향 반대
5  surface_oxidation / ← PLASMA_CLEAN·CH-B  5  -  동률
…  interface_unfill / void_formation  6  -        미검사
```
🔴 **물리량과 모델은 두 줄입니다. 합치지 마십시오** — 같은 물리량이 두 모델에 나오고,
합치면 아무도 하지 않은 세 번째 주장이 생깁니다.
🔴 **순위는 판정이 아닙니다.** 도달량(숫자)은 응답에 안 나옵니다 — 서버가 뺐습니다.
`tied` 인 것들은 **같은 순위 숫자를 그대로** 달고 있었습니다(2,2 / 4,4,4). 그렇게 그립니다.

**경로.** 홉이 2~6 이고 「홉」 열에 수만 보입니다. **기본은 접혀 있습니다** — 25개를 다 펼치지 않습니다.

**상태 열이 이 부품의 어휘입니다:** 최상위 · 동률 · 동률·마킹 2 · 동률·방향 반대 ·
동률·BONDING 겹침 · **미검사**. 「미검사」가 `complete:false` 로 끊긴 것이고 **오류가 아닙니다**.

토큰: 표 머리 `--bg-header`, 줄무늬 `--row-stripe`, 순위 `--text`, 모델 `--text-muted`,
최상위 `--accent`, 마킹된 행 `--accent-2`, 「-」와 「미검사」는 `--text-muted` — `--danger` 금지.

**최소 / 성장** (도출): 최소 380×320. 늘어나면 **행 수**가 늘고, 「물리량·모델」 열만 늘어납니다
(홉·실측·상태는 고정폭).
