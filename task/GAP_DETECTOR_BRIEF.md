## 계산 — 명세 §0~§1 을 그대로 코드로

### 1. 어휘를 순회한다 (도메인 낱말 0)
```
선언에서   술어 P · 주어타입 S · 목적타입 O
결측(주어쪽) = S 노드 중 P 로 «나가는» 것이 없는 것
결측(목적쪽) = O 노드 중 P 로 «들어오는» 것이 없는 것
```

### 2. 🔴 그런데 「두 방향」은 «한 술어의 두 쪽»이 아닙니다
명세 §0 의 정정입니다. 같은 타입에 «둘 이상»의 술어가 들어오면, 각 술어가 그 타입에서
닿은 «집합»을 만들고 그 집합들의 «차이»가 결측입니다. 선언에서 그런 타입이 넷:
```
defect_kind@1   of_kind · leads_to
quantity@1      measures · leads_to
wafer@1         has_wafer · in_container
die@1           inspected · transfer · bonded_from
```
방향의 이름 = 「어느 술어가 그것을 가졌나」. 이름표는 명세 §2-A/§2-B 에 있습니다.

### 3. 제외 셋 — 전부 «선언에서» 나옵니다. 하드코딩 금지
```
① 목적이 노드가 아니면 목적쪽을 «세지 않는다»
   has_netdie@1(kind=value) · register@1(kind=none)
   -> 0 이 아니라 «질문이 성립 안 함». 그렇게 «표시»하십시오
② 자기 고리(같은 타입 -> 같은 타입)의 «머리·꼬리»는 세지 않는다
   transfer · bonded_from · derived_from · slot_map · leads_to(절반)
   -> 안 그러면 모든 사슬이 결측 둘을 내고 화면이 그것으로 찹니다
   🔴 다만 «두 술어의 차이»로 잡히는 것은 «셉니다» — 단일 술어의 끝만 안 셉니다
      (예: 검사는 있는데 계보가 없는 자리 = 셈. 그냥 사슬 머리 = 안 셈)
③ 부재가 «좋은 소식»인 술어는 세지 않는다
   선언에서 이 성질을 가진 것은 observed@1 «하나»입니다 (결함 없는 다이 = 양품)
   -> 이 하나는 명세가 판정한 것이므로 «명세를 근거로» 제외하십시오
```

### 4. 분류하지 «않습니다» — 나이를 같이 냅니다 (소유자 확정)
```
소유자   「없어 나이만 보여」
=> 「아직」이냐 「없다」냐를 «코드가 정하지 않습니다». 부재 + 나이를 냅니다
   나이 = 그 노드가 원장에 «처음 나타난» 때부터 지금까지 (원자의 occurred_at)
   임계값 «없음» · 새 축 «없음»
```
