## 🔴 오해되면 안 되는 상태 «다섯» — 전부 «없음»인데 «고장»이 아닙니다
```
contrast: unexamined   「안 쟀다」 ≠ 「깨끗했다」    ← 지금 «항상» 이 값입니다
                       (원장에 「검사했는데 결함 0」인 웨이퍼가 «0장»)
complete: false        예산에 끊김 -> 끊긴 후보는 «부재»가 아니라 «미검사»
state: empty           걷기가 물리량에 «안 닿음» ≠ 「원인 없음」
tied: true             동률. 순서가 «있는 척» 하면 안 됩니다
incomparable: true     우열이 아니라 «종류가 다름» (한쪽은 표시에서, 한쪽은 대조군에서 앞섬)
```
🔴 **이 저장소는 이 부류로 하루에 여덟 번 거절당한 적이 있습니다** — 「없는 것을 고장이나
진행 중으로 읽는 것」. 다섯이 **서로 다른 말**로 보여야 하고, 어느 것도 «에러처럼» 보이면 안 됩니다.

## 🔴 소유자 보강 (같은 날) — 「모든 UI는 «조립식»」
> 「행동 규칙 추가: 모든 ui는 "조립식"」
> 「고유 div를 가지고 그리드 배치로 작동하게. 마킹은 모든 영역에서 공유」

```
