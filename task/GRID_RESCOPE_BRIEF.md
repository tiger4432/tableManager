# 그리드에서 「선택한 행 다시 번역」 — 그리고 «선언된 것이 보이게»

총괄 지시서. 2026-08-31. 소유자 판정 둘로 모양이 정해졌습니다.

```
「선언에 정의된거만 하는게 맞지, a인가?」
「이러면 사용자들이 어떻게 선언에 정의되었는지 알기 쉽게 라벨 같은게 있어야할듯」
```

## 도착지
```
운영자가 그리드에서 «선언된 소스 표»를 열면 그것이 소스임을 «보고»,
행을 골라 「다시 번역」을 누르면 그 범위만 다시 돕니다.
선언 안 된 표에서는 그 버튼이 «없고», 없다는 것도 «보입니다».
```

## 왜 이 모양인가 — 실측 둘
```
표 -> 소스가 «1:1»       선언 15 관계 전부, 소스가 여럿인 표 «0»
                        -> 「어느 소스를 다시 돌릴지」 물어볼 필요가 «없습니다»
15 관계 전부 등록됨       table_config 에 다 있습니다 -> 그리드에 «이미» 뜹니다
=> 신설은 «라벨 + 메뉴 하나». 새 화면 «없음»
```

## 1. 서버 — 선언 라우트가 «소스»를 같이 줍니다
```
지금   GET /api/ledger/declaration  ->  { state, entities(9), predicates(14) }
       🔴 relation · sources 가 «없습니다». 그래서 클라가 「이 표가 소스인가」를 알 방법이 없습니다
추가   sources: [ { source, relation, emits[술어], scope_columns[선언된 입력 컬럼] } ]
```
```
scope_columns 가 왜 필요한가   그리드 선택을 «범위»로 바꿀 때 어느 컬럼으로 묶을지 정해야 합니다
                            그리고 그건 이미 서버가 검증하는 목록입니다
                            (base_select_columns — 범위 읽기가 그걸로 거절합니다)
=> 화면이 «고를 수 있는 것»과 «서버가 받는 것»이 같은 목록에서 나옵니다
```
⛔ 새 라우트를 파지 «마십시오». 있는 선언 라우트에 절 하나입니다.

## 2. 클라 — 라벨과 메뉴
```
라벨   표를 열면 «머리»에 한 줄
      「원장 소스 — dt_transfer · 만드는 것: transfer@1」
메뉴   선택이 있을 때만  [ 선택한 N행 다시 번역 ]
      -> 드라이런 «먼저». 「거둘 N · 다시 만들 M」을 보여주고 나서 실행
```

### 🔴 라벨은 «셋»으로 말합니다 — 상설 ⑥ 그대로
```
「원장 소스 — <이름>」     선언에 있습니다
「원장에 안 들어갑니다」    선언에 «없습니다» — 이것도 «말해야» 합니다
「선언을 못 읽었습니다」    라우트 실패 — 위 둘과 «구별»되어야 합니다
```
⛔ 셋을 「라벨 없음」 하나로 합치지 마십시오. 그러면 「소스가 아님」과 「못 읽음」이 같아지고,
   그건 오늘 밤 내내 잡은 그 병입니다.

## 3. 하지 않는 것
```
⛔ 체인 리플레이를 여기 붙이지 마십시오 — 그건 «규칙» 단위(params=[rule])이지 행 단위가 아닙니다
   원장 재번역만 이 메뉴입니다. 체인은 별도 판정입니다
⛔ 「어느 표에서든 영향받는 소스를 따라가기」 — 소유자가 ⓐ로 판정했습니다
   선언이 말하는 것(relation -> source)만 합니다. 체인 규칙을 따라가지 않습니다
⛔ 전체 선택을 «막지» 마십시오. 대신 드라이런 수를 보여주고 사람이 정하게 하십시오
```

## 4. ⚠️ 운영 흐름에서 걸릴 수 있는 것 — 알고 시작하십시오
```
소스의 관계 다수가 «뷰»입니다 (dt_log_transferable · bonding_core_die …)
=> 보고 «선택»은 되지만 «고치는» 것은 원본 표에서 해야 합니다
=> 「인벤토리에서 식을 고치고 -> dt_log_transferable 을 다시 번역」이면 표 «둘»을 오갑니다
소유자 판정이 ⓐ이므로 그대로 갑니다. 다만 그 왕복이 잦아지면 그때 다시 올립니다
```

## 5. 검증
```
G1  선언에 없는 표에서 그 메뉴가 «안 보이는가»
G2  라벨 셋이 «각각» 나오는가 — 소스 / 아님 / 못 읽음
    🔴 「아님」과 「못 읽음」을 각각 만들어 확인하십시오. 하나만 보면 구별을 못 잽니다
G3  선택 -> 범위로 넘어갈 때, 서버가 거절하는 컬럼이면 «화면에서 고를 수 없는가»
    (같은 목록에서 나오므로 어긋나면 안 됩니다)
G4  드라이런이 «먼저» 뜨고, 그 전에는 아무것도 안 써지는가
```

## 6. 레인
```
서버(선언 라우트 한 절)   구현자
그리드(라벨·메뉴)        클라
=> 서버가 먼저입니다. 클라는 그 칸이 생긴 뒤에 붙습니다
```
