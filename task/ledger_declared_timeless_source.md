# [Task] 시각 없는 소스 — 「시각 없음」을 선언으로 표현한다

> **상태:** 착수 승인됨 (소유자, 2026-08-18 「시각 없음 선언」)
> **발견 경로:** 가이드만으로 새 소스를 세워 보는 검증에서, 시각 컬럼이 없는 `void` 표가
> **문자열 컬럼을 시각으로 지목**하고 팩에 **`1970-01-01` 상수**를 박아야 통과했다.
> 통과하지만 뜻이 거짓이고, 가이드 §15의 「가짜 값 생성 금지」와 정면으로 충돌한다.

## 문제

원장 봉투의 `occurred_at`은 **없앨 수 없다.** `ledger_events`가 시간 분할이고 PK가
`(id, occurred_at)`이므로 NULL이 들어갈 자리가 아니다. 그런데 세상에는 **시각 컬럼이 없는
표**가 있다. `void`가 그렇다 — 어디에 얼마만 한 보이드가 있는지만 말하고, 언제인지는
말하지 않는다.

지금은 그 표를 원장에 붙이려면 **거짓말을 선언해야 한다:**

- `driver.occurred_at.column`에 시각이 아닌 컬럼(문자열이어도 통과한다)을 적거나
- 팩의 `occurred_at` 역할을 상수로 묶어 모든 원자에 같은 가짜 시각을 찍거나

둘 다 **읽는 쪽에서 구분할 수 없다.** 「2026-08-18에 보이드가 생겼다」로 읽히고, 여정·대조가
그 시각을 세계 시각으로 취급한다. 이 프로젝트가 반복해서 맞은 모양이다 — 사실처럼 생겼지만
사실이 아닌 값.

## 판정 — 「모른다」를 말할 수 있게 한다

**시각을 없애는 게 아니라, 시각의 «출처»를 선언하게 한다.**

원자는 여전히 `occurred_at`을 갖는다(가질 수밖에 없다). 대신 그 값이 **세계 시각인지
적재 시각인지**를 원자가 스스로 말한다. 그러면 읽는 쪽이 「언제 생겼나」와 「언제 봤나」를
섞지 않는다.

### 선언 모양

`sources.<id>.driver.occurred_at`가 지금은 `{column, timezone}` 고정이다. 여기에 두 번째
형태를 받는다:

```jsonc
"occurred_at": { "column": "event_time", "timezone": "Asia/Seoul" }   // 종전: 세계 시각
"occurred_at": { "basis": "ingested", "timezone": "Asia/Seoul" }      // 신규: 적재 시각
```

- `column`과 `basis`는 **동시에 못 쓴다.** 정확히 하나여야 한다
- `basis`의 허용값은 지금 `"ingested"` 하나다. 새 값이 필요해지면 그때 판정한다 —
  열린 문자열로 두지 않는다
- `timezone`은 두 형태 모두 필수다. 묵시적 기본값은 없다

### 원자에 남는 것

`basis: "ingested"`로 선언된 소스의 원자는 **시각 출처를 봉투에 싣는다.** 어디에 실을지는
구현자가 정하되 조건이 둘이다:

1. **원자만 보고 구분할 수 있어야 한다.** config를 다시 읽어야 알 수 있으면 안 된다 —
   원자는 config보다 오래 살고, 그때의 선언은 이미 바뀌어 있다
2. **기존 원자와 섞이지 않아야 한다.** 종전 원자에는 이 표식이 없고, 없음이 곧
   「세계 시각」이다

### 팩·프로필은 안 바뀐다

`occurred_at` 역할은 여전히 필수이고 `$role` 참조여야 한다. **바뀌는 것은 그 역할에 무엇이
들어오느냐**뿐이다 — 프로필이 상수를 박는 대신, 엔진이 선언된 시각 출처에서 채운다.
프로필에 `1970-01-01` 같은 리터럴이 등장할 이유가 사라진다.

## 읽기 쪽 — 여기가 진짜 목적이다

선언만 받고 읽기가 모르면 아무것도 안 바뀐다. **최소한 이것만은 해야 한다:**

- 여정(`/journey`)과 대조에서 적재 시각 원자를 세계 시각처럼 정렬·구간화하지 않는다.
  섞어야 한다면 **섞는다는 사실이 화면에 보여야** 한다
- 「이 시각은 관측 시각입니다」가 값 옆에 붙는다. 문구는 짧게 — 기호나 한 낱말

## 합격 기준

- [ ] `void` 표를 **가짜 값 없이** 선언할 수 있다. 프로필에 시각 리터럴이 없다
- [ ] `column`과 `basis`를 함께 적으면 거절된다. 둘 다 없어도 거절된다
- [ ] `basis`에 미등록 값을 적으면 이름을 대며 거절된다
- [ ] 적재 시각 원자를 **원자만 보고** 세계 시각 원자와 구분할 수 있다
- [ ] 종전 원자는 표식이 없고, 그 없음이 「세계 시각」으로 읽힌다
- [ ] **원자 디프 0** — 기존 소스(`lot_event`)의 원자가 한 글자도 안 바뀐다
- [ ] 가이드에 시각 없는 표의 절이 생긴다. 지금은 그 경우가 아예 없다

## 비범위

- `void` 표에 시각 컬럼을 **추가하는 것**. 그건 소스 스키마 변경이고 별건이다
- 다른 `basis` 값(예: 파일명에서 읽기). 필요해질 때 판정한다
- 백필 실행·커서 이동
