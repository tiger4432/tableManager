## ① 접힘 — 저장·추가 뒤에 펼침이 날아간다

### 실측 (총괄, 09:0x, 라이브 화면)

```
+ 매핑 을 누르면          mappings.register 가 «접힘 · 2» 로 태어난다
저장을 누르면             bind.mappings 서브트리가 통째로 접힌다
매핑 하나 채우는 데       접힘 5번을 손으로 폈다:
                          mappings → register → 역할 바인딩 → subject → keys → dt_job
그 접힌 안에 있는 것       + 매핑 · + 역할 · + 식별키   ← 「없다」는 역할을 만드는 문 전부
```

**그래서 화면이 「역할 X 가 없다」고 말하는 «바로 그 순간», X 를 만들 버튼이 화면에 없다.**
총괄이 이걸 「폼이 못 푸는 칸」으로 읽고 밤을 태웠다.

### 도착 조건

**같은 소스를 다시 만들 때 «손으로 펴는 횟수»가 준다.** 특히 **방금 추가한 것은 열린 채 태어난다** —
사람이 이름을 쳐서 만든 것을 다시 찾아 펴게 하지 않는다.

### 🔴 범위 밖 — 명시한다

```
✖  거절 카드를 «편집기로» 만드는 것          새 표면이다. 소유자 판정 안 났다
✖  트리 렌더러 재설계 · 상태관리 도입         한 자리 막힌 것을 라운드로 키우지 않는다
✖  마찰 4·5·6·7·8 (relation 자유입력 등)     판정 안 났다
```
구현자가 제안했던 「거절 카드에서 바로 만들기」는 **더 좋은 화면일 수 있으나 이번이 아니다.**
지금 고치는 것은 **이미 있는 문이 안 보이는 것**이지, 문을 새로 내는 것이 아니다.

### ⛔ 멈춤 조건 — «하나»다

**펼침 상태를 보존하려는데 트리 노드에 «재렌더를 건너 살아남는 신원»이 없으면 → 멈추고 보고.**
그건 렌더러 구조 이야기라 다른 라운드다. 그 외에는 진행하면서 재고, 숫자는 나오는 대로 한 줄씩.

### ⚠️ 총괄 관측 하나 — «전제로 쓰지 말 것»

총괄이 걸으면서 **드롭박스가 재렌더 뒤 옛 값으로 되돌아가는 것을 세 번** 봤다
(`매퍼 단위` · `종류` · `approval_status`). **다만 총괄은 네이티브 setter + `input` 이벤트로
값을 넣었다** — 사람이 «마우스로 고르는» 경로가 아니다. **내 계측기의 경합일 수 있다.**

```
먼저 재라   진짜 클릭(사람 경로)으로도 되돌아가는가
되돌아가면  ①과 «같은 뿌리»일 수 있다 (재렌더가 뷰 상태를 버린다). 같이 잡히는지 보고
안 되면     내 계측 문제다. 보고만 하고 «고치지 말 것»
```
[[a-hypothesis-is-not-a-diagnosis]] — 후보를 확신조로 넘기지 않는다.

## ② 체크박스 — false 로 «보이는데» 값이 없다

### 실측 (총괄, 09:0x)

```
새 소스의 accepts_verified_join_rules
   화면      체크 해제 상태로 «정상으로» 보인다
   모델      값 «없음»
   검증기    invalid_type 「must be boolean」 + missing_field 「field is required」
   푸는 법   켰다 → 껐다.  그래야 false 가 써진다. 화면은 그걸 말해 주지 않는다
```

**`undefined` 와 `false` 가 «픽셀 단위로 같다».** 그래서 사람은 답했다고 믿고 저장하고,
거절을 보고 어디가 문제인지 못 찾는다.

### 🔴 부류로 판정한다 — 낱개로 가져가지 않는다

**`accepts_verified_join_rules` 는 «한 개»가 아니라 «부류의 대표»다.**

```
부류 = 스켈레톤에서 required 인 «불리언 잎» 전부
      → 부재와 false 가 화면에서 구별되지 않는 자리가 여기 말고 몇 개인가
```
**먼저 세고, 세운 부류 전체를 한 번에 맞춘다.** 하나만 고치면 옆에 같은 게 넷 더 있는 걸 못 본다
(소유자 상설: [[rule-the-class-not-the-instance]]).

### 방향 — 새 축을 만들지 않는다

`0e089c6d` 가 이미 **씨앗은 「종류를 코드에 박지 말고 스켈레톤 게이트를 읽는다」**로 서 있다.
같은 자리에 같은 방식으로 붙인다. 서버 `empty_value` 와 클라 `emptyOf` 는 **같은 규칙을 일부러
두 번 쓴 것**이라 **반드시 같이** 고친다.

### ⛔ 멈춤 조건 — «하나»다

**`accepts_verified_join_rules` 가 스켈레톤에서 `required: true` 가 «아니면» → 멈추고 보고.**
required 가 아니라면 답은 반대다 — 부재가 정상이고 «검증기»가 틀린 것이 되며, 그건 다른 라운드다.

⚠️ **되돌아올 수 있는 것:** 소유자가 예전에 「qualifier 안 넣을 건데 키가 기본으로 들어가서
에러남」으로 불편을 신고했다. **required 가 아닌 것까지 씨앗하면 그 불편이 돌아온다.**
「무조건 채우기」로 도망가지 말 것.

```

      둘 중 하나면 통과. 지금처럼 «조용히 false 로 보이는» 것만 아니면 된다
4  기존 라이브 설정: missing 0 · 거절 0 · 「4 layers · complete」 «유지»
```

숨기는 것과 말해 주는 것은 다르고, **둘 다 지금보다 낫다.**

⚠️ **1번을 빼지 말 것.** 오늘 아침 총괄이 도착했다는 사실이 이 라운드의 기준선이다.
