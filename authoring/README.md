# assyManager — 맵퍼·파서 «작성자» 문서

> **이 폴더는 제품 저장소의 «입구»입니다.** 저장소를 `clone`/`pull` 하면 «같이 옵니다».
> 맵퍼와 파서를 «쓰는» 사람에게 필요한 것만 들어 있고, 제품 코드는 한 줄도 없습니다.
> ⚰️ **[2026-09-13 판정 386] 종전엔 «별도 저장소»였습니다** — 「git 에 걸어 주면 pull 해 쓰지」가 「둘째 저장소를 만들어라」가 아니라 「폴더 «입구»에 두라」는 뜻이었습니다. 🔵 바뀐 것은 «사는 자리»뿐이고 내용은 그대로입니다.

## 누구를 위한 것인가

**저장소 없이 맵퍼·파서를 «쓰는» 운영자**입니다.

```
당신이 쓰는 것   맵퍼 함수 하나 · 파서 함수(또는 클래스) 하나
당신이 안 쓰는 것 제품 코드 · 배포 · 스키마 · 원장 내부
당신이 아는 것   자기 도메인 — 어느 파일이 무엇을 담고, 어느 컬럼이 무엇을 뜻하는지
```

🔴 **그래서 이 문서들은 「제품이 어떻게 도나」를 설명하지 않습니다.** 설명하는 것은
**「당신이 무엇을 적으면 제품이 받아 주나」** 하나입니다. 그 답이 두 줄 안에 안 나오면
그것은 당신 잘못이 아니라 제품의 결함이고, 그렇게 보고해 주십시오.

## 무엇이 있나

| 파일 | 무엇 | 정본 |
|---|---|---|
| [`MAPPING_GUIDE.md`](./MAPPING_GUIDE.md) | 체인 맵퍼 — `(df, db) -> df` 하나를 쓰고 `@mapper` 로 등록 | `server/mapper_sdk.py` |
| [`PARSER_GUIDE.md`](./PARSER_GUIDE.md) | 인제션 파서 — 함수형 하나 · 클래스형 하나, 둘 중 고르기 | `server/parsers/pipeline_base.py` |
| [`examples/`](./examples/) | 복사해 쓰는 파일 «다섯» — 맵퍼 셋 · 파서 둘 | 저장소에서 «이동»(사본 0) |

🔵 **`examples/` 는 «이동»이지 «사본»이 아닙니다** — 그 다섯은 저장소에서 «나갔고», 저장소에 남은
샘플 아홉은 여기 «없습니다». 남은 사유 둘: 시험이 바이트를 라이브 맵퍼와 대조하거나(판정 348),
운영자가 손으로 복사하는 shim 이라 「수정은 `git pull` 하나」가 존재 이유이거나(판정 349).
🔴 **같은 파일이 두 곳에 있으면 갈리고, 갈린 쪽이 조용합니다.** 그래서 가이드는 남은 것들을
«저장소 경로»로만 가리킵니다.

## ⚰️ SDK 버전 — «해결된» 걱정 (기록)

> 🔵 **[2026-09-13 판정 386] 이 절은 «별도 저장소»였을 때의 장치입니다.** 문서가 제품과 «같은 커밋»에 사는 지금은 필요 없습니다 — 아래 해시는 「그때 무엇을 재고 썼나」의 기록입니다.

```
SDK 버전 = 저장소 커밋 해시   e5c41d5c   (2026-09-13 07:59)
```
**이 줄이 이 디렉토리에서 제일 중요한 한 줄입니다.** 아래 모든 문장은 «그 커밋의» 파일을
열어 잰 것입니다. 제품이 갱신되면 이 해시를 올리고, **올리기 전에 그 커밋에 대고 다시 재십시오** —
해시만 올리면 이 문서는 「낡았다」에서 「거짓이다」로 바뀝니다.

판별식 한 줄: **인용한 줄 번호에 인용한 것이 «없으면» 그 문장은 낡았습니다.**

## 받는 법 — 따로 받을 것이 «없습니다»

제품 저장소를 `clone` 하거나 `pull` 하면 이 폴더가 «같이 옵니다». 갱신도 같습니다.
```bash
git pull
```
🔵 **그래서 「SDK 버전」 문제가 «사라졌습니다»** — 아래 §「SDK 버전」이 「이 문서가 어느 제품을
말하는가」를 답하려고 있었는데, 이제 **문서와 제품이 «같은 커밋»에 삽니다.** 해시를 손으로
맞출 일이 없고, 맞추다 틀릴 일도 없습니다.
⚠️ 그 절은 «기록»으로 남깁니다 — 무엇을 왜 걱정했는지가 이 폴더가 여기 있는 이유입니다.

## 정본 관계 — 어느 쪽이 «이깁니까»

```
제품 코드가 이깁니다.        이 문서는 «인용»이고, 인용은 근거가 아닙니다
문서가 코드와 다르면         코드가 맞고 문서가 틀린 것입니다 — 그것이 «발견»이니 보고해 주십시오
문서에만 있는 기능           없는 기능입니다. 이 디렉토리는 무엇도 «약속»하지 않습니다
```
🔴 저장소가 당신에게 약속하는 것은 **「SDK 진입점의 «이름»」 하나**입니다 — `@mapper` ·
`parse_file` · `match`/`process_dataframe`. 그 이름들이 바뀌면 제품이 «거절로» 말합니다.

## 저장소 쪽 입구

제품 저장소에는 이 디렉토리를 가리키는 한 장이 있습니다: `docs/guide/AUTHORING.md`.
그쪽에서 이쪽으로 오는 길이 «하나»이고, 이쪽에서 저쪽으로 갈 때는 «경로»로만 가리킵니다.
