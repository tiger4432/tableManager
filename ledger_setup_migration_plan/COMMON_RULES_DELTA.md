# 공통 규칙 — v2 COMMON_ARCHITECTURE_RULES에 더하는 것

v2의 규칙(스키마 독립성·Pack/Template·엔진 도메인 비의존·다중 기여·좌표/Frame·
기존 계약 보존)은 전부 유효하다. 이 폴더는 다음을 **추가**한다.

## A. 셋업 화면의 4금칙 (SETUP_PAIN_LOG P-01~04의 법제화)

1. **닫힌 목록을 자유 기입시키지 않는다.** 고를 수 있는 값(Pack·claim·role
   대상·열거형)은 반드시 선택지로, 선택지에는 한국어 뜻과 실물 예시가 붙는다.
2. **실물 없이 묻지 않는다.** 매핑 화면에는 항상 (a) 소스 실제 행과 distinct
   예시 (b) 나올 원자/문장 미리보기(진짜 mapper의 드라이런, 쓰기 0)가 함께 있다.
3. **결핍은 이름으로, 다음 행동은 버튼으로.** 거절문·빈 목록·0건에는 반드시
   원인과 다음 행동이 붙는다(거절 사다리 — 유일해→기본값→부분해→거절+행동).
4. **자동 추정은 추정으로 표시한다.** 시스템 초안 값은 근거(어느 컬럼·어느 값
   분포)와 함께 «추정» 표지를 달고, 사람 승인 전에 조용히 확정되지 않는다.

## B. 전환의 2금칙

5. **등가 증명 없는 전환 금지.** 소스 하나를 mapper로 넘길 때는 같은 행을
   legacy와 mapper 양쪽에 태워 원자 봉투를 디프한다. 차이 0 또는 «설명된 차이
   목록»만이 전환 승인 근거다.
6. **은퇴는 마지막에, 한꺼번에.** 병행 기간 중 legacy 경로 수정 금지(동결).
   은퇴는 7단계에서 소스 전체 등가 증명이 끝난 뒤 일괄로.

## C. 문구

화면 문구는 문구 다이어트 규율(내부 어휘 금지 — predicate·atom·subject_type
등은 고급 상세에만, 기본 화면은 「문장」「무엇에 대한 말」「언제」 같은 일상어)을
따른다. 시각은 분 단위까지.
