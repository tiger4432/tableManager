# 단계별 승인 게이트 문장

각 단계 완료 시 아래 문장에 실측을 채워 소유자 승인을 받는다. 승인 전 다음
단계 착수 금지 (예외: 소유자가 명시적으로 병행을 허가한 단계 쌍).

- **1단계**: 「전환표 N경로, lot_event 등가성 실측 — 차이 {0 | 목록 M건}.
  하니스 자기 테스트 초록. 2단계 Pack 목록 제안 첨부. 진행 승인?」
- **2단계**: 「Pack 7종 등재, validator 초록, 한국어 라벨 누락 0.
  판정 요청 {목록}. 진행 승인?」
- **3단계**: 「사전 라우트 가동, 셋업 화면 자유 기입 열거형 0 실측,
  능력 렌더 경로 {URL}. 진행 승인?」
- **4단계**: 「인터뷰→문장 판정→저장, 문서 없이 완주 기록 첨부.
  좁히지 못한 케이스 {목록}. 진행 승인?」
- **5단계**: 「현황판이 결핍 {예시}를 이름으로 말함, 백필 라우트 = CLI 등가.
  끝까지 이어짐(대조 API 후보 등장) 확인. 진행 승인?」
- **6단계**: 「현행 선언 첫 실측 — 어긋남 {N}건·유령 선언 {M}건 목록 첨부.
  진행 승인?」
- **7단계**: 「전 소스 등가 최종표 첨부, legacy 진입점 차단, 회귀 초록,
  되돌림 절차 문서화. 은퇴 승인?」
