## 📐 채우기 전에 ― 이 폼이 왜 이렇게 생겼나

세 가지가 빠지면 데이터를 만들어도 **④번을 증명하지 못한다.**

| | 왜 |
|---|---|
| **정체성 (§1)** | 분할·병합 추적은 「무엇이 같은 것인가」가 정해져야 성립한다. 여기가 틀리면 그래프가 **엉뚱한 개체를 지목**한다(실제 전례: `Wafer` label에 테이프 위치가 섞여 있던 #15) |
| **불완전성 (§6)** | **완벽한 데이터는 교정할 게 없다.** 이 시스템의 명제는 「불완전한 데이터를 사람이 최소 공수로 교정한다」이므로, 결측·모호·표기 혼재가 **의도적으로** 들어가야 실험이 성립한다 |
| **정답 (§7)** | 만들 때 정답을 같이 만들지 않으면 trace 결과가 맞는지 **채점할 방법이 없다**. 「그럴듯해 보인다」는 이 프로젝트에서 통과 기준이 아니다 |

⚠️ **모르면 빈칸으로 두고 「모름」이라 적어 주십시오.** 추측으로 채우면 그 추측이 데이터에 굳고, 나중에 진짜 데이터와 안 맞는데 **왜 안 맞는지 아무도 모르게** 됩니다.

**최소한 이건 알고 있어야 합니다:**
