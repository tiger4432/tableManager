## 0. 제품의 쓰임 — 모든 기저의 «주어»
```
문제가 난다(결함 · 수율 이탈)
 → 운영자가 대상을 «마킹»한다
 → 걸어서 닿는 하위 그래프(자재 · 공정 · 레시피 · 장비 · 검사)를 가져온다
 → «대조군»과 견줘 「무엇이 다른가」를 «순위»로 받는다
 → 필요하면 «행동»한다(홀드 · 이송 · 계획 · 확정)
그리고 이 전부가 «선언»으로 된다 — 임의 스키마에서 «두 줄»로 (완성의 정의, 2026-08-30)
```
지식 탐색과 운영은 «같은 기저»를 쓴다(소유자 문답 09-08 22:3x). 운영에서 느는 것은 «선언»이지 생성자가 아니다.

## 1. 완전성의 정의 (소유자, 2026-09-08 밤)
```
완전한 집합   축을 «먼저» 열거한다. 축마다 칸의 상태는 셋 중 하나:
              ① 선언 칸 있음(이름 · 자리)   ② 기본값이 덮음(«무엇으로» 덮이는지 값을 적는다)   ③ 없음 = 결함(동결 전 채운다)
닫힘          새 경우는 «기존 칸에 대응»돼야 한다. 대응이 안 되면 축이 빠진 것이지 칸 하나를 «더하는» 것이 아니다
온전히 덮음    기능이 필요한 «정보»를 담는다 — 칸의 «값의 정의역»까지(「수식어에 숫자만」 같은 제약이 없게).
              정의역은 «일곱 층 어디에나» 숨는다: 문법(setup_bundle) · 발행(emit) · 걷기 · 폼 · 값 채움 · DB CHECK · 클라 투영 → 칸마다 일곱 층 «다» 본다
봉투          «출처» 축은 새로 정의하지 않는다 — 아웃박스 봉투 다섯 칸이 «완전한 덮개»다. 새는 곳은 «봉투 없는 쓰기 길»과 «원장이 안 읽는 봉투 사건» 둘뿐
동결 관문     S-75 표 셋의 ③ 이 0
```

## 2. 기저 A — 세상의 표기 (원장이 «말할 수 있는» 것)

| 축 | 부축(칸 후보) | 오늘 (총괄 판단 — 응용이 «측정») |
|---|---|---|

## 3. 기저 B — 질의(걷기 스킴)
제약(상설): 「마킹은 질의의 주어」 · 「사용자가 고르는 축은 노드 타입 «하나», 술어는 follow 로만」 · 「부품은 거르지 않는다 — 거르는 것은 walk」 · 「라우트는 하나(`GET /api/ledger/subgraph`)」 · 「배관 낱말은 축이 될 수 없다」. 정본 소비자: `docs/architecture/WALK.md` · `task/CHART_DESIGN.md` §2-bis·§2-ter.

| 축 | 인자(칸 후보) | 오늘 |
|---|---|---|
| **B1 시작** | 마킹 = «이름 붙은» 노드 집합 × 부호, «여럿»(마킹1 · 마킹2 …) · 씨앗 해소(키 → 노드) · 정적 노드는 씨앗 아님(판정 08-29) | ① |
| **B2 길** | `follow`(술어 목록) · `direction` · `hops` 상한 · 인접 반전 규칙(같은 술어 incoming→outgoing 금지) · 정적→동적 정책 | 반전 규칙 «착지 미확인» |
| **B3 짐** | `collect` = 노드 타입(도메인 낱말) | ③ — 09-06 축째 지워짐. 닿는 것 «전부»를 싣는다 |
| **B4 그룹** | `group_by` = 길 위의 노드 타입 또는 속성(레시피 · 장비 · 스텝) | ③ — 클라가 한다 |
| **B5 집계** | `measure`(값 · 수식어 · 개수) · `aggregate`(수 · 비율 · 평균 · 분포) · `n` | ③ — 클라 |
| **B6 대조** | 모집단(마킹) × 그룹 표 · 차이(비 · 차) · 동률은 «답»(판정 08-23) · 절단이 대조를 기울이는지 «칸»으로 | ③ — 순위표가 클라 |
| **B7 시간** | as-of · 구간 · 세대 선택 | ③ — 항상 최신 + 충돌 수 |
| **B8 예산** | `node_limit` 등 상한 · 절단 «표시» | ① |
| **B9 출력** | 노드 `{id, type, keys, attributes}` «통째» · 엣지 `{predicate, qualifiers, direction}` · 절단 플래그 · 충돌 수 | ① (C-45 로 좁힘 6 제거) |
| **B10 거절** | 어떤 조합이 422 인가 — «이름 대어» | 부분 |

🔴 A2 의 카디널리티 ③ 은 B5 집계의 «중복 셈»을 구조적으로 못 막는다 — 표 둘은 «따로»가 아니다.
🔴 그룹 · 집계 · 대조가 «서버»여야 하는 이유: 클라가 하면 걷기가 «전부»를 실어 와야 하고, 10^8 에서는 예산 절단이 먼저 온다. 잘린 표로 센 대조는 «기울어진 답»이고 오류를 안 낸다.

## 4. 기저 C — 행동
```
생성자 «다섯»   트리거 · 선택 · 걷기 · 쓰기 · 선언          (번역은 생성자가 아니다 — 선언 × 쓰기의 «귀결»)
조립 규칙       행동 = 트리거 → 선택 → 걷기 → 쓰기,  선언은 «인자»,  봉투는 «모든» 행동에
지식 = 운영     운영이 늘리는 것은 선언(상태 표 · 허용 전이 표 · 술어 · 가드 = 걷기 술어 · 싱크 · 허용 역할)
직교           권한 = 액션 «위의» 선언 칸(허용 역할) · 승인 = 「트리거 = 승인 사건」
```
| 생성자 | 정의역(칸 후보) | 오늘 |
|---|---|---|
| **트리거** | 사람의 손짓 · 봉투 사건(C/E/D · 시스템 · 외부 응답) · 일정 · 걷기 결과의 조건 | 외부 응답 ③ 후보 |
| **선택** | 키 해소 → 마킹 · 걷기 결과 → 마킹 · 셀 집합 | ① |
| **걷기** | 표 B 그대로 | 표 B |
| **쓰기** | 종류(표 C/E/D · 셀 층 = 확정/cell_sources · 바깥 싱크 = 알림/명령) · 봉투 · **조건부**(「내가 본 상태 그대로면 써라」, 동시 사용자 10) · 역(되돌리기 = 봉투 tx_id) | 조건부 ③ 후보 · 벌크 쓰기(봉투 없음)는 «결함»(S-74 부류) |
| **선언** | 스키마 · 소스 · 플랜 템플릿(DOE 유형) · 규칙 · 이것을 «바꾸는» 것 = 메타 액션(봉투 SYSTEM_RELOAD 부류) | 세대 소비자 없음(S-57) |

## 6. 판별식 — S-75 가 «통과»하려면
```
① 지난 열흘의 발견 넷(S-52 속성 · S-50 결정 단위 · S-57 세대 · S-65-d 뷰 삭제)이 표의 «어느 칸»인지 — 넷 다 칸이 있어야 축이 맞다
② 오늘 있는 «모든» 라우트(`main.py` `@app.`) · 클라 손짓이 C 의 다섯으로 분해된다 — 안 되면 여섯째 생성자거나 결함
③ 다섯의 «임의 조합»이 허용되거나 «이름 대어» 거절된다 — 조용한 불가 0
④ 칸마다 값의 정의역을 «일곱 층» 나란히 — 문법이 받는데 CHECK 가 안 받으면 ③
⑤ 두 줄이 선다 — 「운영에서는 <이 표>에 <이 칸>을 적으면 됩니다」
⑥ 랏 홀드 · 해제 · 이송이 «선언 셋»만으로 분해된다
⑦ 표 셋의 ③ = 0 → 스키마 동결(09-12)
```
