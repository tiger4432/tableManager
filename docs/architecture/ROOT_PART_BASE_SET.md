# 근원 부품의 기본 셋 — 정본 (소유자 10-13 「이 표 정본으로 개발 끌고 가」)

모든 종류(산점도 · Table · 크로스 테이블 · Map · Sheet …)가 공통으로 가지는 칸. 근원 부품(client2/src/testbed/visual_part.js) **한 곳**이 묻고 계산하고, 종류는 그 결과로 그리기만 한다. 새 종류는 1–14 를 저절로 받는다.

| # | 기본 셋 | 무엇 |
|---|---|---|
| 1 | 제목 · 설명 | 부품 제목, 설명 한 줄 |
| 2 | 데이터 | 행 타입(Route) · 걷기 예산 |
| 3 | 받는 마킹 | 시작 마킹(Start from) · 데이터 제한(Limit by: 마킹 여럿, all/any, 아무것도 안 찍혔을 때) |
| 4 | 필터 | 시스템 필터(Filtering) · 부품 안 필터 |
| 5 | 내는 마킹 | 찍으면 쓰는 마킹(Marking) · 클릭 교체 / Ctrl 추가 / 사각형 · 사슬 전파 · Relations 마킹 층 |
| 6 | 행 단위 | Marker by — 노드 하나 / 허브 하나 / 값 기록 하나 |
| 7 | 색 | Color by — 칸 · 식 · 범주별 팔레트 · 색 저장 |
| 7-b | 모양 | Shape by — 점을 찍는 종류 전부(산점도 · Map 점 레이어 …): 근원이 행마다 모양을 정하고 점 그리는 종류가 씀 (소유자 「점을 찍는 부품들은 모두 SHAPE BY 도 있음」) |
| 8 | 범례 | 보이기 · 범주 목록 · 동그라미 누르면 팔레트 |
| 9 | 레이블 | 없음 / 찍힌 것만 / 전부 · 레이블 칸 |
| 10 | 툴팁 | 마우스를 올리면 보일 칸들 |
| 11 | 보이기 제한 | 값 기준 위 N / 아래 N |
| 12 | 트렐리스 | 칸 값으로 패널 나누기 |
| 13 | 바닥줄 | N of N rows · marked · columns · 출처 · 모름 수 |
| 14 | 선언 저장 | 위 전부가 선언 하나에, 다시 열면 같은 그림 |

종류마다 따로(기본 셋 아님): 산점도 X · Y · Size by / 크로스 테이블 행 · 열 축 · 칸 값 / Table 칸 목록 · 정렬 / Map 레이어 · 좌표 · 배경 다이맵 · 도구 상자.

순서(소유자 승인): 3 · 5 · 6 · 7 · 8 마무리 -> 10 툴팁 -> 9 레이블 -> 1 설명 -> 11 위 N -> 12 트렐리스.

판별식: 「이 칸을 종류가 직접 묻나」 — 묻는다면 근원으로 올린다. 1–14 를 묻는 자리가 근원 밖에 있으면 결함.

## 템플릿과 보이는 영역 (소유자 10-13 「이 근원부품 템플릿 위에 보이는 영역을 짓는 것으로 설계」)

근원 부품 = 템플릿: 제목줄 · 축 알약 트레이 자리 · 범례 · 팔레트 · 속성 패널 절(1–14) · 바닥줄 · 찍기 · 마킹 · 색 · 모양 · 레이블 · 툴팁 · 트렐리스 패널 나누기.
종류 = 그 템플릿 안의 «보이는 영역»(그림 영역) 하나만 짓는다: 받는 것은 근원이 계산한 행(색 · 모양 · 찍힘 · 레이블 포함), 내는 것은 그림과 «무엇을 눌렀나»(행 id · 허브)뿐.
판별식: 종류 파일에 범례 · 팔레트 · 제목 · 바닥줄 · 마킹 판단 · 색 계산이 있으면 그것은 템플릿으로 올린다.
