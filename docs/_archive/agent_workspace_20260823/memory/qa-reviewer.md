> **착수 규율 (사용자 지시 2026-07-27): 만들기 전에 이미 있는지 먼저 본다.**
> 문제를 만나면 **"이 시스템이 이미 이걸 하는 곳이 있나 · 이건 무엇과 구조적으로 같은가"**를 먼저 확인한다.
> 1차 참조는 `docs/architecture/PRIMITIVES.md`(기능→구현 카탈로그), 2차는 `docs/architecture/CODE_MAP.md`.
> 새로 만들 때는 **왜 기존 프리미티브를 재사용할 수 없는지 보고서에 명시**한다. 유사한 것이 있으면 **같은 이름·같은 형태**로 만든다.
> 실제 사례 — DOE 삭제 미반영은 `replace_map`(맵 Push가 쓰는 기존 연산)으로 해결되는데 클라에 차집합 계산 기계장치를 얹고 있었다.

> **언어 규약 (사용자 지시 2026-07-26): 에이전트가 산출하는 텍스트는 모두 영어로 쓴다.**
> 대상 — ① `agent_workspace/reports/**` 보고서 ② 코드에 새로 쓰거나 수정하는 **주석**
> ③ 서브에이전트에게 내리는 지시서·메시지 ④ 커밋 메시지.
> 대상 아님 — 사용자에게 직접 보이는 UI 문자열·토스트·에러 문구(한국어 유지), `docs/**` 프로젝트 문서, 기존 주석의 일괄 번역(건드리는 줄만 영어로).

- **함정**: 시스템 python으로 실행하면 psycopg2 부재 등으로 거짓 실패한다.
  **올바른 방법**: 모든 Python 실행은 conda `assy_manager` 필수 — `conda run -n assy_manager python <파일>`.
- **함정**: Windows 콘솔은 cp949라 한글/유니코드 출력에서 인코딩 에러가 난다.
  **올바른 방법**: `PYTHONIOENCODING=utf-8`을 앞에 붙여 실행.
- **함정**: `conda run`은 멀티라인 `python -c` 인라인 코드를 처리하지 못한다.
  **올바른 방법**: 코드를 스크립트 파일로 저장 후 파일 실행.
- **함정**: `/tmp`는 Windows python에서 보이지 않는다.
  **올바른 방법**: 세션 스크래치패드 디렉터리를 사용.

## qa-reviewer 전용

- **함정**: 파생 저장소(그래프 등) 검수에서 쓰기 경로만 보면 재구축(resync) 경로와의 산출 불일치를 놓친다 — UPSERT 키에 포함된 필드가 경로마다 다르게 산출되면 그대로 중복 레코드가 된다.
  **올바른 방법**: 증분 경로와 재구축 경로가 동일 입력에 대해 키 필드까지 동일한 레코드를 내는지 필드별로 대조.

- **함정**: "회귀 의혹"을 diff만 보고 판정하면 기존 결함과 신규 회귀를 혼동한다.
  **올바른 방법**: clean tree(stash)에서 재현 실증부터 — 변경 전에도 깨졌는지 먼저 확인.
- **함정**: 전수 Grep을 git 추적 파일에만 돌리면 사용자 영역의 호출부를 놓친다(shim 사각 사례).
  **올바른 방법**: gitignored 사용자 영역(`server/config/*.json`, `server/ingestion_workspace/`, `server/mappers/`)도 전수 Grep 대상에 포함.
