# 핀포인트 조사 UI 제안 — 모바일 열람용 사본 (2026-08-14)

> 임시 문서. 정본은 `docs/process/SCENARIO_CONSOLE_BRIEF.md` §0-ter(v2).
> 채팅 위젯이 폰에서 안 보여 여기 옮김. 확정되면 이 파일은 삭제.

## 1. 네 동작 → 화면 대응

| 동작 | 뜻 | 화면 |
|---|---|---|
| 1. 기대 위반 찾기 | 분모 있는 놀라움 목록 | **화면 ① 요약 표** (독립 화면) |
| 2. 공유 이력 펼치기 | 혈통·조건·계측을 같은 문법으로 | **화면 ② 참조뷰 — 이력 구역** |
| 3. 세 관문 판정 | 실재·상류·기전 통과 여부 | **화면 ② 참조뷰 — 순위표 구역** (심장) |
| 4. 질문 발급 | 설명 실패 → 수집·결측·DOE | **화면 ② 하단 액션 바 + 화면 ③ 질문 현황판** |

- 동작 2·3·4는 **한 화면(참조뷰)의 세 구역** — 순위표 줄을 의심하면 즉시 이력으로,
  설명이 안 서면 그 자리에서 발급. 화면을 나누면 왕복마다 컨텍스트를 잃음.
- **화면 ③ 질문 현황판**(신규 제안): 발급된 질문이 답을 기다리는 곳 = "수집 대기
  모드"의 홈. 랏 화면(①②)이 "묻는 쪽", ③은 "답하는 쪽". 답이 오면 닫히며 해당
  랏의 조사 이력에 반영.
- 지도 = 구조 뷰(§0-quater, 제작 중), 증거 = 기존 그래프 뷰(링크 병행, 임베드 금지).

## 2. 화면 ① 랏별 요약 표 (목업 내용)

상단: `[불량종류: 보이드 ▾] [기간: 최근 30일 ▾]` + 버킷 뱃지 `양산 118 · 특수평가 9 · 미상 3`

| ☑ | 랏 | 버킷 | 발생/분모 | 율 | 기저 대비 | 추이 |
|---|---|---|---|---|---|---|
| ☑ | CL-2601-006 | 양산 | 312 / 750 | 41.6% | **×6.9** | ▁▂▅▇█ |
| ☑ | CL-2601-014 | 양산 | 198 / 750 | 26.4% | ×4.4 | ▂▃▅▆▆ |
| ☐ | CL-2601-QE2 | 특수평가 | 85 / 250 | 34.0% | (제외) | ▄▄▄▄▄ |
| ☐ | CL-2601-002 | 양산 | 4 / 750 | ×0.1 | 0.5% | ▁▁▁▁▁ |
| ☐ | CL-2601-021 | 양산 | **미검사** | — | — | — |

- 정렬 기본 = 기저 대비 배율(놀라움) 순. 율은 **항상 분모 병기**.
- 특수평가는 **숨기지 않고 표시**, 배율 계산·대조군에서만 제외.
- **미검사 랏도 행으로** — 안 보인 건 양호가 아니라 모름 (랏 수준 3분할).
- 나가는 길: 행 클릭 → 그 랏 참조뷰 / 체크박스 여러 개 → `선택 N랏 대조 (vs 정상)`

## 3. 화면 ② 랏 참조뷰 (목업 내용)

헤더: `CL-2601-006` · `보이드 41.6% (×6.9)` · `분모 750 · sat` · `[그래프 뷰 ↗]`

### (좌) 혈통 — transferred 걷기
```
코어 W-A102 → DT-L88
DT-L88 → DT-L91        [DT 2회]
DT-L91 → 본딩 BD-233
⚠ 본딩→검사 대기 31h (정상 중앙값 6h)
```

### (우) 차이점 순위 — 이 랏 vs 정상 (설명력 순, 분모 병기)

| 부류 | 차이 | 수치 | 관문: 실재/상류/기전 |
|---|---|---|---|
| 범주 | 본딩 장비 EQP-07 | 88% vs 12% | ✓ / ✓ / ✓ |
| 경로 | DT 2회 경유 | 100% vs 31% | ✓ / ✓ / **?** ← DOE 후보 |
| 수치 | 본딩 압력 실측 낮음 | 분포 어긋남 | ✓ / ✓ / ✓ |
| 결측 | **MI 두께 기록 없음** | 0/312 측정 | (답이 아니라 구멍) |

- 관문 셋: **실재**(표본 대비 우연 아님 — Katz 하한) · **상류**(관측보다 앞선
  사건 — 시간 순서) · **기전**(M4 기전 그래프에 경로 선언됨 — 첫 실전 소비).
- 수치 줄 펼치면 분포 비교 미니차트. 기전 뱃지 클릭 → 기전 그래프의 그 경로.
- 결측 줄은 빨강 — 별도 부류, 무해 취급 금지.

### (하) 조사 이력 + 액션 바
- 조사 이력: 이 랏에 이미 발급된 질문(액션)과 그 답 — 같은 질문 두 번 사지 않기.
- 액션: `[수집 요청 발급]` `[결측 채우기]` (+DOE) — 순위표 상위가 근거로 자동
  첨부, 1클릭 + 확인 1회. 발급 즉시 원장에 앉고 이력에 나타남.

## 4. 확인 대기 결정 5 (§0-ter v2와 동일)

1. 행 단위 = **코어 랏**, 웨이퍼 드릴은 참조뷰 안에서.
2. 특수평가·이상 데이터 = 표시하되 구분(뱃지), 계산에서만 제외. **실데이터
   특수평가 구분자는 소유자 입력 대기.**
3. 대조군 기본 = 같은 기간 정상 양산 전부(선택 랏 제외). "불량 0 랏만"은 옵션.
4. 그래프 = 링크 병행(임베드 금지).
5. 구현 순서: 구조 뷰 → ① 요약 표 → ② 참조뷰 골격+범주 대조 → ③ 액션 바 →
   ④ 수치·경로 대조 + 세 관문(기전 그래프 첫 소비 — 진짜 신규).
