한 표

구성요소 항목별 종합 트렌드표 — 행 = 랏(생산 순서), 열 = 선언된 지표 전부

랏버킷검사칩 보이드 발생칩비보이드 칩당수보이드 평균면적박리 발생칩비본딩후 대기 h
조건부서식(항목축: 열마다 자기 기준): 주의 높음 심각 극단

선택기는 없다. 열 = 선언된 지표 전부(지표 선언이 늘면 열이 는다), 행 = 생산 순서라 표 자체가 시간적 놀라움이다. 조건부서식은 열(항목) 축으로 — 각 열이 자기 기저 분포 대비로 칠해져서, 훑기만 해도 이상한 칸이 뜬다. 미검사는 회색 「—」로 남는다(양호 아님). 랏 클릭 = 참조뷰, ☑ 마킹 = 아래 3축 맵.

트렌드 그래프

같은 표를 선으로 — 생산 순서 축, 지표별 소형 다중 차트

한 그래프에 겹치지 않고 지표마다 작은 차트 하나 — 단위가 달라 겹치면 서로를 가린다. 띠는 정상 범위(기저 ±). 장비 교체·레시피 rev 같은 원장 사건은 세로 마커로 얹는다(목업엔 EQP-07 투입 시점). 마킹은 전역이다(스팟파이어식): 표에서 ☑하면 그래프의 그 랏 점이 굵어지고 아래 맵이 뜬다 — 실물에선 그래프에서 드래그 선택해도 같은 마킹이 되고, 마킹 안 된 것은 숨기지 않고 흐리게만.

마킹 → 어디

마킹한 랏별 웨이퍼 맵 — 본딩축 · DT축 · 코어축

같은 불량 칩들을 transferred 걷기로 세 좌표계에 각각 투영. 어느 축에서 뭉치는지가 기전 힌트다 — 본딩축 뭉침=본딩 스테이지 기하, DT축 줄무늬=테이프 행, 코어축 링=웨이퍼 공정.

사용 플로우: 표를 훑는다(선택 없음) → 이상 칸의 랏을 몇 개 ☑ → 세 좌표계 맵으로 「어디」를 본다 → 랏 이름을 눌러 참조뷰의 「왜」(공유 이력·세 관문·액션)로. 칩 단위 놀라움은 맵이 본 화면(표는 랏 행).
피드백 요청: ① 열에 넣을 기본 지표 셋(지금: 보이드 비율·칩당수·면적, 박리 비율, 본딩후 대기) ② 조건부서식 기준 — 열의 중앙값 대비 배수로 할지, 관리도(σ)로 할지.
