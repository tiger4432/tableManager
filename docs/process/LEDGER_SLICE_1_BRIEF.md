## 0. 왜 이 슬라이스인가 — 전략 전환의 실행분

기반(테이블) 영역이 한 달째 스키마 결합에 막혀 있다. 이번 주 `dt_map` 키 이주가
기각된 사유가 그 층의 성질을 보여준다: 충돌 7,159건 · 미끼 컬럼(100% 빈 값, 타입
불일치) · **「파생」 테이블 안의 사람 손수정 16,555행**. `create_all`은 기존 테이블에
손대지 않고, 컬럼 하나가 config·맵퍼·enrichment·참조뷰·그리드로 연쇄한다.

**「기반 완성 → 응용」 순서를 버린다.** 테이블 층에는 「완성」이라는 상태가 없다.

> **새 전략: 기반은 동결하고, 응용 화면 하나가 원장에서 필요한 것만 끌어간다.**

가능한 근거는 하나다 — **원장 스키마(7필드)는 안 바뀐다.** 도메인이 자라면 어휘가
자라는데 어휘는 DDL이 아니라 데이터다. 응용은 스키마 변경을 기다릴 이유가 없는 땅에
선다.

### 동결 선언 (기반 층)

- 버그픽스만. **새 스키마 진화·새 파생 테이블·새 enrichment 체인 금지** — 응용이
  명시적으로 요구할 때만 예외
- 새 데이터 요구의 기본 답이 바뀐다: ~~컬럼/테이블 추가~~ → **어휘 항목 + 번역기 한 장**

## 1. 이 슬라이스의 정의 — 「끝」의 모양

**한 주 뒤 이것이 되면 끝이다:**

> 화면에 `(lot, slot)`을 넣으면 **혈통 사슬이 홉별 상태와 함께** 뜬다. 읽기 전용.
> 참조뷰로 같은 질문을 던지는 링크가 옆에 있다.

되지 않아도 되는 것: 보이드 5홉 완주 · 프레임 확정 편입 · 잔량 · 액션 · 물질화 ·
SEMI 앵커 확정 · 기존 테이블 이주.

## 2. 수직 한 줄만 만든다

```
화면 v0 (읽기)                    ← 클릭되는 물건. 이 슬라이스의 목적
   ↑
추적 질의 (질의 시점 해결, 물질화 없음)
   ↑
혈통 원자 (derived_from · slot_map · has_wafer · register)
   ↑
lot_event 번역기 (백필 + 라이브 구독)
   ↑
ledger_events (신규 테이블, 시간 파티션)
```

이 줄 밖의 것은 만들지 않는다. 투영 3종 일반 구축 금지, 어휘 확장 금지.

## 3. 작업 — 셋

### 3-1. `ledger_events` + lot_event 번역기 (백필)

**설계 §3의 봉투 7필드 그대로.** 필드를 줄이거나 늘리지 않는다 — 각 필드에 붙은
사고 근거는 설계 문서 §3 표에 있다.

- **신규 테이블**, 첫날부터 **시간 파티션**(나중에 붙이면 스키마 재작성이라는 것이
  본 세션에서 실측됨)
- `lot_event` 백필 = 일회성 번역 스크립트. **`lot_event`는 이미 이벤트 테이블**이라
  상태→이벤트 추론이 불필요하고 `event_time`이 `occurred_at`을 그대로 준다
- 번역 산출: SPLIT/MERGE 1건 → `derived_from` 1 + `slot_map` N(슬롯 쌍당 1) +
  `has_wafer` M(**채워진 wafer_id만** — 빈 값은 원자를 만들지 않는다) + 필요한
  `register`
- 🔴 **번역의 트랜잭션 단위 = 소스 이벤트 하나.** 분자(9원자)가 반쪽으로 착지하면
  안 된다. 상관 표지는 비의미 필드이므로 봉투가 보장하지 않는다 — 규칙으로 강제한다
- 🔴 **게이트**: 미선언 어휘·무신원·서명 위반은 **문 앞에서 거절하고 «센다»**.
  조용한 건너뛰기 금지
- `occurred_at`은 소스별 시각 컬럼을 config로 선언(`lot_event`→`event_time`).
  **도착 시각 대용 금지**

### 3-2. 추적 질의 (질의 시점 해결, 물질화 없음)

- 해결 서열은 설계 §6 그대로 — 계급 4 + 계급 내 3층 전순서. **해결기는 하나**
- Lot→Lot 재귀 CTE. 답은 **홉별 상태**를 실어 나른다:
  `resolved` / `candidate(rank,n)` / `unresolvable`
- **끊긴 자리가 이유와 함께 나와야 한다.** 빈 결과 금지 — 어느 홉에서 왜 끊겼는지가
  이 화면의 존재 이유다
- ⏸ 물질화는 **하지 않는다**. 필요 여부는 측정 레인(1000랏 증분 물질화)이 답한다

### 3-3. 화면 v0 (읽기 전용)

- 입력 `(lot, slot)` → 사슬 + 홉별 상태. **새 영역·모드·모달 금지**
- **「참조뷰로 보기」 링크 하나** — 정식 병행 캠페인 대신. 대조는 사후
- 클라 변경은 **빌드까지가 완료**다. dist 없으면 사용자에겐 없는 것

## 4. 관측성 — 탄생 조건 (나중에 붙이지 않는다)

번역기는 태어날 때부터:

- `note=` 박동에 **게이트 거절 계수** (무엇을 얼마나 거절 중인가)
- **뒤처짐 보고** — 커서 대 소스 헤드 격차. 기존 그래프 워커가 이걸 못 해서
  「뒤처지는 동안에도 신선해 보이는」 결함 판정을 받았다. 새 워커는 첫날부터 한다

- 브라우저에서 **실제로 클릭**해 사슬이 뜬다 (단위 테스트로 대체 불가)
