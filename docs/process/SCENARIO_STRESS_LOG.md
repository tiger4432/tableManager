# 시나리오 스트레스 로그 — 현행 스킴의 유니버셜리티 검증 (append-only)

> 제품 소유자 지시 (2026-08-14): 「1시간에 한 번씩 나처럼 실제 운영 시 발생할 수
> 있는 시나리오를 생각하고, 현재 스킴으로 유니버셜하게 처리 가능할지 기록하라.」
> 운영: 온톨로지 포크가 매시 1~3개 신규 시나리오를 세워 판정한다. 판정 어휘:
> **✅ 처리됨**(현행 선언·층이 소화, 근거 명시) / **🟡 문법은 있음**(설계는 덮되
> 착지 안 됨 — 선행 조건 명시) / **🔴 간극**(현행 스킴이 못 덮음 — 판정 필요,
> 소유자에게 보고). 반복 방지: 새 항목 작성 전에 본 로그 전체를 훑는다.
> 층위 참조: 이벤트(원장) · 골격(걷기) · 주석(집계) · 기대(선언) · 문맥(추출기) ·
> 의미(대조·관문) · 질문(액션).

## 2026-08-14 (소유자 직접 세운 시나리오들 — 형식의 기준)

### S-001. 같은 DOE 재발행
불량 조사 끝에 DOE를 발급하려는데, 몇 주 전 다른 엔지니어가 같은 요인 조합으로
이미 돌렸다면? → **✅ 처리됨** (당일 설계로): 재발행 가드 3층 — 요청 id 멱등(같은
클릭) / 조사 이력 칸(사람이 봄) / 의미적 서명 대조(종류×대상×요인 셋, 열린 동일
질문은 확인 단계에 링크로, 강행 시 reissue_of 강제, 닫힌 것은 답을 먼저 표시).
유사(부분 일치) DOE 소환까지 확장됨. 근거: SCENARIO_CONSOLE_BRIEF §0-ter
재발행 가드 블록 + 과거 유사 이벤트 블록 (dfcd115, 6ebd916).

### S-002. 공정을 실제로 했는데 이벤트가 전산에 안 들어옴
A 공정이 현장에서 돌았지만 기록이 없다 — 계측 프로필은 A군과 동일한데 경로
기록엔 A가 없다. → **🟡 문법은 있음**: 결측 셋째 부류(이벤트 결측)로 등재, 탐지
사다리 3단(희귀 서열 서명 / 층간 모순 / 기전 흔적 추론), 액션은 기록 확인 요청,
답은 지각 이벤트로 소급 번역. 대조 오염 방지가 점수 근거. **선행 조건**: 1단은
경로 요인 추출기 착지 시, 2단은 후순위, 3단은 기전 그래프 성숙 후. 근거: 48f1aab.

### S-003. 공정 순서가 랏마다 다름 (스왑·스킵·회차)
A→B인 랏과 B→A인 랏, X를 건너뛴 랏이 섞여 있다. → **✅ 처리됨** (구조로): route
마스터를 선언하지 않음 — 실제 순서는 원자 시각에서 읽고, 문맥(앞뒤·회차·간격)은
추출기의 파생 요인, 스킵은 대조가 잡음("정상군 94%는 지났는데"), 기대 선언은
조건부만. 근거: 22bb116.

### S-004. 유계 지표는 이상치를 심어도 색이 안 칠해짐
발생 칩 비율(상한 1.0)이 기저 61%일 때 배수 문턱 2.0을 수학적으로 못 넘음.
→ **✅ 처리됨** (정직 강등으로): 채점 불가를 코드 선언 + 화면에 문장으로(조용한
무색 금지 — 가짜 감쇄), 심기는 비유계 집계에. 유계용 척도(절대 증분·오즈비)는
자기 라운드 대기. 근거: R-2026-08-14-G.

### S-005. 장비·레시피 같은 슈퍼허브를 걷기가 통과하면 폭발
→ **✅ 처리됨** (구조로): 허브형은 개체가 아니라 payload 주석이라 통과 자체가
불가능, 허브형 질문은 집계 엔진이 답함(저차수는 걷고 고차수는 집계). 술어 선언에
traversable/방향 이관 완료, degree_cap은 집행 지점과 함께 자기 라운드. 근거:
R-2026-08-14-E, 0a86651 실측(관측 10만 원자 유입 0, 5.2ms).

### S-006. 측정 계획 선언이 들어오면 config가 감당 불가로 증식
→ **✅ 처리됨** (규율로): 파일 수와 선언 수 분리 — 새 파일 금지·기존 선언의
필드로, 구조 뷰 선언 지도가 관리 화면(미끼 선언 가지치기), 선언 신설 3문 게이트.
선행 빚: config 중복 통폐합 라운드(MI 묶음 선행). 근거: 9d76332.
