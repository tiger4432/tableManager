답은 지각 이벤트로 소급 번역. 대조 오염 방지가 점수 근거. **선행 조건**: 1단은
경로 요인 추출기 착지 시, 2단은 후순위, 3단은 기전 그래프 성숙 후. 근거: 48f1aab.

### S-007. DOE 수량 관리 — 실험 자재 예약과 이중 예약
3요인 12레그 DOE에 웨이퍼 300장이 필요하다. 어느 랏의 어느 웨이퍼가 가용한가
(맞는 제품·맞는 공정 단계·**다른 실험이 이미 안 잡은 것**)? 두 엔지니어가 같은
웨이퍼를 잡으면? → **🟡 문법은 있음**: 가용 수량 = transferred의 유입−유출
접기(잔량이 이미 걷기 부산물), 예약 = 액션 노드의 applies_to(발화라 원장에
남음), 이중 예약 = 재발행 가드의 서명 대조가 그대로 적용(같은 대상에 열린 예약
→ 확인 단계에 링크). **선행 조건**: 예약 액션 종류(reserve) 등재 + 가용 재고
질의 하나. **기존 프리미티브 주의**: 맵 도메인에 DOE 레그 계획 UI(transfer_plan
legend/DOE 구간)가 이미 있다 — 새로 짓지 말고 그 계획이 액션 발화로 원장에
앉게 잇는 것이 맞는 방향.

### S-008. 보고서 작성 — "그때의 답"이 필요하다
주간 회의 보고서에 "보이드 41.6% (×6.9)"를 인용했는데, 발표 시점엔 증강·번역으로
숫자가 바뀌어 있다. → **🟡 문법은 있음**: 질문 하나=URL 하나 원칙 덕에 보고서 =
질문 URL들의 목록이고, 원장이 append-only라 **as-of(시점) 읽기가 구조적으로
가능** — 그 시각 이전 원자만으로 같은 질문을 답하면 된다. **선행 조건**: 질문
API들에 as-of 파라미터(현재 없음). 이게 붙으면 보고서는 "질문 + 시각"의 목록이
되어 영원히 재현 가능하고, "지금 답과 그때 답의 차이"까지 한 클릭. 소스 레이어만
읽는 축(현행 대조)은 소스가 상태 저장이라 as-of 불가 — **원장 이관(모든 요소가
걷기로)의 실용적 이유 하나 추가**.

### S-009. DOE 결과 회수 — 실험이 끝나면 지식은 어디로 가나
DOE 12레그가 돌아왔다. 레그 간 비교와, "압력→보이드 방향 확인됨"이라는 결론은
어디에 앉나? → **🟡 문법은 있음**: 레그 간 비교 = 기존 케이스-컨트롤 엔진
그대로(레그 = 노출 서명 코호트 — 코호트 뒤집기 문법 재사용, 새 분석 0). 결론의
자리 = **기전 그래프의 근거 승급**: 엣지의 evidence가 declared → doe_confirmed
(DOE 액션 참조 포함)로 올라감 — 지식 환류가 파일 수정이 아니라 근거 등급 변화로
기록된다. **선행 조건**: 기전 엣지 evidence 필드의 등급 어휘(declared/
doe_confirmed/refuted) + DOE 결과→엣지 연결 판정. 놀라움 감쇄기 언어로: DOE의
답이 기전을 승급시키면 같은 놀라움이 다음엔 1관문에서 설명된다 — 고리의 완성형.
