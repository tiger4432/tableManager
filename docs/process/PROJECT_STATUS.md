> 🔴 **후속 사고 — 내 즉효 조치가 오토업데이트를 깼다 (2026-07-30).** `NO_PROXY`를 런처 셸에 넣게 했는데, 런처가 `os.environ.copy()`로 자식을 만들므로 **오토업데이트가 실행하는 사용자 스크립트 전부**가 물려받았다. 그 스크립트들은 `urllib.request.urlopen`으로 사내 인트라넷 API를 치고 프록시 경유가 전제라 **403**이 났다. 사용자 확인: 「프록시 맞아, 본컴에서 따로 실행하면 잘됨」.

> 🔴 **기구 (실측):** `urllib.request.getproxies()`는 `getproxies_environment() or getproxies_registry()`다. **`or`**. 그리고 `getproxies_environment()`는 이름이 `_proxy`로 끝나는 환경변수를 전부 걷는데 **`no_proxy`도 `_proxy`로 끝난다** → `NO_PROXY` 하나만 넣어도 dict가 비지 않아 **레지스트리가 통째로 무시**되고, `http`/`https` 항목이 없으니 **전 요청이 직결**로 나간다. 측정: `NO_PROXY 없음 → {}` / `NO_PROXY 설정 → {'no': ...}`.
