## 1. 살아남은 것 — 원칙 다섯, 지금은 «상설»입니다

이 다섯은 콘솔이 아니라 **응답 계약과 화면 전반의 규율**로 이관됐습니다.
화면이 남의 것이 되어도 「조용히 거짓말하지 않기」는 API 가 지켜야 하기 때문입니다.

```
① 분모 없는 비율 금지      모든 비율은 «분모와 함께». 분모가 없으면 「대조 불가」를 내용으로 렌더한다
② 「없다」를 뭉개지 않기    안 골랐다 · 그런 종류가 없다 · 서버가 답 못 한다 · 걸었는데 비었다 · «잘렸다»
                        평면 표에서 이 다섯을 하나로 접으면 그것이 조용한 거짓말이다
③ 문구 다이어트            기호·짧은 영어·명사형. 전체 문장은 «확정 한 곳»에만
④ 산문 파싱 금지           `state` · `basis` · 발화자 배지는 «구조화 필드»로 싣는다. 문장을 파싱시키지 않는다
⑤ 웨이퍼 단위              🔴 소유자 상설: 「그냥 랏이란 단위를 잊으라 그래」 — 랏은 «값»이고 단위는 웨이퍼다
```

🔴 **①은 일반화된 채로 살아 있습니다.** 보이드는 예시 하나일 뿐이고, 같은 분석이
`observed` 의 모든 `finding_kind` 에 적용됩니다. **코드에 기본값 아닌
`finding_kind == "void"` 분기가 보이면 그 일반화가 소실된 것입니다.**

## 3. 착지하지 «않은» 것 — 실측 2026-08-27

라우트 표에 대고 세었습니다. 지시서가 이름을 댄 것 중 **다섯이 없습니다.**

```
GET  /api/ledger/compare     없음     레시피 rev 대 rev 의 param diff + 결과율
GET  /api/ledger/worklist    없음     모델이 「먼저 보라」는 순서
POST /api/ledger/actions     없음     🔴 웹 프로세스의 «첫 원장 쓰기»가 될 축이었습니다. 안 지어졌습니다
GET  /api/ledger/journey     없음     두 주어의 공정 구간 대조
GET  /api/ledger/coverage    없음     원장 준비 상태
```

그리고 **콘솔 화면 자체가 없습니다** — 지시서가 「`ledger.html` 의 성장」이라고 적은 그 페이지는
삭제됐습니다. 이 문서가 그린 2계층 뷰·액션 버튼·비교 뷰·예방 워크리스트는 «지어진 적이 없습니다».

⚠️ **이것은 대기열이 아닙니다.** 위 다섯을 지금 만들라는 지시로 읽지 마십시오 —
필요해지는 날의 판정은 소유자·총괄 몫이고, 여기 적힌 것은 「없다」는 사실뿐입니다.

## 4. 그 대신 지어진 것 — R&D 진단 보드

화면은 콘솔이 아니라 **부품의 격자**로 지어졌습니다(`client2/rnd-board.html` · `src/rnd_board/`).
설계가 다른 지점이 셋입니다:

```
콘솔 안                     지금
한 화면이 한 동선을 품는다   ->  부품이 «조립식»이다. 화면은 부품을 격자에 앉힌 결과다
화면이 데이터를 가져온다     ->  마킹이 walk 의 «시작점»이고, 차트는 서브그래프를 «보는 창»이다
질문마다 라우트를 판다       ->  같은 walk, 다른 «선언» — { start = 읽을 마킹, collect = 무엇을 걷나 }
```

🔴 **그래서 「라우트를 하나 더」가 이 설계에서는 «어긴 것»입니다.** 화면이 하나 늘 때
늘어야 하는 것은 선언이지 갈래가 아닙니다.

상세: [frontend §4](../architecture/frontend.md) · UI 상설 규칙은 `CLAUDE.md`.


실행 지시가 아닙니다.
