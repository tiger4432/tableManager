# 2026-07-19 19:20:00 - 격자 맵 에디터 원외 칩 표기 제한 하에서 전 영역 그리드 격자 선(Grid Lines) 노출 구현

## 1. 개요 및 동기
* **요구사항**: 
  * 원 바깥에 위치하여 사용 및 조작이 불가능한 격자 영역에 대해, 셀 좌표 글자와 채우기 배경색은 완벽하게 은폐(차단)하더라도 **그리드 격자 선 자체는 캔버스 전역(사각형 전체)에 걸쳐 균일하게 노출**되기를 바라는 추가 의견이 있었습니다.
* **해결 방안**: 
  * 원 밖 영역 셀에 적용되어 있던 `visibility: hidden` 스타일을 전면 폐기했습니다.
  * 대신, 해당 셀들이 공간을 점유하며 테두리는 온전히 그리도록 `border` 및 `background` 설정을 변경하되, 셀 내의 글자색(`color: transparent`) 및 상호작용(`pointer-events: none`)을 완전히 차단하는 방어적 스타일링으로 전환했습니다.

---

## 2. 주요 구현 사항

### A. 미포함 영역 셀의 선택적 은폐 CSS 수정 (`client2/src/style.css`)
```css
/* 웨이퍼 원판 영역 밖의 셀 표기 차단 (그리드 선은 표시) */
.grid-cell.cell-outside-wafer {
  background: rgba(10, 15, 26, 0.3) !important; /* 매우 어두운 투명 배경 */
  color: transparent !important; /* 글자 숨김 */
  pointer-events: none !important; /* 클릭 방지 */
  box-shadow: none !important;
  border: 1px solid rgba(255, 255, 255, 0.04) !important; /* 미세한 그리드 선 표출 */
}
```

## 3. 아키텍처 영향 보고
* **모던 격자 가독성 제공**: 캔버스 전체에 바둑판 무늬의 어두운 투명 격자 선이 질서 정연하게 렌더링되면서도 원 내부 영역만 녹색 테두리와 셀 텍스트가 활성화되어 돌출되므로, 사용자는 맵 에디터가 전체 2D 행/열 격자 시스템 하에서 동작하고 있음을 직관적으로 알 수 있습니다.
* **정적 컴파일 완료**: Vite를 통한 프로덕션 빌드가 성공적으로 갱신 마감되었습니다.
