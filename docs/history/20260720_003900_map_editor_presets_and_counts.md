# 2026-07-20 00:39:00 - 맵 에디터 내 제품군 프리셋 및 범례값별 칩 개수(Count) 실시간 표출 기능 추가

## 1. 개요 및 설계 사상
* **목적**:
  * 맵 에디터(Map Editor) 사용자가 특정 제품군(Product)에 맞게 그리드 크기(Width, Height), 시작 좌표 오프셋(X/Y Start), 회전각, 앞/뒷면 옵션을 빠르게 사전 세팅할 수 있도록 **Product Preset** 설정 기능을 제공합니다.
  * 또한, 마우스 페인팅(Paint/Erase/Fill/Clear) 시 현재 맵 위에서 범례 값별(예: GOOD, FAIL, E1, E2 등)로 칠해진 **실시간 칩 개수(Counts)**를 Legend 목록 우측에 바로 표출하여, 웨이퍼 에지 등 수율 분류 품질을 한눈에 검증할 수 있도록 지원합니다.

---

## 2. 세부 구현 사항

### A. 제품군 프리셋(Product Presets) 기능 구현
* **내장 프리셋 및 커스텀 프리셋**:
  * 4가지 빌트인 프리셋(Standard 10x10, Product A 30x30, Product B 50x50, Product C 60x60)을 탑재했습니다.
  * 사용자가 원하는 임의의 그리드 규격을 생성한 뒤 `💾 Save Current` 단추를 눌러 사용자 정의 프리셋 이름으로 등록할 수 있는 기능을 추가했습니다. 커스텀 프리셋은 `localStorage`에 자동 보존됩니다.
* **UI 연동**:
  * 프리셋을 선택하면 그리드 입력 필드들이 자동 업데이트되며 회전 단추(`.btn-rot`) 활성화 상태 및 앞/뒷면 라디오 선택상태 또한 동시 갱신되어, 복잡한 메타데이터가 단 한 번의 클릭으로 초기 세팅됩니다.

### B. 범례별 칩 개수(Value Count Column) 실시간 집계
* **범례 테이블 컬럼 확장**:
  * Legend 테이블 내에 **Count** 열을 추가하여 실시간으로 값이 매핑된 칩 개수를 표시합니다.
* **실시간 상태 동기화 (`updateLegendCounts`)**:
  * 맵 드로잉(`renderGridCanvas`), 마우스 드래그 박스 페인팅 종료(`mouseup`), 격자 전체 채우기(`fillGrid`) 및 비우기(`clearGrid`) 등 내부 `gridData` 상태가 갱신되는 매 시점마다 `updateLegendCounts()`가 자동으로 트리거되어 숫자가 실시간 반영됩니다.
  * 칩 개수가 1개 이상인 활성 범례 행의 숫자는 청색(`var(--color-primary)`)으로 강조 표시됩니다.
