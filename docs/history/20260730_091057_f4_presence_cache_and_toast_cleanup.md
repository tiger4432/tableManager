## 현상 — 틀린 답이 아니라 물음의 부재

dt 맵을 저장하고 본딩 맵을 다시 불러오면 롤업이 계속 `MAP X`라고 말했고, `↻ 가용`을 누를 때까지 그랬다. 네트워크 로그를 보니 **존재 조회 요청이 아예 나가지 않았다.** 이건 틀린 답과 다른 계급의 결함이다 — **화면이 묻지 않고 있었다.** 핵심가치 #3(실시간 전파) 위반이고, 여기서 가장 아프게 걸린다: 시스템이 **운영자가 방금 자기 손으로 만든 것**을 부인하고 있었다(서버에 261행이 있는데 X).

독립적인 관문 **둘**이 직렬로 있었고, 각각 혼자서도 증상을 만든다.

## 원인 ① 정체 변경으로 트리거를 걸면 "같은 것을 다시 읽는다"가 구조적으로 빠진다

`notifyMapContext`가 pane ② 갱신을 `changed`(테이블·mapKey·depth가 다름)에 걸어 놨다. **같은 맵을 다시 여는 것은 정체 변경이 아니므로** 갱신이 아예 돌지 않았다 — 실측: 재로드는 요청 3건(셀·규격·registry)을 내면서 **존재 조회 0건**.

물음이 하나가 아니라 둘이었다:

- 정체가 바뀌었나(`changed`) → 화면을 재바인딩하는 것들(flash 초기화)
- **방금 서버를 읽었나**(`serverRead`) → 서버 상태에서 **파생된** 것들

재로드는 두 번째만 참으로 만들고, 그 틈에 결함이 살았다.

```js
if (changed || info.serverRead) {
  if (S.stagesStatus === 'error') stagesPromise = fetchStages();
  refreshMaterials();
  ...
}
```

## 원인 ② 캐시가 다시 물을 수도 없었다

`probeMaterialMap`이 `S.matMapState.has(ck)`로 first-write-wins였다. `has()`는 `false`("맵 없음")와 `null`("확인 못 함")을 **정해진 답으로 취급한다** — 그런데 그 둘이 **정확히 운영자가 행동으로 옮기는 답**이고, 그래서 정확히 가장 낡기 쉬운 답이다.

규칙은 발명하지 않았다. **같은 파일의 형제 캐시 `getPoolSummary`가 이미 긍정 상태에서만 캐시하고 `error`면 재조회한다.** 그것을 들어 올렸다.

```js
function matMapCacheHit(ck) {
  return S.matMapState.get(ck) === true;
}
```

- `true` → 다시 묻지 않는다. 이 흐름에서 맵을 지우는 것이 없고, 긍정은 사용자를 행동하게 만들지 않으므로 낡아도 해가 없다.
- `false` → 다시 묻는다. 사용자가 그새 무효화했을 수 있는 **유일한** 답이다.
- `null` → 다시 묻는다. "확인 못 함"을 캐시하면 **장애가 사실로 굳는다.**

증거 지점은 로드 성공과 Push 성공 둘이다. Push 쪽은 `validDieListCache.delete`·`serverCellKeys` 갱신에서 **두 줄 떨어진 자리**이고, 그 둘은 이미 정확히 같은 증거로 무효화한다 — **존재 캐시는 아무도 그 증거에 배선하지 않은 세 번째 캐시였다.**

**폴링을 넣지 않았다.** 폴링은 "결국은 일치한다"를 사고 "묻지 않는다"를 그대로 남긴다. depth > 0에서는 추가 요청 0건이다. `force`는 `↻ 가용` 전용으로 남았다.

두 절반을 **각각 되돌려 넣어 둘 다 증상을 재현**했다 — 어느 쪽도 장식이 아니다.

## 토스트 정리 — 규칙 한 줄과 그 규칙에 맞선 유지

호출 지점 62→53, **깨끗한 경로에서 발화 13건 감소**. 전부 `map_editor.js`(51→42). `transfer_plan.js`는 11 유지 — 열한 건이 전부 거부·실패이거나, 「버튼이 죽은 것처럼 읽힌다」는 사용자 신고로 생긴 `↻ 가용` 응답이다.

**적용 규칙: 성공 토스트는 그 효과가 이미 화면에 없을 때만 살아남는다.** 9건이 탈락했고, 4건은 정보 있는 절반만 남겨 조건부가 됐다 — 칠하기는 **0칸일 때만** 경고, 붙여넣기는 저장불가 셀이 있을 때만, 오버레이는 **절단**일 때만.
