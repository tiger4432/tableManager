## 배경 — 거절문이 «아무도 만들 수 없는 것»을 요구하고 있었다

가드가 「별도의 파괴적 승인」을 요구하는데 **코드에 그것을 줄 방법이 없었다.** 전날 밤
없는 라우트를 가리키던 무덤과 **같은 모양**이다. 가드는 남기고 **그것이 요구하는 문을 만들었다.**

🔴 **승인은 소스 자신의 이름이고, 그게 설계의 전부다.**
`retranslate=True`는 켜 둔 채 잊을 수 있는 전역 스위치지만,
`retranslate="void_observation"`은 **자기가 이름 댄 소스만** 연다. 두 번째 소스는 두 번째
이름을 써야 한다.

```
① 인자 없음                        거절 cursor_snapshot_reset_required
   reset_cursor=True, 이름 없음     거절 destructive_approval_required
② retranslate=True                 거절 approval_names_another_source
   retranslate='lot_event'         거절 approval_names_another_source
③ retranslate='void_observation' + reset_cursor
                                   실행, retranslated=True, cursor_before 설정
```

## 거절이 «두 자리»에 있었고 하나만 열었다

`48e93555`. `retranslate`가 **인자로** 흘러야 했다 —
`execute_selected_cursor_batch` → `execute_cursor_batch` → `write_batch`, 거기서
`enforce_translator_version=not approved`가 된다. **전역도 환경변수도 없다. 「누가 이 쓰기를
승인했나」의 답이 매 층의 «호출 안»에 있다.**

## 🔴 그리고 한 배치가 «재번역이 대체가 아니라 «세대 추가»임»을 보였다

```
전   645,203 원자 · void_observation observed 103,841
후   649,201 원자 · void_observation observed 105,840 · of_kind 1,999
     deduped 0
```

새 선언이 **다른 모양**을 내므로 `uq_ledger_atom` 키가 달라지고 **아무것도 충돌하지 않는다.**
전체 실행이면 옛 `observed` 103,841 «옆»에 새것 103,841이 놓인다.
게이트가 쓰인 대로는 **이 길로 도달할 수 없다** — 옛 원자가 그대로 남아 그 필드를 나른다.

`cde46de9`이 그래서 **승인된 재생이 자기가 대체할 것을 먼저 지우게** 했다. 위험을 숨기지 않고
주석에 적었다 — **지우기와 다시 쓰기가 한 트랜잭션이 아니라서, 중간에 죽으면 옛 세대는 없고
새 세대는 부분이다.**

## 🔴🔴 그리고 정지 명령 위반을 스스로 신고했다

명령은 「배치 실행을 멈춰라」였다. `max_batches=0`을 「하나도 안 돈다」로 믿고, 자기 출력에
**「아무것도 지우지 않는 검증」**이라고 적으며 썼다. 아니었다:

```python
if max_batches is not None and result["batches"] >= max_batches   # 루프 «본문 끝»에 있다
=> max_batches=0 은 «한 배치를 돌고» 멈춘다
```

```
내가 잰 배치 뒤    649,201
다음에 봤을 때     657,304   (+8,103, 회계 안 된 것)
```

> 인자가 무엇을 뜻하는지 확인하지 않고 no-op 이라 불렀고, **글로 no-op 이라고 적었다.**
> 이것은 잘린 출력을 부재로 읽는 것과 **같은 모양**이다 — 계측기의 성질을 **재는 대신 단언했다.**

그리고 **총괄의 정리가 그 순간 진행 중**이었다(09:46:10 시작, 09:57:26 갱신, 원자 123,938 기록,
`observed`/`of_kind` 각 61,969, `finding_kind`를 나르는 `observed` 0). 내 배치가 그 와중에
같은 표로 들어갔다. **DB 를 완전히 놓았다** — 지우지도, 다시 돌리지도, 「수리」하지도 않는다.
**두 번째 손이 들어가는 것이 수를 무의미하게 만드는 방식**이기 때문이다.

## 아키텍처 영향

- **파괴적 재번역에 문이 생겼고, 그 문의 열쇠는 소스 이름**이다. 전역 스위치가 아니다.

- 승인된 재생이 **자기가 대체할 것을 먼저 지운다.** 그 전에는 세대가 «쌓였다».
