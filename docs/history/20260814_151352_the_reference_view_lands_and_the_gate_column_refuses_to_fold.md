# The reference view lands, and the gate column refuses to fold

**Date:** 2026-08-14 15:13 · **Domain:** Client (원장 콘솔 — 참조뷰 R2) · **Status:** 착지 — `4652777`

---

## 배경

브리프 R2: `ledger.html?view=lot` — 기존 페이지의 다섯째 뷰. 패널 다섯이 모든
경로에서 선다 — 부재를 말하기 위해 존재하는 패널까지(「발급된 질문 없음」이
정상인 조사 이력 칸).

## 그래프 링크가 발견이다

포크는 레인에게 「뷰어는 파이프라인 은퇴에서 살아남는다」고 브리핑했고, 레인은
믿는 대신 측정했다: 그래프 라우트 다섯 전부 `raise _graph_branch_retired()`로
열리고 `graph.html`은 그중 셋을 부른다 — **실패만 할 수 있는 화면**이다. 살아
남는 뷰어는 원장 자신의 생성형 구조 뷰라서, 헤더는 `?view=structure`로 링크하고
「구조 뷰」라 말한다 — 「그래프 뷰」라 쓰면 독자를 죽은 화면으로 보낸다.
`graph.html`이 이 페이지 어디에도 안 나옴을 테스트가 단언한다. (판정문 정정
`c7ad95d`가 이 실측에서 나왔다.)

## 미판정은 미통과가 아니다

관문 열은 세 상태를 접기를 거부한다: 단어·글리프·색·**테두리 스타일**까지 다
다르고, 기본값은 «미판정»이다.

```js
// 기본값을 fail로 뒤집는 변이 → 단언 9개가 빨개진다
```

범례 분리는 선언이 아니라 부하로 증명됐다: 행은 `data-gate-state`, 범례는
`data-legend-gate` — 행을 전부 지우면 관문 단언은 0으로 빨개지되 범례는 여전히
«미판정»을 말하며 살아남고, 범례가 행의 속성을 공유하게 만들면 즉시 빨개졌다.

## 픽스처가 자기 전제를 지키게 됐다

혈통 홉의 노드 신원은 `{keys:{lot}}`이지 `{id}`가 아니다 — `{id}`로 시작한 첫
픽스처는 세 홉 전부 unresolvable이었고, 그 위에서 「해소된 두 홉은 basis만
다르다」 단언이 **한 번도 해소된 적 없는 쌍 위에서 초록**일 뻔했다. 픽스처가
이제 자기가 세우려는 전제를 가드한다.

클라 측 순위 매김은 **일부러 없고 그것이 단언돼 있다** — R3의 사전식 순위가 곧
착지하는데 클라의 둘째 순위 규칙은 조용히 경쟁하게 된다.

## 그때 남아 있던 것

- 검증: 단언 72, 코드 변이 3건 빨강 확인 후 원복, build exit 0.
- **dist는 이 커밋에 없다** — 리빌드가 병렬 레인의 미커밋 그래프 은퇴 소스를
  번들했고 그 레인이 아직 도는 중이라, dist는 그쪽과 함께 나간다. 소스에 있고
  dist에 없는 상태가 이 시점의 사실이다.
