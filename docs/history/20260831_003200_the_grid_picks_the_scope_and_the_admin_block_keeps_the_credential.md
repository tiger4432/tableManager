## 무엇이 필요했나

범위 재번역이 서버에 착지했으니(→ `20260830_221600_...`) **운영자가 그 범위를 «고르는» 자리**가
있어야 했다. 행은 그리드에 있고 **토큰은 어드민 페이지에 있다.** 그 둘이 다른 페이지다.

## ① 클라가 «그릴 것이 없어서» 막혀 있었다 — 라우트 하나가 아니라 «절» 하나

`1570c5fe`. 클라 레인이 정확히 이 한 절에 막혀 있어서 **큐를 앞질러** 착지했다.
새 라우트가 아니라 **이미 있는 라우트에 절 하나**다:

```
GET /api/ledger/declaration
  sources: [{source, relation, emits, scope_columns}]   <- 라이브 선언에서 «열다섯»
```

🔴 `scope_columns` 는 **컴파일된 플랜에서** 뽑은 `base_select_columns` 다 — 원시 선언이 아니라.
그것이 **범위 판독기가 이미 대조해 거절하는 바로 그 목록**이기 때문이다. 다른 데서 선택지를
만든 화면은 **서버가 거절할 컬럼을 내놓게 되고, 운영자는 «올바른 거절»을 «고장 난 버튼»으로
읽는다.** 시험은 그 이음매를 **양쪽에서** 단언한다 — 내놓은 컬럼은 전부 `_scope_predicate` 가
받고, 목록 밖의 것은 이름으로 거절된다. 응답을 리터럴과 비교하지 않는다(그 «사본»이
단언이 막으려는 것이다).

**setup 이 컴파일 안 되면 키를 «생략»한다. 비우지 않는다.**

```
이 필드가 먹이는 라벨은 «셋» 중 하나를 말한다
   원장 소스다 · 소스가 아니다 · «알아낼 수 없었다»
빈 목록은 뒤의 «둘을 뭉갠다» -> 아무도 물어보지 못했을 뿐인데 「당신 표는 소스가 아니다」가 된다
```
카탈로그의 나머지는 그대로 답한다 — 컴파일 실패가 `entities` 나 `predicates` 를
거짓으로 만들지는 않기 때문이다. 단언 둘 다 깨웠다: 내놓는 목록에서 컬럼 하나를 깎으면
이음매 시험이, 실패 시 `[]` 를 답하면 생략 시험이 빨개진다.

## ② 라벨이 «세 문장»을 말한다 — 그리고 셋째가 요점이다

`e7b84e9b`. 부품은 자기 div 를 갖고 모듈 수준 상태가 없으며 **라우트를 모른다**(합성 루트가
로더 함수 하나를 주입한다).

```
선언된 표      자기 소스 이름과 emit 하는 술어들을 말한다
선언 안 된 표   그렇다고 말한다
🔴 선언을 «못 읽었다»   그것은 «다른 사실»이다
넷째 상태      표를 안 고른 상태 -> 주어가 없으므로 «아무 주장도 안 한다»
```

셋을 **각각 살아 있는 상태로** 만들었고, 셋째는 **시뮬레이션이 아니라 라우트를 죽여서**
만들었다 — 격리 오리진이 `/api/ledger/declaration` «만» 503 으로 답하고 `/tables` 는 200 이다.
판별 케이스는 **죽은 라우트 밑의 선언 안 된 표**다: 「못 읽음」으로 읽혀야 하고
「소스 아님」이면 안 된다. **셋 중 하나만 만들어서는 볼 수 없는 뭉개짐**이다.

`emits` 는 **거르지 않고** 통과시킨다 — 거르면 화면이 선언보다 «적게» 말하게 되고
**내일의 술어가 조용히 떨어진다.**

🔴 **하니스에서 변이 둘이 처음에 탈출했고, 둘 다 «코드가 아니라 내 단언»이었다.**

```
「이름이 선언에서 온다」  -> «텍스트 전체»에서 쟀다. emits 줄만으로도 만족된다
                          -> 이름 요소가 relation 을 찍는 동안 «초록»이었다
「두 인스턴스가 간섭 안 한다」 -> «낡은 DOM»을 비교했다. 모듈 수준 변수가 통과했다
고친 뒤: 첫째는 이름 «요소»로 좁히고, 둘째는 비교 전에 둘째 인스턴스를 «다시 그린다»
```

## ③ 고르기는 행이 있는 곳에서, 실행은 토큰이 있는 곳에서

`f5d847c9`. 판정대로 지었다. 그리드 페이지는 여전히 어드민을 모른다 — 메뉴 부품이 라우트도
fetch 도 저장소도 이름 대지 않는다. 🔴 그리고 **하니스가 그것을 «주석을 벗긴 코드»에서 센다** —
그 단언의 첫 판이 **자기 설명 주석 때문에** 빨개졌기 때문이다.

메뉴는 **선언된 범위 컬럼마다 한 줄**을 내놓는다. 서버가 거절할 컬럼은 «비활성»이 아니라
**아예 없고**, 고른 다음 400 을 받는 경로가 없다.

넘김(handoff)은 **한 번 쓰고 한 번 먹는다.** 남겨 두면 다음 방문에 **이번에 아무도 고르지 않은
범위가 미리 채워지고**, 운영자는 그것을 자기 선택으로 읽는다 — 이 화면이 읽기 쪽에서 계속
잡아내던 오독의 **쓰기 쪽 판**이다. URL 이 아니라 저장소로 가고, `sessionStorage` 가 아니라
`localStorage` 인 이유도 적혔다: **새 탭에서 어드민을 여는 날 탭별 저장소는 범위를 «오류 없이»
떨어뜨린다.**

## 🔴 ④ 라이브 화면이 «하니스가 볼 수 없던» 결함을 잡았다 — 픽스처가 두 읽기를 구별 못 했다

선언된 표에서 세 행을 고르니 컬럼 여섯이 전부 **「선택한 행에 값이 없습니다」**로 읽혔다.
값은 거기 있었다.

```
이 그리드는 행을 «봉투»로 들고 있다   row.data[col].value
                                   (grid.js 자신의 rawCellValue 가 그렇게 읽는다)
내 픽스처 행은 «평범한 객체»였다
=> 두 읽기가 «같은 답»을 냈고, 그래서 시험이 «아무것도 증명하지 않았다»
```

부품은 봉투를 «배우는» 대신 **읽기 함수를 주입받는다** — 봉투를 아는 것은 그리드를 아는 것이기
때문이다. 하니스는 **두 읽기가 갈라지는 봉투 픽스처**를 들고 간다.

게이트는 **빌드된 번들**에서 쟀다: 선언 안 된 표는 죽은 줄이 아니라 **아무것도 안 그리고**,
선언된 표에 선택이 없으면 그렇게 말하고, 화면의 컬럼은 선언이 준 여섯과 **정확히** 같으며,
하나를 누르면 어드민에 착지해 재번역 블록이 열리고 넘김이 소비되며 **`/admin` 호출이 0** 이다.

변이 하나가 처음에 **INERT** 로 읽혔다 — 이름 붙은 줄을 실패시키지 않고 «던져서»다.
**아무것도 안 잰 것에 대한 정직한 낱말**이 INERT 이고, 그 변이는 결함이 실제로 나는 자리
(조회가 다른 소스로 폴백하는 자리)에 다시 주입됐다.

## ⑤ 자격증명을 «치지 않고» 이음매를 봤다

`a7b00343`. 넘김 검토에서 남은 둘을 닫았다. 세 행을 고르고
「선택한 3행 → run_uid 3개로 다시 번역」을 누르면 어드민에 착지해 블록이 열리고 넘김이 소비되며
입력 셋에 `source=die_inspection` · `scope_column=run_uid` · run_uid 셋이 들어 있다.
**아무것도 다시 타이핑하지 않는다** — 판정이 고르기를 그리드에, 실행을 어드민에 둔 이유다.

🔴 **토큰은 치지 않았다.** 자격증명 입력은 운영자의 동작이지 에이전트의 동작이 아니다.
대신 격리 오리진이 `/admin/retroactive/operations` 를 **직접** `retroactive.inventory()`
모양의 페이로드로 답하게 했다 — 그러면 폼이 렌더되고 **시험 대상(넘김이 입력에 닿는가)이
직접 관측된다.** 다른 라우트는 전부 그대로 프록시다.
**못 잰 것도 적혔다** — 토큰 게이트 자체는 이 배선이 아니라 `adminFetch` 소관이다.

그리고 **구분자 하나가 이 라운드의 부류 결함**이었다.

```
파라미터 키의 구분자가 «생 NUL 바이트»였다
=> grep 이 그 파일을 «바이너리»라고 부른다 -> 이 레인의 검색과 총괄의 검색이 «같은 밤에» 눈멀었다
값은 «그대로», 철자만 이스케이프 표기로 바뀐다
```
기존 단언 셋(동일 집합 · 순서 무관 · 차이)은 **어떤 구분자에서도 통과**해서 이것을 못 본다.
둘을 더했다 — 키가 U+0000 으로 이어진다는 것과, **판별 쌍**: 인쇄 가능한 구분자를 값에 담으면
**두 번째 항목을 위조해 서로 다른 파라미터 집합 둘이 같은 정체를 갖게 되고**,
그것이 한 집합에 대해 잰 수가 다른 집합 옆에 표시되는 방식이다.
구분자를 쉼표로 바꾸면 새 두 줄이 빨개지고 옛 셋은 초록으로 남는다 —
**그것이 옛 셋이 이것에 눈멀어 있었다는 측정이기도 하다.** 되돌리면 265/0,
**번들 해시 무변화**(철자만 움직였다는 값싼 증거).

## 아키텍처 영향

- `GET /api/ledger/declaration` 이 `sources` 절을 나른다. `scope_columns` 는
  **컴파일된 플랜의 `base_select_columns`** 라 서버가 거절할 컬럼을 화면이 못 내놓는다.
- 그리드에 **소스 라벨** 부품과 **범위 메뉴** 부품이 생겼다. 둘 다 자기 div · 모듈 상태 없음 ·
  의존성 주입이고, 그리드 페이지는 어드민을 모른다.
- 범위 선택은 **`localStorage` 넘김 하나**로 어드민에 건네진다 — 한 번 쓰고 한 번 먹는다.
- 파라미터 키 구분자가 **이스케이프 표기**가 됐다. 값은 불변.
