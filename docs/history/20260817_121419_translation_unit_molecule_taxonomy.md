# 번역 단위는 분자 — 전환표의 필수 분류 열

> 2026-08-17 12:14 · Docs / Plan · 커밋 `ef4927c`

## 배경

전환표(01)가 소스를 나열만 하면 「1행 = 1사건」이라는 암묵 가정이 그대로
실린다. 실제로는 스플릿 2행이 한 사건이고, EAV 표는 속성 행 N개가 payload
하나이며, 재고 표는 연속 행의 차이가 사건이다. 처리 단위를 판정하지 않은
전환은 소스마다 다른 임기응변을 낳는다 — 그래서 전환표에 **처리 단위 부류**를
필수 열로 박았다.

## 변경 내용

`01_CUTOVER_INVENTORY.md`에 20줄 추가. 원칙: 처리 단위는 행이 아니라
**분자(한 사건의 온전한 서술)**이고 1행=1분자는 특수례다. 부류 6종:

```
A  행내 전개    1행 → N원자          단순 전개=Pack, 리스트 짝짓기=mapper
B1 짝 문법      N행 = 1사건          mapper (묶음 키+문법 코드)
B2 EAV 피벗     속성 행 N → payload 1  mapper
B3 스냅샷 디프  연속 행 차이 = 사건    mapper
C  표 간 참조   1행 + 이웃 표         Pack 전제 선언
D  집계         N행 → 요약 1          금지 — 집계는 질의 시점에
```

D가 전면 금지인 이유가 이 커밋의 요지다: 저장된 집계는 요약이고, 지각 도착
행이 그 요약을 거짓말로 만든다 — 저장은 문장, 계산은 읽기.

인터뷰(04) 판별 질문도 연동됐다: 「한 사건이 몇 행에 걸쳐 있습니까?」 — 감지
보조는 같은 키 행 반복·부모/자식 컬럼 상보성·name/value 쌍이고, B 판정 시
마법사는 초안을 만들지 않고 「구조 변환 mapper 필요」로 멈춘다.
