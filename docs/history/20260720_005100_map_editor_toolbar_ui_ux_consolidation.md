# 2026-07-20 00:51:00 - 웨이퍼 맵 에디터 상단 툴바 레이아웃 간소화 및 드롭다운 통합

## 1. 개요 및 동기
* **현상 및 요구사항**:
  * 웨이퍼 맵 에디터(Wafer Map Editor)의 캔버스 상단 툴바(`grid-toolbar`)에 원점 지정, 에지 선택, 자동 페인팅, 영역별 제어, 전체 삭제/채우기, 최종 데이터 전송 등 9개의 제어 단추들이 일렬로 노출되어 좁고 복잡해 보이는 UI 문제가 있었습니다.
  * 기능 유형에 맞춰 선택 도구와 그리드 편집 도구군으로 묶어 드롭다운 팝오버 패널로 밀어 넣는 **UI/UX 간소화 리팩토링**을 적용했습니다.

---

## 2. 세부 개선 사항

### A. 선택 도구군 통합 (`🔍 Select Tools` 드롭다운)
* **에지 및 오프셋 도구 합병**:
  * `📍 Set Origin (0,0)` (원점 설정), `✔️ Select E1` (최외곽 선택), `✔️ Select E2` (차외곽 선택), `⚡ Auto-Paint E1/E2` (자동 페인팅) 기능을 **`🔍 Select Tools`** 드롭다운 하나로 통합했습니다.
  * 이를 통해 4개의 가로 버튼 공간을 드롭다운 하나로 축소했습니다.

### B. 그리드 편집 도구군 통합 (`🛠️ Edit Grid` 드롭다운)
* **일괄 작업 합병**:
  * 격자 전체 채우기(`🎨 Fill All`)와 격자 전체 지우기(`🧹 Clear Grid`) 기능을 **`🛠️ Edit Grid`** 드롭다운 하나로 모았습니다.
  * 실수로 전체 삭제나 전체 채우기 버튼을 클릭하는 사고를 예방하는 구조적 효과도 얻었습니다.

### C. 선택 영역 콘텍스트 제어부 (`selection-actions-container`)의 동적 팝업
* **평시 가시성 제거**:
  * 특정 셀 범위를 선택했을 때만 쓸 수 있는 `🎨 Fill Selected`와 `🧹 Clear Selected` 버튼을 평소에는 숨겨 둡니다.
  * 에지 선택 단추 등을 통해 선택 영역이 잡히면 좌측 배너 상태 정보 옆에 **`🎨 Fill Selected` / `🧹 Clear Selected` 컨테이너가 깔끔하게 노출**되도록 동적 콘텍스트 가시성을 부여했습니다.
