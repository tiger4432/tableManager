## 🔴 「표에 원천 데이터를 넣고」의 «표»가 선언에 적힌 이름과 다를 수 있다

밑바닥 표를 찾는 데 **세 겹**이었다 — 선언이 가리키는 이름이 전부 «뷰»였다.

```

bonding_die_from_core   -> 뷰 -> bonding_core_die 도 뷰 -> «bonding_log» + «core_wafer_map»
void_obs_observed       -> 뷰 -> «void_obs» (+ inspection_run 조인)

```

씨앗 키는 **커서 뒤에** 떨어뜨렸다 — 네 표 모두 cursor 컬럼이 `'zz'`/`'ZZ'` 이상인 행이 «0»임을
먼저 확인하고 그 구간에 지었다. 그래서 번역기가 **새 행만** 읽었다.

```

전부 deduped 0 · batches 1 — 재번역 «불필요»
```

=> 두 시간 전의 「덧붙이기가 없다」는 **«선언»을 고칠 때**의 이야기이고, **«행»을 더할 때는
덧붙여진다.** 두 경우가 갈리는 자리가 여기서 수로 갈렸다.

## 소유자가 모양을 지었다 — 「(닿은거/도달한거), (닿은거/도달한거)」

`264d137f` 에 실측이 먼저 적혔고, `e05fbd40` 이 그것을 착지시켰다.
분모는 **「그 씨앗이 그 후보의 «타입»에 하나라도 닿았나」**다.

```python
# server/ledger_api/ledger_subgraph.py — _propagation()
def _reachable(node_type):
    bare = str(node_type or "").split("@", 1)[0]
    pair = [0, 0]
    for seed, sign in seed_signs.items():
        if bare and bare in kinds.get(seed, ()):
            pair[0 if sign > 0 else 1] += 1
    return pair
```

`_reach` 는 **이미 씨앗별로 걷고 있었다.** 오는 길에 «닿은 타입 집합»만 같이 담으면 되므로
**새 질의가 «0»이다.**

```
                              관측(닿음/도달)   대조(닿음/도달)
대조군 = BW-03,04 (정상)
  SYN-R-CMP-01  recipe             2/2            0/2    갈 수 있었는데 없다 = «진짜 차이»
  slurry_A_ml   quantity           2/2            0/2    진짜 차이
  void          defect_kind        2/2           «0/0»   분모 0 — 갈 길이 없다
대조군 = BW-05 (다리 끊김)
  셋 «전부»                         2/2           «0/0»   틀린 1등의 «확신»이 사라진다
```

칸 하나가 **열려 있던 셋을 같이 닫았다** — 끊긴 다리 · `void` 동어반복(집단이 애초에
`defect_kind` 에 못 간다 → 0/0 으로 «자동» 제외) · 진짜 차이(0/2 로 남는다).
**「1층의 void 는 별건」이라고 미뤄 둔 판정이 같은 칸으로 답해졌다.**

## ⚠️ 이 칸이 «못» 잡는 것을 코드에 같이 적었다

```
새 칸 (도달)   분모 = 그 «타입»에 닿나     「길이 있나」
규칙 ③ (측정)  분모 = 그 «항목»을 쟀나     「그것을 봤나」
```

물리량 16개를 «잰» 대조군은 `quantity` 타입에 «닿으므로», 안 잰 항목도 0/2 로 나와
진짜 차이처럼 보인다. **서로를 대신하지 못한다.** 규칙 ③은 여전히 따로 남았다.

그리고 **순위는 안 바뀌었다** — 0/0 후보가 아직 1층에 뜬다. 그것을 빼는 것은 판정이지
칸 추가의 부작용이 아니라고 커밋 본문과 코드 주석에 적혔다.

## 아키텍처 영향

- 응답의 `ranked[]` 에 **`reachable`** 이 `reach` 옆에 앉는다. 각 쪽이 «닿은 수 / 도달 가능 수» 페어다.
- `_reach` 가 씨앗별 **닿은 타입 집합**을 함께 반환한다(`reach, parents, kinds`). 새 질의는 없다.
- 「대조군이 그 부류에 못 간다」와 「대조군이 그 항목을 안 쟀다」가 **다른 분모**로 갈렸다.
- 원장에 **`ZZ-DOE-` 접두** 씨앗이 있다 — 웨이퍼 12 · 표 행 152 + `process_param` 8행,
  DOE 방아쇠와 「끊긴 다리」의 픽스처다.
