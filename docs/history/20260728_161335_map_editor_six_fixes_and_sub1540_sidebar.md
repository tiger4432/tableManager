## 배경

U6/U7 라운드 인접에서 발견돼 보드 5b로 모인 7건(ⓐ~ⓖ) — **전부 이 라운드 이전부터 있던
기존 결함**이다. 6건은 map-pm, 사이드바 도달 불가(ⓕ)는 ui-designer가 나눠 맡았고, 각 건은
격리 스택에서 수정 전 재현 → 수정 후 해소를 확인한 뒤 퀵 QA가 독립 재실행했다.

## 변경 내용

### ⓐ 낡은 초안 — 문구를 고치지 않고 persist를 게이트했다

지문 불일치 시 토스트는 "초안은 지우지 않았습니다"라고 약속하는데, 로드 경로의
`saveLegendToStorage()`가 직후에 초안 슬롯을 서버본으로 덮어 **그 약속을 어기고 있었다.**
초안 계약(불일치 → 적용도 폐기도 않는다)의 편에 서서, 문구가 아니라 persist를 고쳤다:

```js
// map_editor.js — 이 커밋 시점
staleDraftKept = (!doeFresh && hasDoe) || (!cellsFresh && hasCells);
...
if (!staleDraftKept) saveLegendToStorage();
```

보존된 초안은 registry 읽기 실패 경로가 여전히 살려낼 수 있다. 사용자의 다음 편집은
정당하게 슬롯을 덮는다 — 단일 초안 슬롯은 가장 새로운 편집을 지키는 장치다.

### ⓑ `legendDirty`는 맵 단위 상태 — 리셋 위치가 계약이다

맵 A의 미저장 플래그가 맵 B로 살아남아, 편집 0건인 맵에 "● 저장 안 됨" 칩이 떴다.
로드 성공 시 `legendDirty = false`로 재수립하되 **순서가 계약이다**: 그 아래의 초안 복원
(정상/읽기실패 양 분기)이 리셋 *뒤에* 다시 dirty를 세우므로, 복원된 초안은 여전히
미저장으로 표시된다 — 초안 보증과 충돌하지 않는 유일한 배치다.

### ⓒ 메타 없는 맵의 기본 프레임 — "마스크 없음"을 마스크의 언어로

메타데이터 없는 맵의 기본 선택지에서 좌패널 물리 규격(원형 웨이퍼)의 마스크가 그대로
살아 있어, 모서리 셀들이 inside:false로 찍히고 Push의 대비 가드가 **모든 Push를 거부**했다
(재현: 1293행 중 379행만 커버 → 거부). 마스크 술어에는 끄는 스위치가 없다 — 그래서
"마스크 없음"을 그 술어의 어휘로 표현했다: chip 1×1 · offset 0 · margin 3에, 유효 반경이
격자 반대각선을 외접하는 웨이퍼 지름을 기존 규격 기록자 `applyPresetObject`로 기입.
모든 셀 모서리가 타원 안에 들어가 전 셀이 Push 가능해진다. 기본 프레임 = **데이터
바운딩 박스, 마스크 무효** — QA 재현 맵이 거부 대신 정상 확인창(1293건)에 도달.
선택지 버튼 라벨도 바뀐 의미를 따라갔고, 대비 가드는 2차 방어선으로 남았다.

### ⓓ 후보 매칭 — 세 판정자 중 하나만 대소문자를 무시했다

`fillColumnDropdowns`만 대소문자 무시 매칭이라, 같은 후보 목록에 대해 다른 두 판정자
(오버레이 바인딩·서버 `derive_table_binding`)와 **다른 답**을 낼 수 있었다. 정확 일치로
통일 — 대소문자만 어긋난 후보에 의존하던 테이블은 이제 자동 선택되지 않는데, 그것이
"일치하는 후보 없음"의 정직한 해석이다.

### ⓔ 뒤로가기 confirm — 본 것과 고친 것을 구분한다

`framePushed`는 프레임 진입 시 false라 `!framePushed && cells>0` 판정은 **자재 맵을
구경만 해도** 뒤로가기에서 confirm을 띄웠다. 새 플래그 `frameTouched`를 모든 편집 경로가
이미 지나는 두 관문(`persistLegend`/`scheduleCellDraft`)에서 세우고, `setLoadedIdentity`에서
리셋하며, 프레임 스냅숏에 `legendDirty`와 함께 실어 왕복에도 보존한다(ⓑ의 프레임 반쪽 —
자재 우회 후 복귀한 부모의 미저장 칩·뒤로가기 기준선이 함께 살아남는다). 초안 복원은
의도적으로 세우지 않는다: 복원 내용은 초안 슬롯에 살아 있으므로 뒤로 나가도 잃는 게 없다.

### ⓖ 메타 모달 취소 — 신호는 있었는데 소비자가 없었다

`loadExistingMap`은 취소 시 이미 `{count: 0, cancelled: true}`를 반환하고 있었지만,
`openMapFrame`이 이를 `count === 0`("미구축 자재")과 구분하지 않아 **빈 격자 + 거짓
"맵이 아직 없습니다" 토스트**로 떨어지거나 무언 롤백됐다. 취소를 실패 진입과 같은 방식으로
프레임 롤백하고 info 토스트 1회("맵 열기를 취소했습니다")로 알린다. `transfer_plan.js`의
호출부는 취소를 실패로 오인해 "열기 실패" 에러 토스트를 겹치지 않게 분기했다.

### ⓕ 1540px 미만 창에서 계획 사이드바 도달 불가 (ui-designer 레인)

에디터 행의 자연 최소폭(설정 330 + 툴바 ~780 + 계획 430 ≈ 1540px)이 1366/1440 뷰포트를
넘는데, 앱쉘 규약 `body { overflow: hidden }`이 초과분을 **스크롤바도 없이 잘라냈다** —
해당 해상도 사용자는 계획 패널을 쓸 수 없었다. 맵 에디터 페이지에만 로드되는
`transfer_plan.css`에 `.main-layout { overflow-x: auto }`를 스코프해 행 자신이 가로
스크롤하게 했다. 공용 body 가드는 무접촉, 토스트는 position:fixed라 스크롤 오프셋과
무관하게 보이는 뷰포트 중앙을 유지한다.
