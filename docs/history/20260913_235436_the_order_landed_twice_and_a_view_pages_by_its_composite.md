## ① 「착지」와 「돈다」가 다른 날 — S-156 이 착지하고도 «무동작»이었다

```
23:28  c7bc59db  신설 `server/chain/rule_order.py`(84줄) — 규칙 «사이» 순서가 선언에서 «유도»되고

   ↓   그런데 «무동작»이었다

                 서로의 생산자가 되어 «가짜 고리»를 만들었다 -> 순서가 설 자리가 없었다 (판정 387)
23:48  684ffb4d  그리고 성질의 «절반»으로도 모자랐다 — «좁힘» (판정 388, S-232-b)
```
🔴 **388(`684ffb4d`) 이 이 항목에서 제일 값진 줄이다.** 387(`c70dc340`) 이 제안한 성질은 「표 «사이»를 안 옮긴다」였는데,
그것은 **「아무도 안 읽는다」와 같은 문장이 아니다** — `t → t` 규칙도 `t` 를 «쓰므로», `t` 를 읽는
다른 `t → u` 규칙은 진짜로 그것에 의존한다. 오늘의 규칙은 좁다:
```
엣지 P → X 는  P «와» X 가 «둘 다» 그 표를 읽고 쓸 때만 건너뛴다
             = 한 표에 «서로» 의존하는 쌍이라 찾을 전순서가 없다
```
📌 부류: **성질로 바꾸는 것만으로는 부족하고, «어느» 성질인지가 답이다.** 이름을 성질로 갈면
고쳐진 것처럼 보이는데, 그 성질이 넓으면 «다른 방향»으로 틀린다.
🔵 그리고 저자는 한 집이다 — `chain/replay.py:159` 의 같은 이름은 위임이고 자기 머리글에
「저자는 `chain.rule_order` 다」라 적는다. 거절만 호출자가 이미 잡는 이름으로 다시 던진다.
