## 🔴 백필 둘이 거절했고, 둘 다 «선언 결함»이었다

```
process_param_measure    roleframe.RoleFrameError: event_frame.row: value is not
                         deterministic JSON: Out of range float values ... nan
mechanism_edge_causes    source_preparation: source_batch.rows[21].asserted_at:
                         driver identity/order/cursor/time value is missing
```

첫째: **소스는 자기 행이 비워 두는 컬럼을 바인드하면 안 된다** — numeric 컬럼의 NULL 이
프레임에서 NaN 이 되고 NaN 은 결정적 JSON 이 아니다. **데이터 결함이 아니라 선언 결함**이라서
선언을 고쳤다 — **같은 표 위의 뷰 둘**(73,267 · 7,055, 겹침 0, 합 80,322)과 그것을 각각
바인드하는 소스 둘. **둘 다 여전히 `measures@1`**이고 그건 여기서 평범하다 —
`transfer@1`이 이미 소스 셋을 들고 있고 기존 관계 둘도 이미 뷰다.

둘째: **날짜는 애초에 안 빠져 있었다.** 내가 각 모델의 `validity`를 읽으라고 시켰는데
`void_observation_bias`는 그 필드를 **모델이 무엇을 «뜻하는지»** 설명하는 데 쓴다. 파일 자신의
`__doc`가 「Edges are DECLARED knowledge, owner-reviewed 2026-08-14」라 적고 있고 주어가
「edges」다 — 세 모델 전부를 덮는다. **전제가 내 것이었지만, 안 일어난 검토를 도장 찍는 대신
멈춘 것은 옳은 판단이었다.**

## 🔴🔴 그리고 게이트는 통과했을 텐데 라운드가 존재하는 이유가 깨졌을 것이다

`2bc56ca7`. 게이트 3을 기다리지 않고 직접 걸었더니 실패했다.
`defect_kind{void}`에서 `follow=leads_to`로 walk 하면 **노드 1 · 엣지 0**이고 원자가 이유를 말한다 —
목적어 타입이 **quantity 22 · defect_kind 0**.

**내 바인드가 엔터티 타입을 «하나»만 만든다.** 그래서 `void`가
`quantity@1{quantity:"void"}`가 됐다 — 원장이 이미 든 `defect_kind@1{defect_kind:"void"}`와
**다른 노드**다. **내 지시서는 void 와 delam 을 그대로 두면 기존 노드에 붙는다고 레인에게
말했다. 안 붙는다.**

판정은 value/value_text 와 같다 — **바인딩 하나가 두 모양을 못 내면 소스를 나눈다.**
나누는 기준에 **결함 이름이 안 적힌다**: 모델이 각자 자기 `finding_kind`를 선언하므로,
`to`가 그것과 같은 엣지는 결함 종류에서 끝나고(9행) 나머지는 물리량이다(13).
그것이 `void_observation_bias`를 물리량 쪽에 놓는데, **모델 자신이 그렇게 말한다** —
발생이 아니라 «나타남».

> **이걸 안 했어도 게이트는 통과했다.** 원자 80,322이 착지하고 모든 수가 초록이고
> **라운드가 존재하는 이유가 깨져 있었을 것**이다 — **틀린 문장이 게이트가 아니라 지시서의
> 산문에 있었기 때문이다.**

잘못 번역된 원자 22개와 그 커서를 지웠다 — **소스 행 22는 그대로**이므로 지운 것은
**기록이 아니라 투영**이다.

## 아키텍처 영향

- 「원천은 표로, 원장은 표에서」가 **상설**이다. `store.write_batch`의 정당한 호출자가 하나로
  이름 대졌다.
- 엔터티 `quantity@1`, 술어 `measures@1` · `leads_to@1`이 **선언에 있다.** 인과 체인이
  walk «하나»로 닫힌다 — 두 번째 순회기가 없다.
- **바인딩 하나가 두 모양을 못 내면 소스를 나눈다**가 두 번(value/value_text, quantity/defect_kind)
  같은 판정으로 적용됐다.
- 배포 샘플이 **라이브의 사본**이다. 그전에는 새 설치가 그것으로 못 떴다.
