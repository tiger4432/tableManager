# 마킹이 맵을 쌓기를 그만두고 답하기 시작했다

**Date:** 2026-08-14 18:45 · **Domain:** Client (원장 콘솔 — 대조 패널·페어 레일) · **Status:** 착지 — `66e2925` (+ 보드 스냅숏 `d530360`)

## 배경 — 그림 더미는 「어떻게 다른가」의 답이 아니다

랏 여러 개를 마킹하면 맵 125장이 12,283px로 쌓였고 대조는 어디에도 없었다. 세트를
마킹한다는 것은 구성원이 **어떻게 다른가**를 묻는 것인데 화면은 그림 더미로 답했다.
그 더미는 레이아웃 증상 뒤에 숨은 페치 폭풍이기도 했다 — 마킹 5랏이 5 + 5×25 = 130
응답을 요구했고, 이 커밋 후 5가 됐다.

## 대조 패널이 마킹에 배선됐다 (`contrast_core.js`·`contrast_view.js` 신규)

엔드포인트는 하나, `mode`·`finding`은 파라미터다 — 둘째 라우트는 일부러 없다:

```js
// contrast_core.js — THE LANDED CONTRACT, measured live 2026-08-14
// GET /api/ledger/siblings?mode=contrast&scope=<axis>:<v>[,<v>…]
// ONE endpoint, two framings: `mode` is a parameter and there is
// deliberately no second route.
```

스코프는 마킹 집합을 따라가서 마킹이 바뀌면 다시 묻는다. 세 관문 칩은 응답에서
**읽어서** 그리지 조립하지 않는다 — 넷째 관문이 생기면 칩이 하나 늘 뿐 줄이 안 바뀐다.
둘을 마킹하면 우측 고정 레일이 쌍을 지표별로 비교한다(이미 화면에 있는 표 데이터에서
그려서 둘째 체크 즉시 뜬다). 셋 이상이면 조용히 딴 걸 하는 대신 그렇다고 말한다.

**조용히 잘리는 것이 없다.** 절단 안내는 실수(20 표시 / 37 채점 / 17 미표시)를 싣고,
서버 플래그뿐 아니라 `shown < scored`에서도 발화한다 — 짧게 돌려주고 말 안 하는 서버도
부분 목록을 완전한 것처럼 통과시킬 수 없다. 귀속 커버리지·대조군 표본 비율·「규칙
미적용」과 「제외 0」을 구분한 두 버킷이 전부 화면에 있다.

## 죽은 버튼 둘 — 계약 불일치와 no-op 편집

컬럼 메뉴가 비어 있던 이유: 서버는 집계를 `name` 키로 내보내는데 읽는 쪽은
`aggregate` 다음 `id`를 찾아 여섯 개 전부 걸러 없앴다 — 그리고 바는 12개 중 1개만 선
상태에서 「선언된 지표 전부 가동」을 주장했다. 읽는 쪽이 `name`을 받게 됐고, 불일치를
확정처럼 보이게 한 핀 고정 계약 주석이 정정됐고, 완전성 문장은 숫자가 맞을 때만 뜬다.

컬럼 제거가 no-op였던 이유: 집합이 서버 기본값에서 왔으면 질문(URL)이 컬럼을 하나도
명명하지 않아 편집 결과가 같은 URL이었다. 해소된 집합을 편집 적용 **전에** URL에 쓰게
됐다 — 추가 쪽엔 나머지 셋을 떨구는 거울상 결함이 있었고 같은 수리가 갔다.

## 맵의 단위는 웨이퍼, 팬인은 선이 못 답하는 자리에서 거절한다

포커스된 웨이퍼의 DT 출처는 랏 이름 + 슬롯 25개로, 코어 출처는 랏 둘 + 슬롯 25개로
보고하되 **짝짓기를 거절한다** — 응답은 무엇이 나타나는지를 말하지 어떤 짝인지를 말하지
않기 때문이다. 곱집합은 절대 안 나온다. 신원 없는 웨이퍼는 죽은 링크가 아니라 텍스트로
그려지고 이유를 말한다.
