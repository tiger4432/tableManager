# 작성자 가이드가 «저장소 입구»로 들어왔다 — 둘째 저장소가 아니라

> **커밋:** 이 항목과 함께 가는 D-34 (판정 386, 판정 351 «철회»)
> **일자:** 2026-09-13 (밤)
> **레인:** 응용(문서)
> **측정 상자:** 이 워크스테이션. **운영이 아니다.**

## 무엇이 일어났나

소유자의 문장은 **「그냥 git에 걸어주면 pull해 쓰지」** 하나였다. 총괄과 저는 그것을
**「별도 저장소를 만들고 원격을 걸어라」**로 읽었고(판정 351), 오늘 소유자가 정정했다 —
**「1은 저 말이 아니라 그냥 폴더 입구에 두라는 말」.**

```
09-13 07:59  D-21   바깥 디렉터리 `assyManager-authoring/` 를 «별도 git» 으로 세움
09-13 08:22  351    원격 = GitHub 별도 저장소. 소유자가 만들면 push
     … 종일  대기    원격 생성이 «안 왔다» — 그 대기 자체가 표지였다
09-13 21:30  386    351 «철회». 저장소 루트 `authoring/` 에 «추적 파일»로
```

## 🔴 이 라운드의 값은 「무엇이 틀렸나」가 아니라 「무엇이 그것을 오래 숨겼나」다

**두 읽기가 «같은 결과»를 약속했다** — 어느 쪽이든 운영자는 `pull` 로 문서를 받는다.
그래서 **틀린 읽기가 «돌아가는 것처럼» 보였고**, 열흘치 일이 그 위에 쌓였다(디렉터리 · 원격 절 ·
받는 법 · SDK 버전 줄 · 저장소 쪽 포인터).
🔵 **그리고 그것을 «멈춰 세운 것»은 논증이 아니라 «안 온 원격»이었다** — 하루 종일 대기했고,
그 대기가 「이 길이 아니다」를 말하고 있었다.
📌 부류: **같은 결과를 약속하는 두 설계는 «비용»으로 갈린다.** 이번 비용은 「문서가 어느 제품을
말하는가」를 **손으로 맞춰야 하는 것**이었다.

## ⚰️ 그래서 «해결된 것»이 제일 크다 — SDK 버전 줄

바깥 저장소일 때는 「SDK 버전 = 저장소 커밋 해시」 한 줄이 **그 디렉터리에서 제일 중요한 줄**이었다.
문서가 «어느 제품»을 말하는지 다른 방법이 없었기 때문이다.
🔵 **이제 문서와 제품이 «같은 커밋»에 산다.** 맞출 일이 없고, **맞추다 틀릴 일도 없다.**
⚠️ 그 절은 «지우지 않고» 기록으로 남겼다 — **무엇을 왜 걱정했는지가 이 폴더가 여기 있는 이유**다.

## 옮긴 것

```
authoring/README.md · MAPPING_GUIDE.md · PARSER_GUIDE.md
authoring/examples/  다섯 (맵퍼 셋 · 파서 둘)
```
🔵 여덟 파일 전부 **바이트 동일**로 확인하고 옮겼다(`cmp`). 바깥 git 의 «이력»은 안 가져왔다 —
그 커밋 메시지들이 한 일은 이 항목과 앞선 D-21~D-33 항목에 이미 적혀 있다.
🔵 바깥 디렉터리를 가리키던 문서 «일곱»의 경로 아홉이 `authoring/` 으로 바뀌었고,
포인터 `docs/guide/AUTHORING.md` 의 **「형제 저장소」 틀 셋**은 문장째 고쳤다 —
경로 치환은 «글자»를 고치지 «뜻»을 고치지 않는다.

## ⚠️ 그리고 지시의 전제 하나가 거짓이었다 — 서버 시험이 그 경로를 «읽는다»

```
지시     「서버 드리프트 게이트는 바깥 경로를 안 읽음 — git grep … -- server = 0」
실측     server/tests/test_the_authoring_guides_name_entry_points_that_exist.py
         :33  AUTHORING_DIR = os.path.join(os.path.dirname(REPO_DIR), "assyManager-authoring")
         :34  EXAMPLES_DIR  = os.path.join(AUTHORING_DIR, "examples")
         :137 · :152 가 그 경로의 파일을 «연다»
```
🔴 **그 시험은 「저장소 «옆»」을 가리키므로 이동과 함께 빨개진다.**
⚠️ 그 파일은 «서버 시험»이라 이 레인이 안 건드렸다 — 고치는 자리는 코드 쪽이고,
그래서 «이름 대어» 올렸다.
📌 부류: **「코드 0」은 «내가 안 건드린다»이지 «코드가 안 걸린다»가 아니다.**

---
📎 문장마다 해시를 달았고, 「운영」이라 적은 줄은 «없다».
📎 바깥 디렉터리 삭제는 «총괄»이 착지 확인 뒤에 한다 — 이 레인이 지우지 않는다.
