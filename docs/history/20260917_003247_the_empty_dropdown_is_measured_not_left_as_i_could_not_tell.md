# 빈 드롭다운을 «재서» 가렸다 — 「못 가렸습니다」로 두지 않았다

> **커밋:** `fcc61f9c` (00:32) — 클라. 보고는 `0da4b44b`
> **일자:** 2026-09-17
> **측정 상자:** 이 워크스테이션. **운영이 아니다.**

## 배경

`disabled_reason_harness.mjs` 의 고정 표에 한 줄이 `UNRULED` 로 앉아 있었다 —
「옵션이 0 인 빈 드롭다운. 읽어서 못 가렸습니다」. 총괄이 그것을 **접수하지 말고 재라**고
요구했다.

## 무엇을 찾았나

```
그 한 자리(map2/main.js :: node.disabled = options.length === 0)가
드롭다운 «여섯»을 덮는다 — 규칙 · 표 · X · Y · 값 · 참조
그리고 «비는 경우마다» 그 줄의 notice 가 사유를 «먼저» 세운다
```

그 파일의 주석이 이미 그렇게 적어 두었다 — 화면이 규칙이나 표조차 못 찾았으면,
그 사유가 「답에 대한 어떤 말보다 «앞선다»」. 호출 자리들이 그 말과 «일치했다»:

```
표 0        -> 「맵 테이블 없음」        map_editor2.js:310
규칙 못 고름 -> 그 사유 «그대로»         :211 · :245
셋업 실패    -> 그 문장                :255 · :316
컬럼 미선언   -> WORDS.columnsUnstated 가 «같은 줄»에
```

그래서 `STATED` 로 바뀌었고, **호출 자리 다섯이 이름으로 적혔다.**

## 🔴 그리고 열쇠는 «0 으로 남겼다»

```
const OPEN_DEBT = { CONFLICT: 1, UNRULED: 0 };   // 지우지 «않았다»
```

값이 0 이어도 키가 있어야, 다음에 분류 못 한 자리가 «하나 생기는 날» 이 줄이 빨개진다.
키를 지우면 그 자리는 **빨개지는 대신 조용히 존재하지 않게** 된다.

📌 이 저장소가 여러 번 적은 것의 반대 방향 실물이다 — 빈 칸은 「통과」로 읽히므로
**빼지 말고 단언한다.**

## 그때 남아 있던 것

- `CONFLICT` 는 여전히 1 이다. 이 라운드가 닫은 것은 `UNRULED` 하나다.
