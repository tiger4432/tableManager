# 제품이 «자기를 진단»하게 됐고, 깨진 선언이 «혼자» 떨어지게 됐다

> **커밋:** `6f45a004`~`be5eacd6` (13:52~17:27)
> | **일자:** 2026-09-11 (저녁)
> **레인:** 구현자(서버) · 응용 · 총괄
> **측정 상자:** 이 워크스테이션 — «운영»이라 표시한 줄만 소유자가 준 운영 수다.

## 무엇이 일어났나

저녁의 문장은 하나다: **「소유자가 SQL 을 못 낸다」를 «제약»으로 받은 뒤에 설계가 바뀌었다.**
운영을 여기서 잴 수 없다면 잴 수 있는 것은 «제품 자신»뿐이고, 그러면 계기는 제품 안으로 들어온다.
그리고 그렇게 들여다보니 «거절의 모양»이 전부 틀려 있었다 — 하나가 틀리면 천 개를 만든다.

## ⓐ 운영 진단 계기 «셋» — 「정하지 않고 «읽는다»」

```
무엇이   제품이 자기 대기·인덱스·느린 문장의 계획을 «스스로» 말한다. 배큠 상태는 명령이 «읽어»만 준다
왜      소유자가 운영 DB 에 질의를 못 낸다(보안). 그러면 「운영에서 재라」는 답이 «불가능»하고,
        남는 방법은 «계기를 제품에 넣어 값을 받는 것» 하나다(판정 276)
어디    6f45a004 13:52  청크 apply 동안 자기 백엔드의 `wait_event` 를 250 ms 표본(풀 «밖» 커넥션) ·
                        인덱스 목록 · 느릴 때 «자기 EXPLAIN»(`slow_prefetch_explain_seconds`, 기본 1.0 s)
        6652a645 16:58  층 표 배큠이 «명령»이 된다 — dry-run 이 기본이고 **아무것도 «정하지 않는다»**
```
🔵 **「읽고 정하지 않는다」가 이 셋의 규율이다.** 스크립트가 설정을 «골라 주면» 그 선택의 근거가
어디에도 없고, 운영자는 그것이 자기 상황에 맞는지 알 방법이 없다. 값을 보여 주고 판단은 사람에게 둔다.
🔵 그리고 이 계기가 «바로» 값을 냈다 — 기동 줄이 «읽히지 않는 902 MB 인덱스»를 이름 댔다.
   쓰기마다 값을 치르면서 아무도 안 읽는 인덱스다.

## ⓑ 🔴 거절의 «모양» 셋 — 하나가 틀리면 천 개가 된다

```
S-157  HOL 가드가 «표마다 · 스윕마다 한 줄», 그 줄이 «머리의 사유»를 든다
       (종전: 미룬 것마다 한 줄 → 진짜 원인이 자기 로그에 묻혔다)
S-173  격리 재전개가 «이분»이다 — 독 든 행 하나가 사건 «21 개»를 쓴다(종전 1,000 개)
       각 반쪽이 자기 트랜잭션 그룹이고, 자식이 «자기 경로»를 접두로 남긴다(`a` · `ab` · `abb`)
       그래서 한 번의 접두 검색으로 계보가 전부 나오고, 깊이는 `MAX_REEXPANSION_DEPTH = 12` 에서 멈춘다
S-174  행 «하나»의 중복 조인 키가 표 전체의 체인을 멈추지 않는다
S-172  그리고 «이미 터진» 재전개 홍수를 운영자가 치울 수 있다 — `outbox_triage.py` 가
       per-row 사건을 건너뛰고 «접힌 채로» 다시 쏜다
어디   2180dd58 13:59 · c68faff3 17:19 · a50d7328 16:26 · 75af9789 14:05
```
🔴 **운영 수가 이 셋을 «급»으로 만들었다** — per-row 사건 «66 만» × 그룹 배관 ~1.7 s = «며칠».
이 박스에서 같은 기제가 「쓰기 여섯 → 사건 약 1,700」이었고, 운영은 거기에 세 자리가 더 붙는다.
📌 부류: **거절이 «비싸면» 거절이 사고가 된다.** 1,000 → 21 은 기능이 아니라 «비용의 설계»다.

## ⓒ 선언 «격리» 셋 — 깨진 것 하나가 전부를 세우지 않는다

```
S-177 ①  `status: retired` 면 그 선언을 «안 읽는다» — 검증 · 교차 컬럼 · 컴파일 레지스트리 · 계획,
         «네 패스»가 `is_retired()` «한 철자»에서 멈춘다. 그래서 «깨진 채로 은퇴시켜도» 원장이 돈다
S-177 ②  깨진 «활성» 선언은 «혼자» 떨어진다 — `SourcePlan.planned=False` + `refusal{code,path,message}`,
         그리고 «성한 부분집합 위에서» 교차 검사를 다시 돌린다(고정점). 로더가 «어느 것이» 떨어졌는지 말한다
S-177 ③  격리의 «뿌리»가 자기 상수(`ISOLATION_ROOTS`)를 가진다 — 그래서 조인 규칙도 «혼자» 떨어진다
어디     5f2b1b72 16:07 · ce77b224 16:50 · be5eacd6 17:24
```
⚠️ **그 전에는**: 못 읽는 선언 하나가 번들 «전체»를 거절했고, 뒤따르기가 매 바퀴 실패했다 = 원장 정지.
「끄는 방법」(retired)이 정작 «끄고 싶은 이유»(선언이 깨짐)에서 안 통했다.
