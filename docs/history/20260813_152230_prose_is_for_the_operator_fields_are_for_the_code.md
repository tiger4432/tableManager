# Prose is for the operator, fields are for the code

## 배경 — L3가 위험을 추론하지 않고 «생산»해서 증명했다

관례/측정 구별이 hop의 reason 산문 안에만 살았고, 소박한 `includes('convention:')` 검사는
**가정이 측정에 «진» 바로 그 hop을 「가정」이라고 이름 붙였다**(`d9b98ab`의 발견).
화면의 앵커 정규식 파싱은 한 함수·양방향 핀·실패 가능성을 증명한 mutant라는 조건으로
허용됐지만, **리팩터 한 번이면 조용히 거짓말하는 물건**이었다 — 그래서 레인은 조용히
싣지 않고 에스컬레이션했다.

## 판정 R-C

구조화된 `basis` 필드는 **추가 전용**으로 비준하되, 2주차의 enum 확장과 **한 커밋에
묶어** 라우트 계약이 두 번이 아니라 한 번 움직이게 했다. 함께 기록된 상설 원칙:

> 클라이언트가 분기해야 하는 구별은 전부 **필드**여야 한다. 산문은 hop을 읽는
> 운영자의 것이지, hop을 렌더하는 코드의 것이 아니다.
