# 2026-07-17 어드민 대시보드 코드 에디터 우측 분할 영역 100% Fit 및 가로 스크롤 제거

## 1. 개요 및 동기
* **현상**: 인라인 에디팅 진입 시 자바스크립트가 강제로 적용하던 `position: fixed` 기반의 전체화면 클래스(`.fullscreen-mode`)가 부모 엘리먼트의 Stacking Context(쌓임 맥락)에 가로막히면서, 뷰포트 너비(`100vw`)가 우측 패널 내에서 비정상적으로 가로로 길게 팽창하여 거대한 가로 스크롤바가 생기고 제어 버튼 그룹이 보이지 않는 정합성 결함이 존재했습니다.
* **조치 방안**: 사용자의 요구사항에 맞추어 불필요한 전체화면 전환 로직과 스타일링, 토글 버튼을 과감하게 영구 폐기하고, 우측 패널(`right-panel`) 내부 div 영역에만 깔끔하게 핏(fit)되어 안착하도록 100% 반응형 Flex 레이아웃으로 복원 개조했습니다.

---

## 2. 주요 보완 사항

### A. 불필요한 Fullscreen 버튼 및 스타일 소탕
* **[마크업 개정]** `client2/admin.html` 의 에디터 헤더 영역에서 `editor-fullscreen-btn` 토글 버튼을 완전히 삭제 처리했습니다.
* **[스타일 개정]** 스타일시트 내에 선언되어 있던 `#editor-content-wrapper.fullscreen-mode` 및 하위 자식 요소들의 fixed 팽창용 스타일 시트를 전면 제거했습니다.
* **[스크립트 개정]** `client2/src/admin.js` 의 `setupEventListeners` 내의 `editorFullscreenBtn` 클릭 이벤트 리스너를 날리고, `openInlineEditor` 및 `closeInlineEditor` 에서 `fullscreen-mode` 스타일 클래스를 적용/해제하던 모든 구문을 소탕했습니다.

### B. 우측 패널 본문 영역에 에디터 100% 밀착(fit) 강제화
* 에디터 뷰포트 영역이 우측 패널 안에서 가로 스크롤 없이 높이와 너비를 100%로 유연하게 점유하도록 flex 높이 배정(`flex: 1`)을 강화하고 패딩 영역을 확보하여 버튼들이 언제나 우측 창 우상단에 이쁘게 노출되도록 고정했습니다.

## 3. 빌드 및 배포 적용
* **Vite 리빌드**: 리팩토링 처리를 끝마친 후 `client2` 디렉토리에서 `npm run build` 번들링 빌드 처리를 완료하여 실서버 서비스 파일인 `dist/admin.html` 및 `dist/assets/admin-*.js` 파일에 신규 핫픽스를 안전하게 배포했습니다.
