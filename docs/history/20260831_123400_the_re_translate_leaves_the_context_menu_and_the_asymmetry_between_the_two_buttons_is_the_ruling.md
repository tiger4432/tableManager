# 재번역이 우클릭 메뉴를 떠났다 — 그리고 두 버튼의 «비대칭»이 판정을 눈에 보이게 만든 것이다

> **커밋:** `6e060fd7` (12:34)
> | **일자:** 2026-08-31 낮
> **레인:** 클라(그리드 · 어드민)
> **측정 상자:** 이 워크스테이션. **운영이 아니다.**

## 배경 — 소유자가 «두 번» 우클릭에 넣지 말라고 했다

그리고 「행 선택 리플레이는 어디 갔냐」고 물었다. 자리가 배너가 된 이유가 그 두 문장이다.

```
선택은 «그리드»에서 일어난다   ->  버튼이 «선택을 보고» 살아난다
우클릭에 넣으면              ->  메뉴가 길어지고, 선택한 뒤에 «눈이 안 간다»
```
메뉴는 **누르는 것들**로 돌아갔다 — 이 커밋 뒤 항목 «넷», 그중 재번역은 «없다».

## 🔴 ① 두 버튼의 «비대칭»이 결함이 아니라 판정 그 자체다

같은 배너에 버튼이 둘인데 **넘기는 것이 다르다.**

```
원장 쪽   «그룹»을 넘긴다   선언된 범위 컬럼마다 하나 + 그 컬럼의 «서로 다른 값 수»
체인 쪽   «업무 키»를 넘긴다  규칙 목록이 «토큰 뒤»라 어드민이 묶는다
```

```js
// 🔴 두 버튼의 그룹은 «서로 다른 곳»이 압니다:
//       원장  scope_column 값마다   -> 선언이 주고, 그러니 «여기»서 묶습니다
//       체인  규칙마다              -> 규칙 목록이 토큰 뒤라 «어드민»이 묶습니다.
//                                  여기서는 고른 행의 업무 키만 실어 보냅니다
//    두 번째를 여기서 묶으려 하면 이 파일이 `/admin/chain/rules` 를 불러야 하고, 그 순간
//    위의 경계가 사라집니다. 무엇을 «모르는지»가 이 부품의 설계입니다.
```
🔴 **비대칭을 없애면 이 화면이 토큰이 걸린 라우트를 부르게 된다.**
그래서 하니스는 **출력이 아니라 «파일»에 대해** 단언한다 — 이 파일에 `/admin/` 도 fetch 도
토큰도 없다는 것은 **어떤 렌더 결과로도 못 보이기 때문**이다.

## ② 값이 «없는» 컬럼을 «버리지 않고 이름을 댄다»

선택된 어느 행도 값을 안 가진 범위 컬럼은 **그룹이 될 수 없다** — 빈 범위를 넘기면 어드민이
**400** 을 낸다. 그렇다고 조용히 빼면 운영자는 **왜 없는지 모른다.**

```js
/** 원장 쪽 그룹: 선언된 범위 컬럼마다 하나. 값이 하나도 없는 컬럼은 «그룹이 아닙니다».
 *
 * 🔴 그 컬럼을 빈 그룹으로 넘기면 어드민이 「값 0개짜리 범위」로 400 을 받습니다. 넘길 수
 *    없는 것은 «넘기지 않고», 왜 빠졌는지는 화면이 말합니다(`dropped`).
 */
```

## 🔴 ③ 그리드가 행을 «봉투»로 들고 있어서 평범한 읽기가 «전부 없음»을 냈다

```
그리드의 실제 모양   row.data[col].value
평범한 읽기         row[col]   ->  값이 «있는데» 전부 undefined
=> 화면이 「이 값이 없습니다」라는 «거짓»을 말한다. 오류는 «안 난다»
```
해결은 부품이 봉투를 배우는 것이 **아니다** — 그러면 부품이 그리드를 아는 것이고 조립식이
깨진다. **읽는 법을 «주입»받는다**(`readValue`). 아는 쪽이 함수로 알려 준다.

## 어드민 쪽 — «하나»를 받던 자리가 «목록»을 받는다

그룹들이 파라미터 «위»에 행으로 도착하고, 하나를 누르면 입력이 채워지며
**다른 그룹에서 잰 개수는 버려진다.** 세는 것과 돌리는 것은 **이미 있던 두 버튼 그대로**다 —
**두 번째 세는 길은 두 번째 어긋날 자리**다.

## 지우는 것도 «같은 커밋»에

`grid_rescope_menu.js` 와 그 하니스가 **자기가 재던 메뉴와 같은 커밋에서** 사라졌다.
`scopeValuesFor` 는 **그대로 옮겨 갔고**, 여전히 적용되는 단언들이 **같이 따라갔다.**
`grid.js` 는 «선택 신호»를 얻었고 **누가 듣는지는 모른다** — `main.js` 가 잇는다.
(두 파일 건너 스마트 붙여넣기 리더와 **같은 모양**이다.)

## 측정 — 읽기 전용 오리진에서 «비-GET 전부 차단»하고

```
우클릭 메뉴 «4» 항목 · 그중 재번역 «없음»
버튼 둘   처음엔 «비활성», 선택하면 «활성»
원장 패널  범위 컬럼 «9» 나열, 그중 «1» 은 「값이 없다」로 «이름이 붙어» 있다
체인 패널  무엇을 넘기는지와 «어디서 묶이는지»를 말한다
네이티브 다이얼로그 «없음» · 비-GET «0»
```

## 🔴 자기 결함 셋 — 전부 «하니스가 아니라 눈»이 찾았다

```
① 배선 뒤 «첫 빌드가 FAILED» (쉼표 하나 누락)인데 하니스 게이트 줄만 읽고 «초록»이라 불렀다
   -> 페이지는 «이전 번들»을 계속 서빙했고, 옛 화면을 새 화면으로 보고할 뻔했다
② 부팅 자동 선택이 업무 키를 «한 번도 안 넘겼다»
   -> 체인 버튼이 「이 표엔 키가 없다」고 말하는데 «그 표의 머리엔 키가 떠 있었다»
③ 문구가 「1 groups from 1 rows」
```
🔴 ①이 이 저장소의 상설(「클라 변경은 빌드 전엔 안 끝났다」·「빌드했다고 로드된 건 아니다」)
**둘 다에** 걸린 자리다 — 그리고 **게이트 «줄 하나»를 읽는 것과 게이트를 «통과»하는 것이
다르다**는 것이 이 건의 새로운 부분이다.

## 아키텍처 영향

- 재번역이 **우클릭 메뉴를 떠나 «자기 div» 를 가진 배너**가 됐다 (조립식 규칙 그대로 —
  모듈 수준 상태 없음, 화면이 그 div 를 앉힌다).
- 이 부품은 **`/admin/` 도 토큰도 fetch 도 모른다.** 그 사실을 **파일에 대해** 단언한다.
- 값을 읽는 «법»이 **주입**된다 — 부품이 그리드의 행 모양을 모른다.
- 어드민이 «범위 하나» 대신 **«그룹 목록»** 을 받는다. 세는 버튼과 돌리는 버튼은 그대로.

## 그때 남아 있던 것

- 이 시점의 배너는 **실행하지 않는다.** 「고르는 곳은 그리드, 돌리는 곳은 어드민」이
  2026-08-31 12:2x 판정이고 부품이 그것을 그대로 따른다.
- 체인 쪽 그룹핑은 **어드민에서 일어난다** — 규칙 목록이 토큰 뒤에 있기 때문이고,
  이 화면은 그 목록을 안 부른다.
- 측정은 **비-GET 을 전부 차단한 읽기 전용 오리진**에서 한 것이라, 실제 실행 경로는
  이 라운드에서 관측되지 않았다.
