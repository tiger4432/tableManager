# 2026-07-20 00:54:00 - 메타데이터가 없는 맵 로드 시 좌표계 선택 모달(Choice Modal) 기능 추가

## 1. 개요 및 분석
* **요구사항**:
  * 데이터베이스에서 기존 맵 데이터를 로딩할 때, 해당 테이블에 격자 레이아웃 정보인 `grid_metadata`가 없는 경우가 존재합니다.
  * 이때 기존 데이터를 복원해 그리기 위해 1) 자동으로 원점 오프셋을 0으로 맞추고 회전 없는 기본 앞면 상태로 좌표계를 쉬프트하는 **표준 좌표계** 방식, 혹은 2) 사용자가 좌측 입력 필드에 적어 둔 오프셋과 회전, 대칭 등 **현재 입력 설정을 기반으로 한 변환** 방식을 선택해 불러올 수 있도록 모달 대화창 기능을 신설했습니다.

---

## 2. 세부 구현 사항

### A. UI 마크업 및 글래스모피즘 테마 스타일 추가
* **`choice-modal` 패널 제작**:
  * `client2/map_editor.html` 최하단에 모달 오버레이 및 패널 구조를 디자인했습니다.
  * `client2/src/style.css`에 백드롭 필터(`backdrop-filter: blur(8px)`) 및 스케일 업 애니메이션을 사용하여 기존의 프리미엄 디자인 언어를 계승했습니다.

### B. 로딩 시 비동기 확인 Promise 연동
* **`loadExistingMap` 로직 개편**:
  * 테이블 데이터를 Fetch 한 후, `grid_metadata`가 존재하지 않고 유효한 데이터 좌표쌍들이 있는 경우 로딩 프로세스를 일시 중지하고 선택창을 노출합니다.
  * JS `Promise`와 이벤트 리스너를 바인딩하여 1) 표준 좌표계, 2) 현재 입력 설정 적용, 3) 불러오기 취소 분기를 비동기 처리합니다.

### C. 좌표계 변환 방식
* **표준 좌표계 적용 시**:
  * 로딩된 좌표들 중 최소값 `minX`, `minY` 및 최대값 `maxX`, `maxY`를 계산하여 그리드 가로/세로 크기를 `(maxX - minX + 1)`, `(maxY - minY + 1)`로 자동 세팅합니다.
  * 원점은 시작점 X=0, Y=0, 앞면(Front), 회전 0도로 고정하며, 맵 좌표 역시 `(x - minX, y - minY)`로 원점 가깝게 자동 쉬프트 및 맵핑하여 물리 좌표와 정확히 일치되도록 가공합니다.
  * 가공 완료된 오프셋 및 면 정보는 좌측 패널의 입력란과 라디오 단추에 자동으로 동기화되어 표출됩니다.
* **현 설정 그대로 가져오기 적용 시**:
  * 좌측 입력 패널의 현재 값들을 사용하여 역좌표 변환을 실행합니다.
