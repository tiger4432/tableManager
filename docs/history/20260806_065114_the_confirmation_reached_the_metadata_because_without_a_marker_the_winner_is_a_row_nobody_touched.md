## 배경 — 사슬이 `frame_confirmation`에서 끊겨 있었다

조작자가 프레임을 확정하면 그 사실은 확정 기록 테이블에만 남았다. **확정된 좌표계를
에디터와 계획이 읽을 수 있는 자리**(`wafer_map_metadata`)에는 도달하지 않았다.

거기에는 명시적 금지가 있었다. 스펙 9.1과 `assume_phys_from`의 주석이 **「이 함수가
만든 값이 `wafer_map_metadata`에 도달하는 경로는 저장소에 없어야 한다」**고 못 박고
있었다 — 빌린 값이 저장되면 아무도 주장하지 않은 수치가 선언을 사칭한다.

**제품 소유자가 그 금지를 뒤집었고, 근거가 금지보다 셌다.** 유효 다이 맵은
**제품 규격마다 다르다.** 그러므로 어떤 소스 맵이 **특정** 유효 다이 맵과 일치한다는
것은 그 맵이 같은 제품 규격이라는 뜻이고, 같은 제품 규격이면 웨이퍼와 칩 기하가 같다.
**일치가 곧 증거다.**

> 금지는 **표지 없는 빌림**에 대한 것이었고, 명시적 확정 아래의 **표지 달린** 빌림은
> 다른 행위다. 정정은 문장을 조용히 고치는 대신 **왜 바뀌었는지**를 원래 문장 자리에
> 남기는 방식으로 들어갔다.

## ① 왜 일곱째 토큰이 필요했나 — 이것이 이 라운드의 하중을 받는 사실이다

씨앗 단위의 정렬 승자는 **`rot0_front`**, 즉 회전 0 · 전면 · y반전 없음 — **정확히
무증거 삼중항**이다.

```
표지 없이 방위를 쓰면 → 나오는 행이 아무도 손대지 않은 맵의 행과 **바이트 동일**하다.
그 순간 확정은 관측 불가능해진다.
```

그래서 자기 토큰이다. `assumed`(조작자의 주장)보다 세다 — 제품별 기준과의 일치는
증거다. `declared`(누군가 쟀다)는 거짓이다 — **이 맵을 잰 사람은 아무도 없다.**
서열은 그 사이고, `geometry_declaration`의 **분기 순서가 곧 서열**이다.

```python
    if m.get(PHYS_ASSUMED_KEY):
        return GEOMETRY_ASSUMED
    if m.get(PHYS_CONFIRMED_KEY):
        return GEOMETRY_CONFIRMED
    if m.get(AUTO_REGISTERED_KEY) is True:
        return GEOMETRY_AUTO_REGISTERED
```

`assumed`가 먼저 읽히는 것은 **두 표지를 함께 든 사본이 「확정된 값을 다시 빌렸다」는
뜻**이고, 합쳐진 것은 가장 약한 기여자를 따라가기 때문이다. 저장되는 행에는 둘이 같이
붙지 않는다 — 확정 쓰기가 빌림 표지를 **대체**한다.

**키가 둘인 이유도 대칭이 아니라 사실이 둘이라서다.** `phys_confirmed_from`(웨이퍼·칩
기하)과 `frame_confirmed_from`(회전·면). 하나로 합치면 **phys를 선언한 맵의 프레임만
확정한 경우에 「기하도 확정했다」는 거짓말**이 된다.

**`grid_y_invert`는 쓰지 않는다.** 후보 축이 아니라(탐색 공간은 4회전 × 2면이고 y반전은
별칭으로 상쇄된다) 확정된 적이 없고, 덮으면 **그것에 상대적으로 표현된 회전·면의 뜻
자체가 바뀐다.**

## ② 격자는 채점 자신의 합성기에서 온다 — 맵의 셀에서 다시 유도하지 않는다

정렬은 그 맵 자신의 셀에서 유도한 격자 위에서 **돌지 않았다.** 바닥에서 **빌린** 격자
위에서 돌았고, 부분 맵을 살린 판정 전체가 「부분 맵의 자기 셀 범위는 **하한이지
격자가 아니다**」였다.

씨앗 단위에서 두 후보 격자는 **실제로 다르다.**

| | 격자 | 시작 |
|---|---|---|
| 바닥에서 빌린 것(채점이 선 프레임) | **13×13** | (0, 0) |
| 그 맵 자신의 셀 bbox | **11×13** | (2, 0) |

새로 합성한 격자를 쓰면 **채점이 한 번도 쓴 적 없는 프레임**을 기록하게 되고,
**자기를 낳은 판정과 어긋나는 메타 행은 행이 없느니만 못하다.** 그래서 채점이 쓰는
그 함수(`assumed_meta_for_unregistered` · `assume_phys_from`)를 그대로 부른다.

## ③ 확정된 phys를 다시 빌리면 확정이 자기를 지운다

```python
# 이전
    return map_overlay.geometry_declaration(meta) != map_overlay.GEOMETRY_DECLARED
# 이후
    return map_overlay.geometry_declaration(meta) not in (
        map_overlay.GEOMETRY_DECLARED, map_overlay.GEOMETRY_CONFIRMED)
```

이 줄이 없으면 다음 `/view`가 표지를 `phys_assumed_from`으로 덮고, 그 순간
`geometry_declaration`이 `assumed`를 답한다 — **확정 다음 화면이 확정 이전 화면과
구별되지 않는다.** 계산 결과는 바이트 하나 안 바뀌면서.

쓰기는 `source_name="user"`다. 낮은 서열로 쓰면 레이어링이 기존 셀을 그대로 이기고
**아무것도 안 바뀐 채 200이 나간다.**

머리 행과 메타 행은 **규율이 아니라 구조로** 한 트랜잭션이다. 그래서
`commit=False`로 부르면서 메타를 쓰라는 요청은 **조용히 둘로 갈리는 대신 거절된다.**

## ④ `ac81461` — 같은 결함이 다른 갈래에 그대로 있었다

`3e96747`은 **행을 새로 만드는 갈래**에서만 격자를 채점에 맞췄다. 근거는 「격자는
확정된 사실이 아니므로 이미 있는 행의 격자를 고칠 근거가 못 된다」였고, **그 문장은
참인데 결론이 틀렸다.**

부분 맵의 등록기 행은 격자로 **그 맵의 셀 bbox**를 들고 있다 — 스펙이 「하한이지
격자가 아니다」라고 못 박은 바로 그 값이다. 그래서 채점은 그 맵의 격자를 빌린다.

**실측(bbox 2,1..6,5 / 바닥 13×13@(0,0)): 채점은 13×13@(0,0) 위에서 돌았고 이 함수는
5×5@(2,1)을 적었다.** 새 행 갈래가 피하려고 만들어진 결함을 기존 행 갈래가 그대로
갖고 있었다.

**⚠️ 술어가 두 갈래에서 다르다는 것이 이 수리의 미세한 부분이다.** 채점은 「빌려야
하는가」를 묻고(확정된 phys는 아니오), 쓰기는 「여기에 써도 되는가」를 묻는다(**잰 값
위에만** 아니오). **재확정이 같은 바닥에서 값을 다시 유도하려면 뒤엣것이어야 한다.**

`borrowed_meta_for`의 `None`은 채점에게 **「이 맵을 제외하라」**는 답인데, 쓰기는
제외할 수 없다 — 조작자가 프레임을 확정했고 그 사실은 남아야 한다. 그래서 phys를 못
빌리면 **격자만이라도 채점과 같게 맞추고 나머지는 그대로 둔다.**

**`auto_registered`는 phys를 다시 쓰면 뗀다 — 다만 격자 출처를 댈 수 있을 때만.**
무조건 떼면 phys에 대한 거짓 진술을 `grid_start_*`에 대한 거짓 진술로 바꾸는 것뿐이다.
`grid_start_*`는 **값만으로는 부재를 나타낼 수 없는 유일한 축**이라, 표지가 없으면
무엇을 들고 있든 `declared`로 읽힌다. 그 가드는 **phys는 선언했는데 격자는 안 읽히는
바닥** 위에서 자기 테스트를 갖는다 — 미실행 코드가 아니다.

**기록 A가 기록 B가 거절하는 프레임을 담고 있었다.** 메타 행 쓰기는 `parse_frame`을
통과해야 하는데 확정 기록 쪽은 아무 문자열이나 받았다. 실측: `frame="rot45_front"`
요청이 **200으로 끝나고**, 확정 기록에는 `rot45_front`가 남고, **메타 행은 아예 만들어
지지 않았다.** 한 요청이 한 기록에만 답을 남기는데 응답은 성공 — 두 기록이 갈리는 가장
조용한 형태다. 게이트는 **두 번째 합법 프레임 표를 만들지 않고** 기록 B가 쓰는 그
함수를 부른다.

⚠️ **일부러 `frames`에는 걸지 않았다.** 저것은 규칙의 `target_fields` 값이고,
`dt_job_lot_slot_attribution`에서는 lot과 slot이 들어간다 — 게이트를 넓히면 **프레임이
아닌 정답을 거절한다.**
