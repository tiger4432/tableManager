# 페이로드 «하나»는 크기 1 인 배치다 — 그래서 제일 짧은 규칙이 돈다

> **레인:** 구현자 · 문서 정비는 응용

## 무엇이 일어났나

`is_batch` 를 «안 적은» 규칙이 세 줄짜리 맵퍼의 모양이다. 좌석은 그런 규칙에 페이로드를
«한 개»씩 건네는데, `payloads_to_df` 가 그 dict 의 «키»를 걸었다. 운영자가 읽은 것은
SDK 안쪽에서 나온 `AttributeError` — 그들이 «적을 수 있는 칸»을 아무것도 이름 대지 않는 문장이다.

## 이름의 복수형은 «크기»이지 «요구»가 아니다

```
크기 1 을 `payloads_to_df` «한 자리»에서 접는다
그래서 문 둘(SDK · 위임하는 BaseMapper)이 «다르게 답할 수가» 없다
페이로드가 «정말 아닌» 항목은 이제 루프 안에서 터지지 않고 «이름으로 거절»된다
```

## 되돌리면 «먼저 우는» 곳

게이트를 SDK 에 dict 를 직접 건네서가 아니라 `rule_run` 을 «지나서» 쟀다 —
모양을 정하는 반쪽은 팬아웃이고 그건 다른 파일에 산다. 그 자리에서 재지 않으면
「고쳤다」가 실제 경로에 대한 말이 아니게 된다.
