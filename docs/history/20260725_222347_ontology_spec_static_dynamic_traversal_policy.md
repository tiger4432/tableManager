## 배경

Eqp·Recipe 같은 **공유 마스터 노드는 필연적으로 슈퍼 허브**가 되며, 이를 경유하는 순진한 탐색은 무관한 제품 이력으로 컨텍스트가 범람(cross-talk)하고 서브그래프가 폭발한다. 사용자가 별도 세션에서 도출한 대응 설계를 스펙 §7.5c로 수렴했다.

## 변경 내용 (스펙 서술 — 구현은 미착수)

### 노드 이원 분류 — 매핑 config `node_class` 필드 (필수 예정)

| 분류 | 정의 | 예시 |
|---|---|---|
| **dynamic** | 타임스탬프를 갖고 특정 개체 컨텍스트에 귀속되는 이벤트/인스턴스 | Chip, Wafer, ProcessEvent, EqpState … |
| **static** | 시간 불변에 가까운 공유 기준 정보(마스터) = 슈퍼 허브 후보 | Eqp, Base, Recipe, Line, Map … |

```jsonc
"node": { "label": "Chip", "identity": "log_id", "props": ["bx", "by", "cx", "cy"],
          "node_class": "dynamic" },   // ← §7.5c 정적/동적 분류 (필수 예정)
```

### 4대 탐색 정책 (그래프 쿼리 API 계층에서 강제 — 저장소 아님)

| # | 방향 | 정책 |
|---|---|---|
| 1 | 동적 → 동적 | 🟢 허용 (깊이 cap 내) — 백본 추적 |
| 2 | 동적 → 정적 | 🟢 허용 (**1-hop 한정**) — 로컬 컨텍스트 ROI 결합 |
| 3 | 정적 → 정적 | 🟢 허용 (**1-hop 한정**) — 마스터 계층 판독 |
| 4 | 정적 → 동적 | 🚫 **기본 금지** — 슈퍼 허브 범람 원천 차단 |

- 정책 4 예외: **영향도 분석 모드** — 출발 노드가 정적이면 S→D 1단계 허용하되 시간 창/개수 상한 필터 강제.
- **2단계 백본→ROI 추출**: ① D→D 백본 확정 → ② 백본 노드에서 D→S 1-hop ROI 결합. 멀티 시드는 컨텍스트 토큰 태깅으로 시드별 경로 격리.
- **EqpState 허브앤스포크**(§7.5b 접합): `[Run] →(1:1) [EqpState(시간 슬롯)] →(N:1) [Eqp]` — topology만으로 시간대 격리, 동시성 판별 = in-bound Run ≥ 2.
- **슈퍼 허브 pruning**: degree 임계(예: 1,000) 초과 노드 진입은 쿼리 계층에서 절단 + 개수 보고.
