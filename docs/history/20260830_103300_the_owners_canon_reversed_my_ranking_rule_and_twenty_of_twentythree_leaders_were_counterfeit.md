
**quantity 21 중 20 은 대조군이 «잰 적이 없는데» 분모가 `[2,2]` 로 붙는다.**
분자는 «키»별이고 분모는 «타입»별이라, **「안 쟀다」가 「쟀는데 없었다」로 읽힌다.**
정본이 이름 붙인 **가짜 감쇄 셋째 — 「없는 0 을 무해한 0 으로」** 그대로다.

```

quantity  안 잰 물리량은 «노드가 아예 없다»    -> 키 단위 분모를 만들 재료가 없다
                                            = 종점 노드 문제. 소유자 판정 자리다
```

## 계측을 «노드로» 세우는 지시서 — 그리고 왜 «둘»이어야 하나

`a0a9b8a3`. 소유자가 계측을 노드로 만들라고 판정했고, **모양은 이미 소유자의 것**이었다 —
`ONTOLOGY_GRAPH_SPEC` §7.5b 가 기능적 온톨로지와 계측 시그니처를 들고 있고,
**설계됐지만 한 번도 실체화되지 않았다**고 표시돼 있었다.

키를 정한 것은 측정이다.

```

wafer 로만 묶으면    노드가 «웨이퍼별» -> 대조군의 계측은 «다른 노드» -> 분모가 영원히 0
                    = 이 라운드가 «치료 중인 병»을 자리만 옮긴 것

=> 공유 station  (step, eqp)                 63 노드     «분모»가 서 있을 자리
   run          (wafer, step, eqp, time)  24,070 노드     «사건»
```

🔴 **station 은 `param` 을 실으면 안 된다.** 그런 노드에 닿는 것 자체가 「값이 존재한다」를 뜻하게 되어
**분모가 분자와 같아진다.**

**새 표도 새 소스도 없다** — `process_param_num` 에 컬럼이 이미 있고 읽는 소스 둘이 **행 단위**다.
그래서 `lot_event` 의 `in_slot` 이 부딪히는 벽에 부딪히지 않는다.
