## 변경 내용 — «다리»가 지어졌다 (`545e0e42`)

CLAUDE.md 가 허용한 «덧붙이기»의 근원 템플릿이다. 지금까지 그런 헬퍼가 **없었다.**

```javascript
  // 🔴 THE ASSERTION THAT KEEPS THIS FROM BECOMING SLICING AGAIN. Nothing is removed, so
  //    the copy must start with the original byte for byte. If a future edit "just tidies
  //    one import away", this throws instead of quietly measuring a different program.
  if (!body.startsWith(original)) {
    throw new Error('appended copy does not start with the original bytes — '
      + 'something was removed, which makes this slicing again');
  }
```

```
사본 자리    원본 «옆». 상대 import 가 «그대로 풀려야» 하기 때문 —
            다른 데 두면 그 import 들이 죽고, 고치려던 그 병을 «다시 만든다»
퇴화 단언    «헬퍼 «안»»에 있다. 밖에 두면 스무 곳 남짓이 각자 사본을 만들고
            그러면 병이 «이름만 바뀐다»
정리        `finally` 에서 사본을 지운다 — 남으면 다음 사람의 `git status` 에 «남의 것»으로 보인다
```

🔵 **주장이 아니라 증명으로 자리를 잡았다** — `map_editor.js` 는 import 되고 export 가 없으므로,
`VALID_DIE_TABLE` 과 `applyPhysicalGeometry` 에 «한 줄도 안 자르고» 닿는 길이 덧붙이기다.

그리고 하니스가 **닿는 것보다 «퇴화 가드»를 더 무겁게 채점한다** — 닿는다 단언 «셋», 무언가
제거된 사본을 «거절»한다 단언 «다섯», 파일을 안 남긴다 «하나».
그리고 `valid_die_ref` 값을 **적어 두지 않는다** — 선언의 값을 되뇌는 하니스는 «선언이 바뀌는 날»
옛 값으로 초록을 유지한다.

## 2-b — 계획이 가정한 것보다 «답이 작았다» (`5191d083`)

```
계획   DOM 스텁이 필요할 것이다

=> vm 샌드박스가 하던 일 중 «가장 큰 조각»이 재구현되는 대신 «사라졌다»

🔵 그리고 이것이 총괄이 요구한 「시끄러움」을 **던지는 스텁보다 더 엄격하게** 만족시킨다:

```

=> DOM 에 손 뻗는 것은 «즉시» ReferenceError 로 죽는다
   조용히 초록으로 만들 «관대한 스텁»이 하나도 안 남는다

**조각이 아니라 «진짜 함수»를 돌려서 증명했다** — `currentFrame` 이 프레임을 돌려주고,

그 거절은 **환경의 구멍이 아니라 모듈 «자기 계약»이 프레임 인자를 요구하는 것**이다.

⚠️ **출하되는 것은 하나도 안 달라진다** — 접근자는 «사본»에만 있고 사본은 `finally` 에서
지워지므로, `map_editor.js` 는 쓰기 표면을 «얻지 않는다».
