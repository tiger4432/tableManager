- `row_axis.label`이 행 헤더가 됐다 — `y=`로 축이 바뀌므로 하드코딩 라벨은
  오라벨이 된다.
- **R-G의 「채점 불가」 필드는 존재하지 않았다** — HEAD와 서버 레인의 미커밋
  트리 둘 다 확인, 비ready 상태는 `unmeasurable`(관계 부재)뿐. 클라는 그것을
  **유도하지 않았다.** 대신 일반 경로(모르는 상태도 서버의 사유로 렌더)를 짓고,
  선언이 생길 때까지 지표에 대한 주장이 아니라 **이 응답에 대한 사실**을 쓴다:
  「이 응답에서 칠해진 칸 0 / 3 · 최대 1.06×, 첫 문턱 2배」. 단언 셋이 선을
  지킨다 — 관측은 «불가»라고 말하면 안 되고, 칠해진 열엔 플래그가 없어야 하고,
  선언이 오면 관측을 «대체»해야 한다(중복 금지).
- 슬롯 스트립은 서버의 `frame_ambiguous_across_slots` 거절에서
  `frame.available_slots`를 읽는다 — 클라의 목록 생성기는 삭제, 문구는 서버
  문장 그대로.
- `frame.valid_die_ref`는 **존재만 보고하고 어느 맵인지 고르지 않는다** — 키
  공간이 (product, type) 대 {lot}_{slot}으로 만나지 않으므로, 등록 격자에
  그리고 「유효 다이 마스크 미적용」이라 말하며 「유효 다이 0」은 절대 찍지
  않는다.
- 가짜 기저 `1.554`는 출하 소스에 없음을 grep으로 검증, 돌아오면 하니스가
  죽는다.
