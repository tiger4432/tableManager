# 에이전트 산출 텍스트 언어 규약 — 영어로 통일

> 커밋 `6ac2ac9` · 2026-07-26 22:41 · 도메인 Process / 멀티 에이전트 운영
> 상위: [agentic_environment](../process/agentic_environment.md) · 규율: [CONTRIBUTING](../process/CONTRIBUTING.md)

## 배경

사용자 지시. 에이전트끼리 주고받는 텍스트(보고서·지시서·커밋 메시지·코드 주석)와 사용자가 읽는 텍스트(UI 문구·프로젝트 문서)가 뒤섞여 있었다. 기준을 **"누가 읽는가"** 하나로 정리한다.

## 변경 내용

`agent_workspace/memory/*.md` 5개 교훈 파일(`client-pm`, `server-pm`, `doc-keeper`, `qa-reviewer`, `ui-designer`)의 **공통 절 맨 위**에 같은 규약을 실었다. 각 에이전트가 착수 시 교훈 파일 전체를 Pre-Flight로 로드하므로, 규약이 매 작업 시작 시점에 확실히 걸린다.

```markdown
> **언어 규약 (사용자 지시 2026-07-26): 에이전트가 산출하는 텍스트는 모두 영어로 쓴다.**
> 대상 — ① `agent_workspace/reports/**` 보고서 ② 코드에 새로 쓰거나 수정하는 **주석**
> ③ 서브에이전트에게 내리는 지시서·메시지 ④ 커밋 메시지.
> 대상 아님 — 사용자에게 직접 보이는 UI 문자열·토스트·에러 문구(한국어 유지),
> `docs/**` 프로젝트 문서, 기존 주석의 일괄 번역(건드리는 줄만 영어로).
```

**대상이 아닌 것**을 명시적으로 열거한 것이 규약의 핵심이다. 특히:

- **`docs/**`는 한국어를 유지한다** — 사용자가 읽는 산출물이지 에이전트 간 통신이 아니다.
- **기존 주석의 일괄 번역은 금지** — 건드리는 줄만 영어로 쓴다. 번역 커밋은 diff를 오염시키고 리뷰 비용만 늘린다.
- UI 문자열·토스트·에러 문구는 최종 사용자가 읽으므로 한국어를 유지한다.

## 아키텍처 영향

코드·설정 무변경. 운영 규약만 바뀐다. 이 사이클 이후의 보고서(`agent_workspace/reports/**`)와 커밋 메시지가 영어로 전환되며, 이 문서를 포함한 `docs/**`는 한국어를 유지한다.
