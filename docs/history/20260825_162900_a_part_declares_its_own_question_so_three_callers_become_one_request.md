## 아키텍처 영향

- **후보 질문이 선언 하나**다. 세 자리가 같은 선언을 읽으므로 요청도 하나다(13).
- `follow`는 **엣지 필터가 아니라 경로 제약**이다 — 중간 홉을 빼면 목적지가 통째로 사라진다.
- 데스크톱 배포가 **라우트 하나 + zip 하나**이고, 부재는 부재로 답한다.
