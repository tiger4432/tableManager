# 범위 개정 — 소스→원장 먼저 단단하게, 편의층은 그 뒤

> 2026-08-17 11:58 · Docs / Plan · 커밋 `09d07a4`

## 배경

30분 전 `84bd418`이 7단계 지시서를 세웠는데, 소유자가 즉시 범위를 좁혔다:
사전·마법사·검사기·현황판(3·4·6단계와 5단계 일부)은 전부 **소스→원장 신뢰
위의 편의층**이므로, 토대인 1·2단계(+ 필요시 백필 라우트만)를 먼저 완주한다.
계획이 선 지 반 시간 만의 개정이라 별도 문서가 아니라 `00_MASTER_PLAN.md`에
개정 절로 남겼다.

## 변경 내용

`00_MASTER_PLAN.md`에 12줄 추가. 「단단하게」를 감상이 아니라 **측정 가능한
셋**으로 정의했다:

```
「단단하게」의 정의 (이 순서로 증명):
1. 등가 — 같은 행은 legacy와 mapper에서 같은 원자가 된다(1단계 하니스 실측).
2. 완비 — 현행 유입 경로 전부에 대응 Pack이 있고, 각 Pack의 전제(run 표·
   키·시각)가 선언에 명시된다(2단계).
3. 불변 — 게이트·드라이런·해소 문법은 mapper 경로에서도 한 글자도 다르게
   동작하지 않는다(기존 계약 보존 — v2 규칙 6).
```

## 아키텍처 영향

실행 순서만 바뀌었고 7단계 구조 자체는 유지됐다. 편의층(UI·사전·검사기)이
토대 증명보다 앞서 착지하는 경로가 계획 수준에서 차단됐다.

## 그때 남아 있던 것

- 1·2단계도 아직 미착수 — 이 개정은 착수 순서의 선언이다.
- 「필요시 5단계의 백필 라우트만」의 «필요시» 판정은 열려 있었다.
