## 시간을 실제로 잡아먹는 실패는 「없는 함수를 가리키는 앵커」다

**`saveValidDieRefDeclaration()`은 `5b15c24`에서 삭제됐다.** 후임
`saveMapSpecOnly()`는 **같은 계약이 아니다** — 옛 항목은 「서버 사본에서 파생된
화면만 저장할 수 있다」고 적혀 있었는데, 새 함수는 **일부러** `loadedIdentity`가
아니라 **현재 컨트롤을 읽고**, 필드 하나가 아니라 **규격 블록 전체를 쓴다.**
옛 항목을 따라간 독자는 **의도적으로 없어진 가드를 놓고 추론하게 된다.**

`crud.refuse_notation_derived_columns`도 `8d306a5`에서 삭제되고 묘비 주석만
남았다. 그래서 「쓰기 가드 둘이 앞단에 있다」는 서술은 **이제 하나다.**

## 스펙 §0.3 — 단계 0과 1을 합쳤다. 나눌 수 없다는 것이 측정됐기 때문이다

프레임 심볼 16개 중 **순수한 것은 4개**뿐이고, 나머지 12개가 `el`·`currentRotation`·
`physFrameOverride`를 읽는다. **하네스 15개가 잘라 가는 것이 정확히 그 12개다.**

절충안이 **구조적으로** 실패한다: `import`된 함수는 **자기 모듈 스코프를 닫아
버려서 샌드박스가 심어 놓은 `el`을 영원히 못 본다.** 순수한 부분만 뽑아내면
슬라이스 20개가 없어지고 **전환되는 하네스는 0개다.**

그래서 조립 층이 같은 단계에 들어가고, 분할점은 `resolveGridFrame:5502` —
`el`을 받고, 폼을 읽고, phys 입력 여섯 개를 되쓰는 자리다.

그리고 **어떤 방식으로도 면역인 하네스가 하나** 있다:

```
coord_table_paste_harness.mjs:646 은 'currentCoordFrame(' 이라는
문자열 자체를 단언한다.
```

## diff가 커밋 메시지와 어긋난 자리

- **「앵커 453개 중 275개가 낡음」이라는 문장은 diff 어디에도 그대로 없다.**
  453 = 275(map_editor) + 178(서버)이고, 낡은 것은 246 + 29 = 275다.
  즉 **275가 map_editor 앵커 총수이자 전체 낡은 수로 두 번 쓰인다.** 산수는
  맞지만 문장만 읽으면 어느 275인지 알 수 없다.
- **diff는 메시지가 말하지 않는 일을 더 한다** — 파일 17개의 낡은 규모 표기 정정
  (`vectors.json` 1,477→3,613, `notation_norm.py` 542→808 등), `8d306a5`가
  `server/scripts/rederive_notation_norm.py`도 지웠다는 기록, CLI 경로 6개를
  `scripts/…`에서 `server/scripts/…`로 정정.
- 스펙 단계 표에서 **「20군데」가 설명 없이 「15군데」로 바뀐다.**
