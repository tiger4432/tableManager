# 2026-07-20 00:27:00 - 메인 UI 툴바 레이아웃 간소화 및 설정/메뉴 드롭다운 통합

## 1. 개요 및 동기
* **현상 및 요구사항**:
  * 메인 화면의 상단 제어 바(Controls Area)에 테이블 선택, 데이터 추가/삭제, 설정 체크박스들(Sort Latest, Copy Header), 트랜잭션 옵션, 그리고 다양한 앱 링크들이 너무 빽빽하게 나열되어 시각적 피로감을 유발하고 있었습니다.
  * 창 크기를 작게 조절할 때 레이아웃이 뭉개지거나 줄바꿈되는 상황을 해결하고자, 제어 요소를 성격별로 분류하여 그룹화 및 팝오버 드롭다운으로 압축하는 **UI/UX 간소화 개편**을 진행했습니다.

---

## 2. 세부 개선 사항

### A. 세그먼트 버튼 그룹화 (Segmented Action Group)
* **Refresh 및 행 조작 통합**:
  * 개별적으로 분산되어 있던 `🔄 Refresh`, `➕ Row`, `🗑️ Row` 버튼들을 공백 없는 하나의 유기적인 세그먼트 버튼 블록(`.glass-btn-group`)으로 묶어 배치했습니다.
  * 테두리 병합 및 라운딩 공통 처리를 통해 세련된 조작부 룩앤필을 구현했습니다.

### B. 옵션 드롭다운 (`⚙️ Options`) 통합 도입
* **설정 옵션 압축**:
  * 상단 공간을 많이 차지하던 `👁️ Columns` 토글 버튼, `Sort Latest` 체크박스, `Copy Header` 체크박스, `Tx Mode` 스위치를 단 하나의 **`⚙️ Options` 드롭다운** 패널 속으로 통합했습니다.
  * 옵션 버튼 클릭 시 슬라이드 블러 효과를 지닌 패널(`.glass-dropdown-panel`)이 나타나며, 내부 항목을 클릭하더라도 이벤트 전파를 제어하여 창이 마음대로 꺼지지 않도록 완성도를 높였습니다.

### C. 내비게이션 드롭다운 (`🧭 Menu`) 통합 도입
* **외부 링크 정리**:
  * 테이블 관리와는 성격이 다른 앱 전환 링크인 `🗺️ Map Editor`, `⚙️ Admin Dashboard`, `📥 Download Desktop` 버튼들을 **`🧭 Menu` 드롭다운** 버튼 하나로 압축 정리했습니다.

### D. 트랜잭션(Tx) 제어부의 동적 슬라이드 노출
* **평상시 툴바 비우기**:
  * 평상시 가로 영역을 차치하던 `Apply` 및 `Discard` 단추들을 제거했습니다.
  * 대신 트랜잭션 대기 중인 수정 사항이 생겼을 때만 좌측 Ready 배너 옆에 활기찬 오렌지색 글로우 뱃지(`⚡ Unsaved: N`)와 함께 `Apply`, `Discard` 단추가 동적으로 페이드인 노출되어 저장 유도성과 툴바 공간 효율을 둘 다 극대화했습니다.
