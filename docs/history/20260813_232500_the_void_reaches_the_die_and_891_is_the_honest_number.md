# The void reaches the die, and 891 is the honest number

**Date:** 2026-08-13 23:25 · **Domain:** Server (void↔die 이음새, 합성) · **Status:** 착지 — `aa49167`

---

## 배경

void가 합성 데이터 위에서 자기 레이어의 다이에 닿았다. **레인의 읽기로는 8,607 매칭,
올바른 읽기로는 891 — 그 간극이 발견이다.**

## base 좌표는 계산되지, 발행되지 않는다

모든 base 좌표는 `bond (x, y)`를 그 맵의 `wafer_map_metadata` 행이 선언한 프레임
변환에 통과시킨 상이다 — 기존 프리미티브를 임포트해서:

```python
to_base = map_overlay.make_frame_transform(recorded_meta, base_meta)
```

감사는 생성기의 기억이 아니라 **저장된 메타데이터**(여섯 달 뒤 누군가 읽을 그 행)에서
35,250 좌표를 재유도 — **불일치 0.** 프레임이 하중임은 단언이 아니라 시연됐다: 실제
셀 하나를 여덟 프레임에 통과시키면 일곱 개의 «서로 다른» 답이 나오고 **아무것도
raise하지 않는다** — 틀린 프레임은 실패하지 않고 다른 다이를 이름 댄다.

## 🔴 모델링 선택 하나를 총괄이 교정했고, 추론이 수리보다 값지다

레인은 `stack_height`를 «높이»로 읽고 `gate <= height`로 조인했다 — 근거는 비즈니스
키가 `stack_height`를 생략하므로 한 base 위치에 한 행, 「레이어 인덱스면 그럴 수
없다」는 역산. **그 추론은 거꾸로 돈다**: 키는 결함이다(`c1aa1b9`가 측정·고정 — 다이
12개 들어가 1행 나옴). 미수리 선언에 대한 증거이지 컬럼 의미에 대한 증거가 아니다.
소유자 판정: **레이어 번호다**, SAT의 `gate`와 같은 축. 스키마의 현재 모양을 도메인에
대한 진술로 읽는 것은 픽스처가 자기가 폭로할 결함을 상속하는 정확한 경로다.

`=`가 `<=`를 대체하고 9,110 void 중 891이 다이에 닿는다. 나머지 ~8,200은 소속될 행이
없는 레이어에 앉는다. `<=`는 12개 레이어의 void를 한 다이에 붙여 그것을 사라지게
했다 — 그럴듯한 행, 틀린 답. **891은 더 나쁜 결과가 아니라 `c1aa1b9` 미수리 결함의
측정된 가격이 처음으로 수가 된 것이다.**

## 실제 백필의 블로커 — 찾았고 옳게 우회하지 않았다

기존 5,296행은 base 좌표를 받을 수 없다: 125개 맵 메타가 `auto_registered: true`라
`geometry_computable`이 **이름으로** 거절하고, `phys_chip_x/y = 1`·`phys_wafer_dia =
300`은 자동 등록기의 플레이스홀더다. 실제 웨이퍼의 실제 기하를 누가 선언하기 전까지
대기 — 실물에 대한 결정이라 옳게 놔뒀다.
