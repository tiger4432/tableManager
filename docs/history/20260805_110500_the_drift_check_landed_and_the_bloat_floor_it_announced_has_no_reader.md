## ① enrichment 클라 — 판정 전 게이트를 없앴다

지워진 블록:

```js
-  if (!hasDecisionKeys(node.data, S.rule)) {
-    showRefStatus('🚧', '판단키 없음 — 조회 불가', ...);
-    return;
-  }
```

이제 **어느 키 컬럼이 비었든 상관없이 모든 참조 뷰를 요청**하고, 결정 키를 **그대로**
보낸다(`''`를 걸러내던 변환도 없앴다).

> **공백을 어떻게 접을지는 서버의 규칙 하나로 남는다.** 클라에 두면 그것이
> **두 번째 구현**이 된다.

행이 판정 하나로 접히지도 않는다 — **같은 행에서 뷰 A는 이름을 대고 거절하고 뷰 B는
답할 수 있다.** 거절 문장은 **서버 것을 그대로** 렌더하고, 화면에는 한 줄,
레코드 전체는 콘솔로 간다.

## ② 스키마 드리프트 — 코드가 기대하는 스키마를 DB가 갖고 있지 않을 때의 가드가 아예 없었다

그것이 **추가 컬럼 하나가 테이블 하나를 통째로 내려앉힌** 경로다.

`check_schema_drift.py`(178줄)는 SQLAlchemy가 매핑한 **모든** 테이블을 —
시스템 테이블과 `table_config.json`에서 만들어지는 동적 테이블 둘 다, 양쪽 다
`Base.metadata`에 살기 때문에 — 정보 스키마와 대조하고, **드리프트마다 무엇이
깨지고 무엇을 해야 하는지를 이름으로 적는다.** 쓰지 않고, **타입이 아니라 이름을**
비교한다. 종료 코드는 0/1/2.

가정보다 나빴다는 것이 실측됐다: **컬럼이 없으면 전체 엔티티 SELECT가 실패하고,
그 속성을 한 번도 세팅하지 않아도 ORM INSERT까지 실패한다.** 즉 화면만이 아니라
**인제션에 닿는다.**

**새 테이블은 안전하고, 기존 테이블의 새 컬럼은 아니다.**

## ⚠️ ③ 블로트 경보 — 커밋 메시지가 말하는 수리가 코드에 배선되지 않았다

이것이 이 커밋에서 가장 중요한 대조다.

커밋 메시지는 이렇게 적는다 — 경보가 **비율 전용**이었고, 살아 있는 행이 0인
테이블에서 dead/live는 **정의되지 않으며**, 그래서 비워지도록 순환하는 큐나
아웃박스는 **죽은 행을 영원히 쌓으면서 한 번도 경보를 울리지 않는다.**
`database_outbox`가 **죽은 행 11,734 · 산 행 0 · autovacuum 이력 없음**으로 앉아
있었고, **시스템 전반 저하가 블로트로 추적된 바로 그날 이 스크립트는 DB가 깨끗하다고
말했다.** 진단은 맞다.

**그런데 `diagnose_db_health.py`의 16줄 diff는 상수와 그 주석이 전부다.**

```python
+DEAD_ABSOLUTE_FLAG = 1000
```

이 커밋 시점 **`DEAD_ABSOLUTE_FLAG`를 읽는 곳이 트리에 없다.** 정의된 줄 하나가
유일한 출현이다. 표시를 세우는 코드는 **바이트 단위로 이전과 같고 여전히 비율
전용**이다:

```python
            flag = "  <-- " if (ratio or 0) >= BLOAT_RATIO_FLAG else "      "
            if (ratio or 0) >= BLOAT_RATIO_FLAG:
                worst.append(name)
```

`database_outbox`의 비율은 `NULL`이므로 `(ratio or 0) = 0 < 0.20`이고, **이 커밋
뒤에도 `worst`에 들어갈 수 없다.** 헤더도 여전히 비율로 인쇄한다. 절대 1,000이
쓰이는 유일한 자리는 **이 커밋 이전부터 있던 SQL의 `WHERE n_dead_tup > 1000`**이고
그것은 무엇을 조회할지를 정할 뿐 무엇을 경보할지를 정하지 않는다.

> **이 저장소는 「안전 필드에 독자가 0이었다」를 이미 한 번 기록했다**
> ([`20260804_072450`](./20260804_072450_the_safety_field_had_zero_readers_and_a_hand_rolled_predicate_undid_it.md)).
> 같은 모양이 상수 하나로 다시 나타났다.

**진단 자체는 재사용 가치가 있다** — 정규화가 분모를 버렸고, **분모가 사실이었다.**
이것은 정렬 순위를 뒤집던 커버리지 백분율과 **같은 모양**이다.

## ⚠️ 그리고 `deferred()`는 diff에 없다

커밋 메시지는 `deferred()`를 **시험했고 기각했다**고 적는다 — 읽기는 고치고 쓰기는
깨진 채로 두므로, **시끄러운 전면 실패를 조용한 부분 실패와 맞바꾼다**는 이유다.
**그 문자열은 커밋 메시지에만 있다.** 어떤 훅에도, `check_schema_drift.py`에도,
주석에도, 테스트에도 없다.
