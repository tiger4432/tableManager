# No route master — the order is read, never declared

**Date:** 2026-08-14 13:28 · **Domain:** 프로세스(본질 정본 — 공정 순서) · **Status:** 기록만 — `22bb116`

---

자유 순서 공정이 어떻게 온톨로지화되는가를 소유자가 확정했다: 공정은 순서
스왑·스킵·회차가 자유라 **순서를 선언하는 순간(route master) 그 선언이 첫
재작업에서 거짓말이 된다.**

- 실제 순서는 원자들의 `occurred_at`으로 이미 기록 — 저장할 것이 아니라 읽으면
  나오는 것.
- **컨텍스트 = 파생 특징**: 서열 서명·문맥 위치(본딩 앞/뒤 CMP, 몇 회차)·간격을
  선언된 추출기가 요인화 — 「같은 공정도 언제 하냐에 따라 다름」은 코드가 아는
  것이 아니라 순서 차이가 요인이 되어 데이터가 말한다.
- **스킵은 route 없이 대조가 잡는다** — 「정상군 94%는 지났는데 이 랏은 안
  지남」이 결측/경로 부류로 뜬다.
- 기대 선언은 절대 위치 금지, **조건부만**(「CMP를 지났으면 두께」) — 순서가
  바뀌어도 안 깨진다. 기전 그래프도 무순서.

층위가 한 줄로 닫혔다: **이벤트(원장, 불변) → 컨텍스트(추출기, 파생) →
의미(대조·관문, 판정).**

## 그때 남아 있던 것

- 경로 특징 추출기는 이 시점 선언도 구현도 없다(브리프 R7 대상). 당일 스트레스
  로그 S-003이 이 블록을 근거로 순서 뒤섞임 시나리오를 ✅ 처리됨(구조로)으로
  판정했다.
