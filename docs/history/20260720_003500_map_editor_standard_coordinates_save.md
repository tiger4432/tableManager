# 2026-07-20 00:35:00 - 맵 에디터 저장 시 표준 좌표계(Standard Coordinates) 강제 변환 및 저장 기능 적용

## 1. 개요 및 설계 사상
* **목적**:
  * 사용자가 맵 에디터(Map Editor) 상에서 편의에 따라 맵을 회전(`rotation=90/180/270`)하거나, 단면을 뒤집고(`side="back"`), Y축 반전 및 X/Y 오프셋을 조정한 상태로 웨이퍼 데이터를 그리더라도, **데이터베이스에는 무조건 정규화된 표준 좌표계(Standard Coordinates) 형태로 통일하여 저장**되도록 보장합니다.
  * 표준 좌표계는 다음과 같이 정의됩니다:
    * `rotation = 0`
    * `side = "front"`
    * `grid_start_x = 0`, `grid_start_y = 0`
    * `grid_y_invert = false`
  * 표준 좌표계의 화면/시각 좌표는 기하학적 정렬 상 물리 좌표 `(xp, yp)`와 완벽히 1대1 일치합니다.

---

## 2. 세부 구현 사항

### A. 맵 에디터 저장 로직 수정 (`client2/src/map_editor.js`)
* **좌표 역변환 적용 (`pushMapData`)**:
  * 기존에는 사용자의 현재 화면 눈금에 기입된 시각 좌표 `visual.x`, `visual.y`를 그대로 DB의 X, Y 컬럼에 기입했습니다.
  * 개선 후에는 화면에서 어떤 설정이 활성화되어 있든 관계없이, 각 셀의 **물리 좌표 `physical.x` 및 `physical.y`**를 추출하여 DB의 X, Y 컬럼에 밀어 넣습니다.
* **표준 메타데이터 강제 저장**:
  * 데이터베이스의 `grid_metadata` 컬럼에는 항상 표준값으로 고정된 설정 개체가 기입됩니다:
    ```json
    {
      "grid_cols": cols,
      "grid_rows": rows,
      "grid_start_x": 0,
      "grid_start_y": 0,
      "grid_y_invert": false,
      "rotation": 0,
      "side": "front"
    }
    ```
