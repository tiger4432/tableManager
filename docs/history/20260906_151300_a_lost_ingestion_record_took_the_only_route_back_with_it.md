## 무엇이 걸려 있었나

`FileIngestionLog` 행이 «없으면» 그 파일은 `/failed` 에 «안 뜨고» Retry 버튼이 «없다».
원장 쪽 FAILED 체크포인트는 봉인된 채라 스윕도 그 파일을 다시 안 집는다.

```
=> 파일은 «영영 안 들어오고», 화면은 「실패 없음」이라고 말한다
   즉 실패한 기록 쓰기가 잃는 것은 «문장»이 아니라 «유일한 복귀 경로»다
```

status 도 안 대서 **행동으로 옮길 수가 없었다.**

