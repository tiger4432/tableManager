# 버튼이 «부품»이 됐다 — 그리고 인라인 하나는 «선언»이 되어 살아남았다

> **커밋:** `1cfff4e7` (17:49) · `40a9f6f5` (18:00)
> | **일자:** 2026-09-05
> **레인:** 디자인
> **측정 상자:** 이 워크스테이션. **운영이 아니다.**

## 배경 — 한 화면에 버튼 모양이 «열여섯»이었고, 내가 범인을 틀리게 지목했다

이날 이 축은 「버튼이 열여섯 모양이다」에서 시작했다. 처음 내놓은 원인은 **문맥 선택자**였다.

```
🔴 실측하니 그 선택자는 padding 을 «하나도» 안 세운다
   원인은 인라인 스타일 «열둘»이 부품이 소유해야 할 «기하»를 나르고 있던 것
```

⚠️ 그리고 이것이 이날 **세 번째** 「원인은 인라인 스타일이었다」다.
찾는 방식이 갈랐다 — **규칙별이 아니라 «버튼별»로 재서** 나왔다.

## 변경 내용 — 기하는 나가고, «뜻»은 남는다

```
가져간 것   padding · font-size 등 «부품이 소유하는 기하»
남긴 것    accent · success · secondary 색  ->  그 인라인들이 «섞어» 들고 있었다
          font-weight  ->  부품이 소유하는 기하가 «아니었다»
🔴 통째로 벗겼으면 표류와 함께 «뜻»도 지웠다
```

**보이는 변화** — 맵 에디터의 버튼 여섯이 기본 크기로 커지고 padding 을 공유한다.
🎨 Fill Selected 와 🧹 Clear Selected 가 가장 많이 바뀐다(작고 빡빡한 것 → 보통).
⚡ Push · 📐 규격만 저장 · ⚡ 적용 · 📂 Load 가 `8px 16px` 에 안착한다.
**색은 어디도 안 바뀐다.** 회전 토글과 index 는 그대로 보인다.

### 🔴 `btn-rot` 은 «반대로» 갔다 — 그리고 그것이 증거다

```
4px 는 «표류»가 아니라 «의도»다:  토글 넷이 좁은 한 줄을 공유하고, 기본 padding 은 그 줄을 넘친다
=> 인라인이 «사라진» 것이 아니라 «선언이 됐다»
🔵 그래서 문맥 규칙 «수»가 하나 «늘었다» — 줄지 않고.  그것이 「의도가 살아남았다」의 증거다
```

### 안 보이는 버튼 둘도 했다 — 「도달 가능해지는 날 틀린다」

```
index 의 숨은 버튼 둘은 «보이는 변화가 없다». 그래도 했다:
   보여지는 날에만 무는 인라인은 «도달 가능해지는 날 틀리는 가드»다
```

### 형제 커밋 — 폭 쌍둥이도 «이미 옆에 있던 부류»가 됐다 (`40a9f6f5`)

한 버튼이 `width: 100%` 를 인라인으로 세우고, **바로 옆 버튼은 같은 효과를 `w-full` 클래스**로
내고 있었다. 이제 한 자리다. **보이는 변화 없음** — 폭이 동일하다.

## 이 축이 «닫힌» 근거

```
열 모양  ->  넷.  그리고 넷 중 «이름 없는 것이 없다»
=> 그것이 이 축의 «도착 정의»였다
```

⚠️ **모달 푸터는 그대로 뒀다.** 그 규칙은 «사유가 안 적힌 선언»이고,
「모달 버튼이 툴바 버튼보다 커야 하나」는 **소유자의 질문**이다 — 흡수하면 그 질문에
조용히 답하는 것이 된다.

## 아키텍처 영향

- 버튼 기하가 **한 자리**(스타일시트)에 산다. 마크업의 인라인이 **부품 소유 기하를 하나도
  안 나른다.**
- 「인라인 스타일이 스타일시트를 이긴다」가 이 저장소에서 **하루에 세 번** 원인이었다는 것이
  이 라운드로 확인됐다.
- 조립식 규율에서 이 버튼들이 **다른 화면으로 옮겨질 수 있는 상태**가 됐다 —
  기하가 마크업이 아니라 부품에 있다.

## 그때 남아 있던 것

- **표류 둘이 남았고 이름이 적혔다** — 헤더의 radius(선택자를 다른 컨트롤 셋과 공유한다)와
  모달 푸터의 font-size. **둘 다 인라인이 아니라 문맥 규칙**이라, 이 라운드가 겨눈 원인
  «밖»이다.
- 모달 푸터의 크기 질문은 **소유자 판정 대기**로 남았다.
- `1cfff4e7` 시점에 문맥 규칙 수가 **하나 늘어 있다**(`btn-rot`). 줄어드는 것이 아니라
  늘어난 것이 정상이라는 근거가 커밋에 적혀 있다.
