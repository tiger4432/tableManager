## 무엇이 일어났나

조인과 오토컨펌만 «자기 행을 자기가» 썼고, 체인의 나머지는 바꿀 것을 돌려주면
호출자의 배치가 썼다. 그 차이를 나르던 것이 좌석이 부르기 «전»에 조회하던 등록된 사실
(`writes_itself`)이었다. 둘 다 «제안»하게 되면서 그 사실이 답할 것을 잃었다.

## 그 칸이 «칸 하나»가 아니었다

```
소급이 그 칸으로 «쪽 루프»를 골랐다
  -> 실패한 쪽을 격리하던 팔이 «자기 행을 쓰는 규칙»만 지키고 있었다
  -> 자기 행을 쓰는 것이 0 이 되면 그 팔은 «아무것도» 안 지킨다
  -> 나쁜 쪽 하나가 파일 맵퍼 백필 전체를 다시 죽인다
그래서 격리가 «루프»로 옮겨졌다 — 다음 라운드로 미뤄 뒀던 것을 이 라운드가 강제했다
운영자 동의 화면도 같은 사실에서 «단위»를 골랐고, 이제 있는 단위 하나를 센다
```

## 이 라운드가 «드러낸» 것 둘 — 그 칸 얘기가 아니었다

```
소급이 제안 항목을 «업무 키만으로» 다시 지었다 -> id 로 행을 짚는 맵퍼가 정체성을 잃고
   키 게이트가 배치를 통째로 거절했다 (거절문이 «쪽마다» 그 컬럼을 이름 댔다 — 실측)
조인 셀을 «철회 가능»하게 만드는 도장을 떨어뜨렸다 -> 백필된 셀만 철회 불가가 될 뻔했다
```
그리고 「자기가 트리거 경로다」라고 독스트링에 적은 하니스가 그 경로를 «쓰기 단계 없이»
다시 구현해 두고 있었다 — 아무것도 확인하지 않았고 아무 말도 안 했다.
