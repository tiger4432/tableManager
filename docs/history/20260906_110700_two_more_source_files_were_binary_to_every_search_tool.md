# 검색 도구에 «이진»으로 보이던 소스가 하나가 아니라 «셋»이었다

> **커밋:** `8121549e` (11:07) · `78a88e7f` (10:40, `map2/main.js` 를 같이 고쳤다)
> | **일자:** 2026-09-06
> **레인:** 구현자(클라)
> **측정 상자:** 이 워크스테이션. **운영이 아니다.**

## 무엇이 일어났나

`map2/main.js` 의 NUL 바이트는 «혼자»가 아니었다. `client2/src` 를 NUL 로 훑으니 셋이
나왔고 하나는 PNG(정당한 이진)였다. 나머지 «둘»이 소스다:

```
src/enrichment.js       1,279줄이 ripgrep 에 «안 보인다»
src/map2/authoring.js     395줄이 «안 보인다»
+ map2/main.js
=> 합쳐 «4,288줄» 을 모든 검색 도구가 «조용히» 건너뛰고 있었다
```

🔴 **그래서 이 트리에서 잰 「0 히트」는 «자기가 말한 트리»보다 «작은 트리»에 대한 답이었다.**
개수를 세는 모든 감사가 그만큼 «덜 센» 것이고, 그 사실이 어디에도 안 적혀 있었다.

## 그 NUL 은 «실수가 아니다» — 그래서 지우지 않고 «이스케이프»로 썼다

```
하나   컬럼 서명을 만드는 «조인 구분자»
하나   「부재」 표지 — «타이핑할 수 없어야» 선언된 값이 부재와 «같아질 수 없다»
=> 런타임 문자열은 «동일»하고, 인쇄 가능한 문자로 바꾸면 «왜 틀리는지»를 각 자리 옆에 적었다
```

## 🔵 그리고 «두 번째 결함을 보고할 뻔했다가 안 했다»

`enrichment.js` 가 그 콘솔에서 깨진 글자로 렌더링돼 «인코딩이 망가진 것»처럼 읽혔다.
**유효한 UTF-8 이었다.** 깨짐은 터미널의 코드페이지였고, 고쳤다면 **멀쩡한 파일을 다시 쓸**
뻔했다.

## ⚠️ 그리고 이 착지가 «문서 하나»를 낡게 했다

`docs/architecture/SYSTEM_FLOWS.md:670` 이 여전히 「`map2/main.js` 에 NUL 이 있고 grep 이
이 파일을 건너뛴다」를 «현재형»으로 말한다. 2026-09-07 실측: 그 파일에 NUL 이 «없다».
낡은 것이 아니라 **거짓**이고, 읽는 사람에게 «없는 사각»을 우회하게 만든다.
