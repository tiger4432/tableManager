단계별 지시서**로 묶었다 — 코드 변경은 없다.

## 변경 내용

`ledger_setup_migration_plan/` 폴더 신설, 11파일 430줄. 7단계 구성:

| 단계 | 산출 |
|---|---|
| 01 | 소스별 전환표 + **등가성 디프 하니스** (디프 없는 일괄 전환은 소망일 뿐이라는 전제) |
| 02 | 현행 세계를 덮는 Pack 7종 계약 — 한국어 메타데이터가 3단계 사전의 원천 |
| 03 | 사전 API + 「답할 수 있는 질문」 렌더 (P-01·02·03 종결) |
| 04 | 마법사에 인터뷰 정문·문장 판정 (v2 04 계약은 불변, 앞뒤 한 층씩) |
| 05 | 파이프라인 현황판 + 백필 라우트 (P-04 종결) |
| 06 | 합의 검사기 — 선언을 라이브 원자 잎과 실측 대조, «영원히 조용»의 종결 |
| 07 | 소스별 등가 증명 후 legacy 번역기 일괄 은퇴 |

`COMMON_RULES_DELTA.md`가 v2 공통 규칙에 셋업 4금칙(자유 기입 금지·실물 없이
묻지 않기·결핍은 이름으로·추정은 추정으로 표시)과 전환 2금칙을 추가했다:

```
5. 등가 증명 없는 전환 금지. 소스 하나를 mapper로 넘길 때는 같은 행을
   legacy와 mapper 양쪽에 태워 원자 봉투를 디프한다.
6. 은퇴는 마지막에, 한꺼번에. 병행 기간 중 legacy 경로 수정 금지(동결).
```

`APPROVAL_MESSAGES.md`는 단계마다 실측을 채워야 하는 승인 게이트 문장을
고정했다. 코드에 막혀 있는 부분(주어 타입·불량 종류 선언화, R-O 뿌리 키)은
단계에 넣지 않고 판정 대기 목록으로 분리했다.
