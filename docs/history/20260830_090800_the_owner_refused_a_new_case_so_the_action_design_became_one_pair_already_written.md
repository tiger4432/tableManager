## II-a 가 갈렸다 — 「원자 0」이 「소스 없음」을 뜻하지 않는다

```

넷째 in_slot 이 엔진에 거절된다 — 문장 매퍼는 역할당 스칼라 하나를 주는데

```

```

원장 쪽에서 보면 «똑같이 생겼고», 취해야 할 행동은 «정반대»다
=> 둘을 가르는 것은 «수»가 아니라 «실행»이다 — 번역을 돌려서 분자와 거절을 읽는다
```

### ⚠️ 시도했다가 «되돌린» 수리도 같이 기록됐다

`in_slot` 을 행 단위 declarative 소스로 옮기는 것을 시도했다.

```

번역        «안 된다» — 행 경로는 프레임 «전체»를 정규화하는데
           lot-event-live-frame 이 numpy 플래그 컬럼을 낸다
           그 스칼라 중 numpy «만» 숫자 타워에 등록돼 있지 않다
           그리고 그다음엔 바인딩이 읽지도 않는 컬럼에서 NaN
```

**둘 다 절반 착지로 두지 않고 되돌렸다.** A-1 은 선언 편집이 아니라 **벽이 이름 붙은 구현 라운드**로 남았다.

## 🔴 소유자: 「케이스로 쪼개지 말고 근본 원리를 찾아라」 — 원리는 «어젯밤 것»이었다

`cd8945ed`. II-a 를 「소스 없음」/「소스 거절됨」으로 쪼개는 것은 **분모가 없는 자리에 갈래를 하나 더 만드는 일**이었다.
대조에 대해 전날 밤 이미 쓴 문장이 그대로 답이다.

```
대조   reach 0    분모 reachable    닿을 «수» 있었나
액션   atoms 0    분모 molecules    «시도되기라도» 했나

한 문장:  0 은 자기에 대해 아무 말도 안 한다. 분자를 «분모와 함께» 보고한다
0/0  시도된 적 없음        0/N  시도됐고 매번 거절됨        M/N  돌고 있음(액션이 아니다)
=> in_slot 은 0/N 이고, 갈래는 «필요 없다»
```

같은 모양이 분류를 **키우지 않고 덮었다.**

```
I-c    닿은 것 / 닿을 수 있는 것       <- 이미 출하돼 있다
II-a   원자 / 분자
II-b   읽은 컬럼 / 있는 컬럼
III-a  1층 구성원 하나 / 여럿
III-b  잰 항목 / 잴 수 있는 항목      <- 규칙 3
```

즉 **선언되는 방아쇠는 조건 목록이 아니라 「분자 · 분모 · 그 쌍을 읽는 법」**이다.

## 중요도는 «세어서» 나왔다 — 점수를 지어내지 않았다

`7fa35f7d`. 상설은 「우선순위는 도달 가능성이지 점수가 아니다」이므로 가중치를 만들지 않고 **셌다.**
심어 둔 픽스처 셋 위에서.

```
                      1층 3 중 분모 0 인 것   전체 중 그런 것
대조군 정상                     1                17 / 157
다리 끊김                       3                23 / 103
대조가 아예 없음                 3                87 /  87
```

두 수가 곧 중요도다 — **이 간극이 1층을 얼마나 무효화하나**와 **답 전체를 얼마나 덮나**.
셋째가 둘째와 갈리는 것은 **둘째 수 하나로**이고, 그것이 「순위가 근거 없다」와
「순위도 근거 없고 나머지도 그렇다」를 가른다. 정렬 기계는 후보들이 쓰는 `_rank_layers` 를 그대로 쓴다 —
**액션용 새 정렬기는 없다.**

⚠️ **그것이 «혼자서는 못 하는» 것도 같이 적혔다.** 정상 대조군 케이스의 분모 0 하나는 `void` 이고,
그것은 **두 집단을 정의한 축**이다. 어느 축이 마킹을 정의했나는 **씨앗 고르는 사람의 기준**이라
시스템이 모른다 — 그래서 세어서 보여 주고, 그 줄은 사람의 판단으로 남았다.

## 결정력은 «같은 쌍»이고, DOE 방아쇠를 흡수했다

`7541e711`. 소유자가 「결정적인 액션과 중요한 액션을 어떻게 구별하나」를 물었다.
판별식은 **대조 쪽 분모가 0 인 항목을 뺀 뒤 1층의 크기**다.

```
0 개 남음   간극을 메우는 것이 답을 «만들어» 낸다      -> 결정적일 «수» 있다
1 개 남음   답은 이미 서 있다                        -> 확인용
2+ 남음    메워도 동점이 남는다                       -> 관측으로 못 가름 = DOE
```

심어 둔 픽스처 셋 + 대조에서 쟀다. 정상 대조군은 근거 있는 둘이 남아 **DOE 로 착지한다** —
교란을 심었을 때 나오라고 기대한 결론 그대로다. 끊긴 다리와 부재 대조군은 0 이 남는다.
그리고 **`follow` 에서 교란 축을 빼면 하나가 남아 판정이 「이미 답해짐」으로 뒤집힌다** —
같은 데이터, 다른 렌즈. 그것이 «세는 것»과 «판정하는 것»을 가른다.

🔴 **규칙이 늘지 않고 «줄었다».** 전날 밤의 DOE 방아쇠는 「분모 0 을 뺀 1층에 둘 이상 동점」이라는
**자기 조건**으로 쓰여 있었는데, 그것이 정확히 「근거 있는 것이 둘 이상」이다.
DOE 는 이제 **결정력에서 파생**되고 옆에 선언되지 않는다.

⚠️ 헤지가 같이 적혔다 — **「결정적이다」가 아니라 「결정적일 수 있다」**다.
분모를 메우면 모든 후보가 `[2,2]` 가 되어 답이 아예 없을 수도 있고, 그건 메우기 «전»에는 알 수 없다.

## 아키텍처 영향

- 보드에 **정본 안건 A~E** 하나가 있고, 옛 표지 여덟은 자기 라운드의 기록으로 남았다.
- 액션 분류가 **케이스 목록이 아니라 「분자/분모」 한 쌍**이다. I-c 를 포함해 다섯이 같은 모양이다.
- 중요도와 결정력이 **같은 분모에서** 나오고, DOE 는 결정력에서 파생된다. 새 정렬기·새 점수 «0».

## 그때 남아 있던 것

- **다섯 분모 중 실제로 호출자에게 닿는 것은 I-c «하나»뿐이다.** 나머지 넷은 셀 수는 있지만
  어떤 응답에도 어떤 실행 결과에도 실려 있지 않다.
- 클라 빌드 게이트 둘이 **빨갛다고 보고된 상태**이고, 총괄의 자체 실행은 이 시점에 진행 중이라
  보드에 **미검증**으로 적혔다.
- `in_slot` 은 여전히 emit 하지 못한다. 행 단위 declarative 로 옮기는 시도는 **되돌려졌다.**
- 액션 발급기는 없다. 있는 것은 원리와 심어 둔 픽스처 셋이다.
