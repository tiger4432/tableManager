# 2026-07-20 01:08:00 - 웨이퍼 맵 에디터 데이터 엑셀 복사(Copy to Excel) 기능 추가

## 1. 개요
* **요구사항**: 에디터 화면에 렌더링된 2D 웨이퍼 맵의 칩 배치 데이터를 복제하여 스프레드시트(Excel) 프로그램에 즉시 붙여넣을(Ctrl+V) 수 있도록 해주는 클립보드 복사 기능을 요구했습니다.
* **설계**: 화면 상의 2D 시각 레이아웃 정렬 형태 그대로 탭(`\t`)과 줄바꿈(`\n`) 문자를 조합한 표준 TSV(Tab-Separated Values) 매트릭스를 클립보드에 적재해 엑셀과의 완벽한 1:1 복사-붙여넣기 인터랙션을 구현했습니다.

---

## 2. 세부 구현 사항

### A. UI 통합 (`🛠️ Edit Grid` 드롭다운 내 배치)
* 복사 관련 작업의 응집도를 고려하여 상단 툴바의 **`🛠️ Edit Grid` 드롭다운**의 세 번째 항목으로 **`📋 Copy to Excel`** 버튼을 추가 배치했습니다.

### B. TSV 행렬 추출 로직 및 클립보드 연동
* **`copyGridToExcel()` 함수 신설**:
  * 2차원 셀 캐시 배열인 `gridCells2D[r][c]`을 순회하며, 각 그리드 칸의 실제 데이터 값(예: `1`, `0`, `E1` 등)을 수집합니다.
  * 빈 격자 칸은 공백 문자`""`로 채워 스프레드시트의 빈 셀로 맵핑되도록 포맷팅합니다.
  * 열 단위는 탭 문자(`\t`), 행 단위는 개행 문자(`\n`)로 병합하여 최종 클립보드 문자열을 조립합니다.
  * `navigator.clipboard.writeText()` API를 활용해 원격으로 클립보드 적재 처리를 수행합니다.
* **피드백 애니메이션**:
  * 복사가 성공적으로 끝나면 버튼의 텍스트가 **`✅ Copied!`**로 1.5초간 변했다가 본래대로 복구되어 사용자 조작 피드백을 극대화합니다.
