
🔴 **근거가 문서 산문에만 있으면, 그 근거를 거짓으로 만드는 커밋이 문서를 «안 건드린다».**
   코드는 바뀌고 문장은 그대로 서 있고, **아무것도 빨개지지 않는다.**
   (CLAUDE.md 상설 ④ 「판정은 «강제되는 자리»에 산다고 «적는다»」가 정확히 이 부류다.)
