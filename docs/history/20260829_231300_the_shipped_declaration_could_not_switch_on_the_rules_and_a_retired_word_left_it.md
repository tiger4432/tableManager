# 출하되는 선언이 그날 밤의 규칙을 «켤 수 없었다» — 그리고 은퇴한 낱말이 선언을 떠났다

## 배경 — 그날 저녁 착지한 걷기 규칙 «둘»이 «선언»을 읽는다

그날 저녁의 규칙 둘은 코드에 낱말을 박지 않고 선언에서 읽는 쪽을 골랐다.
그 선택의 대가가 이것이다 — **선언이 안 적혀 있으면 규칙이 «꺼진 채로» 돈다.**

```
_static_types()             선언에 class 를 단 엔티티가 «하나도» 없으면 -> 빈 집합
_static_step_predicates()   같은 조건에서 -> 빈 집합
die -> wafer 사슬            in_container@1 이 어휘에 «있어야» 건너간다
```

**라이브 파일에는 셋 다 있었고, 출하되는 샘플에는 «하나도» 없었다.**
그래서 새로 체크아웃한 상자는 **같은 코드를 돌리면서 가드 둘이 죽어 있고 사슬이 끊겨 있다** —
그리고 **조용하다.** 빈 클래스 집합은 「이 선언에 허브가 없다」와 **구별되지 않는다.**

🔴 `class: static` 의 공백은 그날 밤 것이 «아니다» — 클래스를 처음 선언하던 날
라이브 파일에만 들어갔고 샘플로 건너온 적이 없다. **그 사이에 빨개진 시험이 하나도 없다.**
`in_container@1` 과 그 매핑 둘만 그날 밤 것이다.

## 변경 — 샘플에 셋을 얹었다

```json
// server/config/sample/ledger_config.json.sample — vocabulary
"in_container@1": {
  "status": "active",
  "subjects": ["die@1"],
  "object": { "kind": "entity_ref", "types": ["wafer@1"],
              "qualifiers": { "required": [], "optional": [] } }
}
```

```json
// 같은 파일 — entities
"quantity@1":    { "keys": ["quantity"],    "class": "static" },
"defect_kind@1": { "keys": ["defect_kind"], "class": "static" },
"recipe@1":      { "keys": ["recipe"],      "class": "static" }
```

그리고 `bonded_from` 소스에 `core-die-in-core-wafer` · `base-die-in-base-wafer` 매핑 둘.

**의미 디프는 추가 «여섯» · 삭제 «0» · 변경 «0»이다.**
텍스트 디프에 보이는 삭제 세 줄은 뒤에 `class` 줄이 붙으면서 `]` 가 `],` 가 된 것뿐이다.
두 문서 모두 라이브 물리 카탈로그에 대해 **오류 0**으로 검증됐다 — 샘플은 그 전에도 0이었고 그대로 0이다.

## 🔴 은퇴한 낱말이 «살아 있는 규칙»으로 읽힐 수 있었다

`36802e42`. `continues` 는 클래스 축이 들어오면서 대체됐다. **읽는 쪽은 갔고 키는 남았다** —
라이브와 샘플 «양쪽»의 술어 여섯에.

```
has_wafer@1 · derived_from@1 · slot_map@1 · transfer@1 · inspected@1 · bonded_from@1
   "continues": true      <- 아무도 안 읽는다
```

**단순한 죽은 값이 아니라 «반대 방향으로» 힘을 실었다.** `continues` 와 `class` 는 **같은 구분**을
서술하므로, 읽는 사람이 여섯을 살아 있는 규칙으로, 클래스 셋을 잔재로 읽는 것이 **합리적이었다.**

삭제 여섯 · 추가 0 · 변경 0. 정리된 선언으로 라이브를 재기동해 다시 쟀다.

```
기준선  SYN-BW-101-16   285 노드 · 373 엣지 · 652 claims   (무변화)
씨앗 대조                같은 1층 · 같은 reach · 같은 reachable 페어
스위트                   47 passed
```

## 아키텍처 영향

- 새 체크아웃이 라이브와 **같은 규칙으로** 돈다 — 정적 노드를 안 펴는 가드, 이름을 좁혀 부르는 가드,
  die 에서 wafer 로 건너가는 다리 셋이 샘플에서도 켜진다.
- 선언에서 **같은 구분을 말하는 낱말이 하나**가 됐다.

## 그때 남아 있던 것

- **검증기는 여전히 `continues` 를 옵션으로 받아들였다.** `setup_bundle._validate_vocabulary` 의
  주석이 「게이트를 먼저 열고 선언을 나중에 청소한다」고 적어 두었고, 이 커밋이 그 «나중»이다.
  받아들이는 쪽을 닫는 것은 이 시점에 서버 소관의 별건으로 남았다.
- 이 결함을 찾은 것은 **검토가 아니라 히스토리 패스**였다. 보드는 이것을 그날의 **같은 부류 넷째**로
  기록했다 — 넷 다 **돌고 있는 DB 에서는 안 보이고 새 환경에서만 보이는** 것들이다.
- `config/backup/**` 스냅샷에는 `continues` 가 그대로 있다.
