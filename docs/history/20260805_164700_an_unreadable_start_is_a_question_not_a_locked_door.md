## 배경 — 가드가 모달 앞에서 멈춰 섰다

레거시 에디터는 원래 **선언이 없는 맵을 열어 운영자가 좌표계를 고르게** 했다 —
표준 합성 프레임이거나, 이미 화면에 있는 패널. `aee05b1`이 넣은 가드가 **그
모달 앞에서 멈췄다**: `grid_start_x/y`가 읽히지 않는 메타 행은 **거절**을
돌려줬고, **운영자는 그 맵을 아예 열 수 없었다.**

```js
// 지워진 가드
      return { ok: false, refusal: refuseUnconfirmedMeta(
        `규격에 START X,Y가 없습니다 (grid_start_x=${JSON.stringify(loadedGridMeta.grid_start_x)}, `
        + `grid_start_y=${JSON.stringify(loadedGridMeta.grid_start_y)})`) };
```

## 진단은 맞고 살아남는다

정의되지 않은 START가 셀 루프로 흘러 들어가 **44셀을 단일 `NaN_NaN` 키로
붕괴시켰고**, Push가 **아무도 고르지 않은 0**을 영속화했다.
**「모르니까 0」은 기본값이 아니다 — 좌표계 전체를 평행이동하는 행위다.**

**결론이 틀렸다.** 조용한 0에 대한 답은 **묻는 것**이고, 묻는 장치는 **가드
스무 줄 아래에 이미 있었다.**

```js
// 대체
      showToast('맵 규격에 START X,Y가 없습니다 — 좌표계를 선택하십시오.', 'warning');
      return { ok: true, gridMeta: null, mapKey: loadedMapKey };
```

**행은 통째로 버린다. 부분이 아니라 통째로** — **고른 원점 아래에서 읽은 절반의
선언은 아무도 선언하지 않았고 아무도 고르지 않은 프레임**이기 때문이다.

`declaredNum` 술어는 **손대지 않았고**(diff 양쪽에 컨텍스트로 그대로 있다),
이제 그것이 라우팅을 결정한다 — **부재와 0의 구분이 여전히 질문 전부**다.
`Number(null)`이 0이기 때문이다.

```js
    const declaredNum = (v) => (v === null || v === undefined || v === ''
      ? null : (Number.isFinite(Number(v)) ? Number(v) : null));
```

## 쓰기 쪽에서 가드가 하중을 받고 있었는지 실측했다 — 아니었다

**모달의 두 버튼 다 셀 루프 전에 읽을 수 있는 정수를 START 칸에 써 넣는다.**
선택 경로 push에서 좌표 왕복 불일치는 **0건**이다. 라우팅은 유지하되 행을 살려
두는 변이는 **단언 24개를 죽인다.**

## 부재의 두 철자는 하나의 결함이 아니다

| 철자 | 증상 |
|---|---|
| **키 자체가 없음** | `NaN`으로 **시끄럽게** 붕괴한다 |
| **명시적 `null`** | **44셀이 서로 다른 다이에 앉고, 성공을 보고하고, 0을 영속화한다. 화면은 맞아 보인다** |

**조용한 쪽이 위험한 쪽이다.** `declaredNum`을 맨 `Number()`로 바꾸면 **`null`
계열만 죽는다** — 그래서 픽스처가 이제 **두 철자를 다** 싣는다.

```js
      F: { label: 'F key-absent', meta: noStart },
      G: { label: 'G start=null', meta: { ...META, grid_start_x: null, grid_start_y: null } },
```

그리고 `PANEL_F`(17×19 @ 2,−4)는 **메타 행(21×21 @ 1,−6)과도 데이터 bbox(8×7 @ 5,−1)와도
일부러 다르게** 잡혀 있다 — 어느 쪽이 쓰였는지가 값으로 갈리게.

## 모달 제목도 정정됐다

`맵 규격 미등록`은 이제 거짓이다 — **행이 등록돼 있으면서도 읽히지 않을 수
있기** 때문이다. `좌표계 미확정`으로 바뀌었다.

## ⚠️ diff가 커밋 메시지와 어긋난 자리

- **「행이 없는 맵과 바이트 단위로 같게 모달로 흘러든다」는 반환값에 대해서만
  참이다.** 새 경로는 진짜로 행이 없는 맵이 내지 않는 `console.warn`과
  `showToast(…, 'warning')`을 낸다.
- **셀 수가 diff 안에서 갈린다.** 지워지는 주석은 `46셀 전부가 NaN_NaN 한 칸으로
  접혔다`라고 적고, 커밋 메시지와 새 주석은 전부 **44**라고 적는다. 같은 측정에
  대해 두 숫자가 한 커밋 안에 있다.
- 「변이가 단언 24개를 죽인다」를 기록한 산출물은 diff에 없다.
