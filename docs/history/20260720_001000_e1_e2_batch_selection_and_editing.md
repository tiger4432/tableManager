# 2026-07-20 00:10:00 - 웨이퍼 최외곽 E1/E2 셀 자동 검출 및 일괄 선택/페인팅 기능 추가

## 1. 개요 및 동기
* **배경 및 요구사항**:
  * 웨이퍼 공정 및 테스트 데이터 가시화 영역에서, **E1 (Edge 1)**과 **E2 (Edge 2)**는 각각 웨이퍼 유효 영역 경계(Circle Boundary)로부터 안쪽으로 1칸, 2칸 떨어져 있는 최외곽 및 차외곽 칩(셀) 레이어들을 의미합니다.
  * 기존에는 웨이퍼 링의 곡선을 따라 존재하는 수십~수백 개의 최외곽 칩들을 수동으로 한 칸씩 마우스로 조준하여 칠해야 해서 맵 설계 효율이 매우 떨어졌습니다.
  * 이를 개선하기 위해 **수학적 공간 분류 알고리즘을 도입**하여, 유효 캔버스 영역 내의 **E1, E2 셀들을 즉시 자동 검출하여 선택 및 일괄 채우기/비우기**를 할 수 있는 지능형 맵 드로잉 액션을 설계/구현했습니다.
  * (덤으로, 메인 DB 그리드 상에서도 컬럼 셀 값이 'E1' 또는 'E2'인 데이터 행을 일괄 체크해 주는 편의 단추를 유지 탑재했습니다.)

---

## 2. 세부 구현 사항

### A. 웨이퍼 외곽 경계 거리 측정 알고리즘 설계
* `client2/src/map_editor.js` 내에 **`getEdgeClassification()`** 공간 분할 함수를 탑재했습니다.
  1. **유효 원 영역(Inside Wafer) 식별**: 반지름 $R$에 대한 칩 격자 $c, r$의 정규화 거리 공식 $u^2 + v^2 \le 1.0$를 만족하는 유효 원 내부 영역을 배열 맵(`isInside[r][c]`)으로 매핑합니다.
  2. **E1 (Edge 1 - 최외곽 1칸)**: `isInside[r][c]`가 참인 셀 중, **상하좌우 및 대각선을 포함한 8방향 이웃(8-Neighbors)** 중 단 하나라도 '원 외곽 영역(Outside Wafer)'이거나 '격자 바깥(Grid Boundary)'인 경우를 필터링해 냅니다.
  3. **E2 (Edge 2 - 차외곽 2칸)**: 유효 영역(`isInside`) 내부이고 E1이 아닌 셀 중, 8방향 이웃 중 **최소 하나 이상의 E1 셀과 인접**해 있는 내부 레이어를 차순위 링으로 추출합니다.

### B. 맵 에디터 일괄 액션 UI 통합
* **UI 구성 (`client2/map_editor.html`)**:
  * `✔️ Select E1` (최외곽 1칸 일괄 선택)
  * `✔️ Select E2` (차외곽 2칸 일괄 선택)
  * `⚡ Auto-Paint E1/E2` (E1/E2 자동 링 페인팅)
* **상태 제어 및 페인팅**:
  * `Select E1`/`Select E2` 클릭 시 수학적 링 영역에 해당하는 격자들이 가이드 하이라이트되며, `Fill Selected` 또는 `Clear Selected` 단추로 현재 브러쉬 값 일괄 기입 및 삭제가 연계됩니다.
  * `⚡ Auto-Paint E1/E2` 클릭 시, 범례 테이블에 `E1` (보라색, `#8b5cf6`) 및 `E2` (분홍색, `#ec4899`) 브러쉬 아이템을 스토리지와 UI에 자동 등록하고, **해당하는 모든 외곽 원형 셀에 E1, E2 값을 1초 만에 일괄 페인팅**하여 맵 드로잉 속도를 수십 배 단축시킵니다.
