# 조인 키의 «색인 좌석»이 체인으로 옮겨 갔고, 이름 바꾸기가 «한 커밋 먼저» 탔다

> **커밋:** `21abf176`(은퇴 2/5 · 판정 440 ④ · 모양 승인 442 ③) + `7ecc6a1f`(이름 바꾸기가 «먼저» 탄 커밋) — 구현자

## 무엇이 일어났나

조인 키가 «요구하는 유일 색인»의 일 — 이름을 짓고, DDL 을 인쇄하고, 키를 렌더하고, 카탈로그에
묻고, 세우고, 걷어내는 것 — 이 **지워질 패키지 밖**으로 나왔다.

```
server/chain/join_key_index.py   신설 280줄
   INDEX_PREFIX :32 · required_index_name :42 · column_is_text :63 ·
   index_key_expression :84 · required_index_ddl :117 ·
   normalize_index_expression :172 · unique_index_covering :223
server/virtual_join/unique_key.py -> server/chain/unique_key.py   484줄(함수 열일곱)
server/virtual_join/config.py :128  그 이름들을 «되-import»
```

**왜 좌석이 남을 수 없었나:** `chain.builtins.ensure_declared_unique_keys` 가 **통합** 조인의
`key.unique` 인덱스를 이 이름들로 세운다. 패키지를 이름째 지우면 **소유자가 «옮겨 간» 쪽 조인의
유일성**이 같이 사라진다 — 남은 `uq_vjoin_` 인덱스가 모든 삽입을 23505 로 거절하고 그룹이
영구 실패하는 S-248 이 새 길로 되돌아온다.

**왜 식까지 같이 왔나:** `index_key_expression` 은 인덱스의 사설 철자가 아니다. DDL ·
`join_onclause` · crud 의 키 비교가 **전부** 그것으로 키를 렌더하고, PostgreSQL 은 질의의 식이
인덱스의 식과 **맞을 때만** 그 인덱스를 쓴다. 두 철자는 예외를 안 낸다 — **순차 스캔을 계획하고
시험은 전부 초록**이다. 정의를 하나로 두는 것이 그 성질을 «조심»에서 «구조»로 바꾼다.

## 좌석이 «둘»이 아니라 «여덟 이름»이었다 — 그래서 첫 시도를 되물렀다

판정 440 ②는 좌석을 「이름 둘」로 적었는데, 열어 보니 `unique_key` 가 패키지로 **세 번** 되돌아가고
거기서 이름 **다섯**이 더 딸려 왔다. 정의 **열넷**이 옮겨졌다. 총괄이 같은 자리에서 그것을
「오늘 밤 여섯 번째 — 내가 «연» 이름을 «좌석»으로 말하기」로 적었다.

⚠️ 그 창은 하필 **PG 스위트를 돌리겠다고 알린 시각**이다.

## 📌 그래서 「한 커밋으로 되돌린다」가 이 단계에서 «거짓»이다

```
판정 440 의 안전선  「되돌리는 법 한 줄 … «한 커밋»으로 — 흩어지면 «그 사이»가 거짓이다」
실제               git revert 21abf176 하나면 config.py 의 정의는 돌아오는데
                   unique_key.py 는 chain/ 에 «그대로» 남는다(이름 바꾸기가 7ecc6a1f 에 있다)
                   -> 되돌린 config.py 가 다시 `from virtual_join import unique_key` 를 부른다
                   -> 위 깨진 상태가 «그대로» 재현된다
```
되돌리려면 **두 커밋**이고, 그중 하나는 제목이 `docs(orders):` 라 `git log -- docs/` 에도 안 뜬다.
커밋 메시지가 이것을 **스스로 적었다**(⚠️ 문단) — 적은 것은 옳지만, 적는 것이 되돌림 가능성을
되살리지는 않는다.

📌 **부류: 「관통 단위 전환은 통째로 착지」.** 이름 바꾸기와 그 이름을 부르는 자리 고치기가
다른 커밋에 있으면, 그 사이가 거짓이다.

## 그대로 두는 것

`INDEX_PREFIX` 의 «값»과 로거 이름은 안 바꾼다. 패키지가 사라지면 둘 다 «틀리게 읽히지만»,
운영자의 «기존 인덱스 이름»과 «기존 로그 검색»이 그 철자에 걸려 있다 — 바꾸는 것은 마이그레이션이고
별도 라운드다.
