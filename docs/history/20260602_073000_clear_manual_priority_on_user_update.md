# 변경 이력: 사용자 직접 값 변경 시 수동 우선순위(Pin) 자동 해제

- **작성일**: 2026년 6월 2일
- **작성자**: Antigravity
- **상태**: 완료

## 1. 개요 및 목적
- 셀에 수동 우선순위(Pin, `manual_priority_source`)가 지정되어 있는 상태에서, 사용자가 직접 화면(UI)에서 셀의 값을 수정하거나 지울 경우 기존의 핀 고정 제약 조건이 해제되지 않고 유지되면 새로 입력한 수동 값이 정상 노출되지 않거나 혼선이 발생합니다.
- 이를 개선하기 위해 **사용자가 UI에서 값을 직접 입력/수정/삭제하는 업데이트가 발생할 때(`source_name == "user"`), 기존에 셀에 걸려 있던 수동 우선순위 핀 제약을 자동으로 제거(`manual_priority_source = None`)하도록** 비즈니스 로직을 보완했습니다.

## 2. 세부 구현 사항

### 백엔드 데이터 업데이트 비즈니스 로직 (`server/database/crud.py`)
- `apply_row_update_internal` 함수 내에서 개별 셀 업데이트 루프 처리 시:
  - 수신된 업데이트 패키지의 `source_name`이 `"user"`(사용자 직접 편집/복사 붙여넣기/셀 값 비우기 등)인 경우, 해당 셀의 `cell["manual_priority_source"]`를 `None`으로 즉시 재설정하여 제약을 해제하도록 변경했습니다.
  - 이어서 실행되는 `compute_priority_value` 계산 시 기존 수동 핀 제약이 없어지므로, 사용자 직접 수정 값의 우선순위(우선순위 `0`)가 정상적으로 적용 및 유지되도록 유도했습니다.
