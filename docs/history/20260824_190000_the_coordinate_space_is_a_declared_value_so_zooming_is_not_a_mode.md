## 배경 — `if (zoomed)`를 부품 안에 넣지 않는 것이 목표였다

칩 확대를 「모드」로 만들면 부품 안에 갈래가 하나 생기고, 그 갈래는 다음 확대에서 둘이 된다.
그래서 **좌표계 자체를 선언된 값**으로 만들었다 — `3d730222`.

측정이 설계를 세 번 바꿨다:

```
연속 평면 20,000um   빈 격자 루프가 4억 번 -> 노드 힙이 터졌다  => lattice: false
다이당 발견 평균 2.06, 최대 13, 4개 이상인 다이 1,906         => 전부 같은 빨강으로 그리면 안 된다
첫 페인트가 resize 콜백에만 의존                            => 콜백이 안 뜨는 페이지에서 캔버스 300x150·픽셀 0
```

`149be0ea`이 첫 페인트에서 **호스트에게 자기 상자를 물어보게** 만들었다.

## 🔴 좌표계에 «기본값»을 두지 않는다 — 기본값이 「어느 격자인가」를 지운다

```js
// client2/src/rnd_board/map_panel.js  (6c6b7719)
this.space = options.space || null;
// reload():
if (!this.space) { this.status = 'unspaced'; this.render(); return Promise.resolve(); }
```

기본값이 있으면 **다이가 어느 격자 위에 있는지가 조용히 정해진다.** 선언이 없으면 그리지 않고
그렇다고 말한다.

## 좌표는 «세 상태»다 — 「여기 없다」와 「아직 없다」는 다른 문장이다

`e26bf2dc`이 점이 **자기 자리들을 스스로 말하게** 했고, 여기 자리가 없는 점은 **버려지지 않고
세어진다.** `7b09ed31`이 그것을 세 상태로 못 박았다.

`859d696b`이 좌표계가 **walk 의 노드**를 읽게 만들어 확대가 `lot_map`에 안 매달리게 했고,
`efb69c01`이 **「답이 어떻게 모델이 되나」와 「누가 그릴 수 있음을 판정하나」까지 선언**으로
올렸다(`model`/`serverVerdict`가 표의 행이 된다). `c08e1601`에서 칩 확대가 **선언 하나**로 서고,
**빈 마킹은 거절이 아니라 기다림**이 됐다.

## 마크가 «맵이 이미 쓰는 노드 id»를 나른다

`b2ef4bc7`. 트렌드의 마크가 자기 철자를 만들지 않고 원장이 이름 댄 것을 그대로 쓴다:

```python

"node_id": ledger_explorer.entity_id(subject_type, keys),
```

옛 `mark_key`는 **폴백으로 남았다.** `b1d81e0e`이 클라 쪽 2단계를 붙였다 — 트렌드 점이
원장이 이름 댄 노드를 마킹한다.

## 아키텍처 영향

- **좌표계가 선언**이다. 기본값이 없고, 확대는 모드가 아니라 다른 선언이다.
- 「답 → 모델」 변환과 「그릴 수 있나」 판정이 **부품 밖의 선언**이다.
- 마크가 **노드 id 를 나른다.** 트렌드에서 찍은 것이 맵이 읽는 것과 같은 문자열이다.
- 필터된 뷰가 **표로** 서고 버린 행 수가 남는다.
