# 어떤 하네스도 볼 수 없던 모듈 전역 이름 — 그리고 그것을 드러낸 것은 번들이었다

> **일자:** 2026-07-31 밤 | **관련 커밋:** `cd3e0f4`(네 라운드 병합) · `52a1703`(dist 재빌드)
> **담당:** **사용자가 손으로 찾았다** · client/server 구현 · 총괄
> **대상:** `client2/src/map_editor.js`(`validDieListCache`) · 가상 조인 SQL 표현식 · 소급 어드민 화면 · 오버레이 mm 공간

## 배경 — 네 라운드가 주제가 아니라 트리를 공유해서 함께 착지했다

- **가상 조인**: 해소된 값이 **SQL 표현식**이 되어 검색·필터가 푸시다운되고,
  CSV 추출이 그리드와 같은 값을 나른다(15,504행 대조, 불일치 0. 전체 내보내기에
  SELECT 3개, 5행에서 12,005행까지 평평).
  `/schema`가 `join_resolved_columns`를 알린다 — `announced_columns`는
  **무엇을 추가할 것인가**라는 더 좁은 질문에 답하며 `collide`를 뺀다.
  그 컬럼들에서 Blank/NotBlank는 사라졌다 — **해소된 값은 절대 비지 않기 때문**이고,
  헤더가 **작동하는 질의**를 대신 이름으로 댄다.
- **저장 정규화가 쓰기 깔때기로** 갔다. 그래서 SQL이 파이썬의 공백 처리를 흉내
  낼 필요가 없다. 실측: 깔때기가 있으면 코퍼스 입력 22개 중 **0개**가 갈리고,
  없으면 17개 중 **8개**가 갈린다. 라이브 스캔에서 백필 부채는 없었다.
- **소급 어드민**: 개수가 **측정에 쓰인 파라미터를 함께 나르므로** 낡은 측정이
  확인 창까지 갈 수 없다. 두 버튼이 **하나의 in-flight 플래그**에서 유도되므로
  **의도 하나에 아웃박스 행 하나**다.
- **오버레이**: 클라가 **새 변환 없이** 밀리미터 공간을 얻는다 — `getDieIndex`가
  이미 계산해 두고 버리던 **반올림 전 값**을 반환한다. 팬아웃 셀은 **대표값이 아니라
  목록**을 들고, **셀 안 나머지**를 나른다. 저장 좌표 **600개 중 0개 이동.**

## 이 커밋이 남긴 진짜 교훈은 지나가다 고친 결함이다

> **`validDieListCache`가 선언된 적이 없었다.**
> 개명이 그 캐시를 `mapKeyListCache`로 접으면서 **이 호출부를 놓쳤다.**
> 그래서 **성공한 모든 Push가 레전드 저장 직전에 예외를 던졌고**, 그것이
> **HEAD의 출하된 번들 안에 있었다.**
>
> **하네스는 소스 텍스트에서 함수를 잘라낸다. 모듈 전역 이름을 볼 수 없다.**

사용자가 손으로 찾았다.

## 그리고 그것을 확인시킨 것은 번들의 성질이었다

`52a1703`이 그 증거를 남긴다.

> HEAD의 번들은 `validDieListCache`를 **글자 그대로** 나르고 있었다 —
> **선언되지 않은 전역은 미니파이로 없앨 수 없고, 선언된 것은 없앨 수 있기 때문**이다.
> **그 1 → 0 서명이 결함을 찾은 방법**이다. 새 번들은 0을 보고한다.

## 그때 남아 있던 것

- 이 라운드 뒤 클라 하네스 체계에 **모듈 전역 이름을 보는 축이 없었다.**
  (그것을 채운 것은 2026-08-04의 `undeclared_identifier_harness.mjs`다.)
- 소스는 `cd3e0f4`에, 번들은 `52a1703`에 착지했다 — **두 커밋 사이의 HEAD에서는
  소스가 고쳐졌고 사용자가 받는 것은 고쳐지지 않았다.**
