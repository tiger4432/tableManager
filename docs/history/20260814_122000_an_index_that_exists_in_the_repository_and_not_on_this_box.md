닿을 수 있는 곳에는 어디에도 없는 유효한 인덱스. 당일 틀린 읽기의 값을 치른 후속도
항목이 든다: 생성 후 ANALYZE — 통계 없는 표 위의 유효한 인덱스는 도움이 안 된
인덱스와 정확히 같아 보인다.
