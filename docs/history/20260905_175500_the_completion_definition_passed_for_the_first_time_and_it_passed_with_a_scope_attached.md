## 아키텍처 영향

- `closed_lists()` 가 **인자를 하나 받는다.** 이 함수가 발행하는 목록 중 «이 배포의 선언»을
  성질로 갖는 것이 하나 생겼다는 뜻이고, 그것이 `implementations` 다.
- 작성 계획에 **`state="derived"` 가 실제로 쓰이는 자리**가 생겼다 —
  「닿을 수 없으면 선언도 닿지 않는다」의 표지가 이론이 아니라 필드 상태가 됐다.
- `implementations.py` 가 `preparer_output_columns()` 를 갖는다.
  `__dict__` 로 읽는다 — `getattr` 이면 **중간 기반 클래스의 답이 모든 하위 클래스에 빌려지고,
  컬럼 하나를 더한 하위 클래스가 «조용히 한 칸 모자란» 선언을 받는다.**
- 완성 판정의 «주체»가 총괄에서 **소유자로 옮겨갈 수 있는 문장**이 존재한다.
