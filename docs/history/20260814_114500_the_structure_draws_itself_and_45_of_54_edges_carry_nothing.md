## 화면 (`1574f03`) — 픽스처는 과수원이다

「구조가 너무 숨겨져 있어서 UI 어떻게 설계해야 할지 모르겠어」 →
`ledger.html?view=structure`. 기존 페이지의 셋째 질문, 헤더 앵커 둘로 전환 — 새
페이지·모달·모드 없음, 뷰가 곧 URL이다.

손그림 금지 규칙은 단언이 아니라 **채점**됐고 픽스처가 그 방법이다: `Orchard`·
`Sapling`·`planted_in`·`bore_fruit` — 생산 단어가 하나도 없어 하드코드 노드 목록을
든 화면은 **아무것도** 렌더하지 못한다. 별도로 하네스가 주석 제거 후 두 모듈을 실제
엔티티 타입·술어 16종으로 grep해 **0 히트**를 요구한다. 선언 골격은 각 술어 자기
시그니처의 곱집합, 무게는 `GROUP BY subject_type, predicate, object_kind` — 내일
등록되는 술어는 스스로 그려진다.

선언-전용 엣지는 일부러 작게 만들지 않았다: 2.4px 점선 — 가장 가는 실선보다
**무겁게** — 불투명도 1, 연속 블록 정렬. 선언되고 소비 안 되는 축이 이 화면의 존재
이유라 속삭임으로 렌더하면 요점을 이긴다. 그리고 측정된 0은 미보고로 찍히지 않는다:
0의 주장 가능 조건은 집계가 셀 «수 있었을» 때뿐(`state ∈ {ready, empty}` + `edges`
배열 존재), 0 카운트 축은 「원자 0 — 기간/등급 없음」. 레인이 자기 첫 드래프트에서
**공허 검사 둘**을 찾았다: 범례가 행과 같은 단어·같은 `data-status`를 써서 전 행을
숨긴 mutant에 트리 전역 단언이 초록으로 남았다 — 엣지 목록으로 스코프 축소.

그래프 라이브러리도 캔버스도 없다: `graph_viewer.js`의 force 레이아웃은 «인스턴스»
그래프용이고, 이것은 읽고 선택해야 하는 한국어를 든 어휘 십수 노드다 — GROUP BY의
문장 모양인 결정론적 3열 인라인 SVG, 술어 노드가 자기 엣지 라벨을 겸한다. 브라우저
실측: 노드 겹침 0, 상자 넘친 텍스트 0, 라벨 17px.

**존재하지 않는다** — config도 로더도 라우트도 없고 제안 문서의 마크다운 펜스 안
모양뿐. 레인이 `.json.sample` 전사를 거절했다(출하된 샘플은 제안을 착지로 읽게
한다) — 응답은 `state: "absent"` + 스펙 참조, 이음새는 라이브(파일을 넣으면 코드
변경 없이 렌더, 테스트로 증명). 그리고 `ledger_config.json`은 소스 하나를 선언하는데
원자의 98.9%가 선언 안 된 소스에서 온다 — 숨기지 않고 `undeclared_source:*`로 보고.

```
flowing         선언 AND 원자 있음
declared_only   선언, 세었고 0            <- 정직한 빈 축
undeclared      어휘가 선언 안 한 모양의 원자  <- 드리프트
unmeasured      아무것도 못 셈 (릴레이션 부재)
```

계급 브레이크다운은 SQL로 재철자하지 **않았다**: CASE 사다리를 써서 재보니 285 ms 대
152 ms — 느려서 버렸다. 센서스가 페이로드 플래그를 그룹 키로 올려 `claim_class`를
그룹당 한 번 부른다 — 한 철자, 드리프트 없음. 캐시 없음; 파티션 256 MB 초과 시 30일
창이 강제되며 스스로 말하되 **창은 카운트만 좁히고 선언된 구조는 절대 좁히지 않는다**.
비용은 나중에 발견되는 대신 명기됐다: 풀스캔, 84,747 원자에 182 ms(~2 µs/원자, 10M에
