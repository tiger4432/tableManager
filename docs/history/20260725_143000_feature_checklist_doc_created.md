# 기능 인벤토리 + QA 기능 점검 체크리스트 문서 신설

- **일시:** 2026-07-25 14:30
- **주체:** doc-keeper (총괄 위임)
- **영역:** 문서 전용 (코드 무변경)
- **산출물:** `docs/qa/FEATURE_CHECKLIST.md` (신규 폴더 `docs/qa/`)

## 배경

프로젝트가 Enrichment Queue v1·std parser·듀얼 테마 등 기능이 빠르게 누적되면서, "현재 시스템에 어떤 기능이 있고 각각을 어떻게 수동 검증하는가"를 한 곳에서 답하는 문서가 없었다. (구 `CLIENT_FEATURE_CHECKLIST`는 PySide6 시대 산물로 `_archive/`에 있음.) 총괄이 QA용 기능 인벤토리 + 체크리스트 신설을 위임.

## 변경 내용

### 신규: `docs/qa/FEATURE_CHECKLIST.md`

2부 구성 — §1 기능 인벤토리(서브시스템별, 기능당 한 줄 설명 + 진입 경로 + CODE_MAP 참조), §2 QA 수동 점검 체크리스트(기능별 정상 경로 1 + 대표 에지 1~2, 클릭 수준 절차, `- [ ]` 형식).

문서 헤더(유지 규율 포함):

```markdown
> **Status:** 🟢 Living | **Last-verified:** 2026-07-25 | **Owner:** Integrity/QA (유지: doc-keeper)
> **유지 규율:** 새 기능이 병합·커밋되면 총괄이 doc-keeper에 위임하는 **코드맵 갱신과 같은 사이클**로
> 이 문서에도 해당 기능 행(§1)과 점검 항목(§2)을 추가한다.
```

커버 범위(총 14개 점검 그룹): 데이터 그리드(조회/편집/레이어링/핀/소스삭제/행/클립보드/컬럼선택/페이징·필터/Tx모드), 이력(글로벌/셀/행/점프/영속), 파일 인제션(커스텀/std 폴백/err 격리/재시도/멱등), auto_update, 체인 인제션(SLO 100ms·순환 차단·실패 격리), enrichment queue(워크리스트/컨베이어/참조뷰/배지/레이어링 보존), 맵 에디터, admin 7탭, 그래프 동기화, 듀얼 테마, WS 실시간, 데스크톱 래퍼.

핵심가치 직결 항목은 🎯 마킹(릴리스 블로커) — 예:

```markdown
- [ ] 🎯 **SLO 100ms**: 원본 편집 커밋 → 파생 반영 WS 통지까지 워커 `[Latency]` 로그 기준 100ms 이내
- [ ] 🎯 **멱등성 — 재드롭 무중복**: 동일 파일을 `raws/`에 2회 드롭 → 행 수 불변(비즈니스 키 업서트)
- [ ] 🎯 **소스 삭제 → 차순위 폴백**: 최우선 소스(user) 삭제 → 표시값이 차순위 소스 값으로 재계산
```

문서/코드맵만으로 확신할 수 없는 클라이언트 UI 세부(소스 모달 트리거, 핀 UI 절차, 스마트 페이스트 임계, view-mode 옵션, 맵 에디터 버튼 라벨, 페이지별 테마 토글 유무 등)는 본문에 `<!-- TODO: client-pm 확인 -->` 주석으로 표시 — 총괄이 client-pm에 이관해 보강 예정(보고서에 목록화).
