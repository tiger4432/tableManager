## 배경

`admin.html` 이 `--bg` · `--text-primary` · `--text-secondary` 를 부른다.
브라우저가 싣는 파일 전부를 걸어 재 보니 **그 셋은 정의가 «0»** 이고,
`tokens.css` 에 대고 `git log -S` 를 돌리니 **«한 번도» 없었다** — 키보드에서 지어진 이름이다.

## 🔴 왜 이것이 조용히 앉아 있었나 — 미정의 커스텀 속성은 «속성마다 다르게» 실패한다

```
`fill` 의 무효   -> 상속이 «아니라» 초기값 = 검정
                   -> 체인 그래프 노드 원이 «검게» 칠해지고 그 위의 라벨(`--text`)이 안 읽혔다
`color` 의 무효  -> «상속»
                   -> 값도 라벨도 muted 도 «전부 한 색»이 됐고 `[data-tone="muted"]` 이 «무효»였다
                   -> 「측정 안 함」이 「측정된 수」와 «정확히 같은 픽셀»로 그려졌다
```
후자가 이 저장소가 여러 번 적은 **「같아 보이는 다섯 개의 0」** 부류이고, 이 라운드가 존재하는 이유다.

## 무엇을 바꿨나

### 🔴 셋을 «정의하지 않았다» — 그리고 그 이탈을 «적고» 벗어났다

지시는 「토큰 셋을 정의하라」였고, 정의하면 지시의 «목표»(구별되는 픽셀)에는 닿는다.
그러나 캐논에 `--bg-surface` · `--text` · `--text-dim` 이 **그 세 역할로 이미 있다.**
정의하면 한 역할에 «두 번째 이름»이 남는다 — 토큰 층의 «문 가르기»이고,
디자인 시스템의 자기 규칙이 「역할 토큰이 유일한 색 어휘」다. 그래서 «참조 다섯»을 캐논으로 옮겼다.

```css
-    .cg-node circle { fill: var(--bg); … }
+    .cg-node circle { fill: var(--bg-surface); … }
```
```css
-      color: var(--text-secondary);          +      color: var(--text-dim);
-      color: var(--text-primary);            +      color: var(--text);
-      color: var(--text-primary);            +      color: var(--text);
-      [data-tone="muted"] … var(--text-secondary);  +  … var(--text-dim);
```
**새 어휘 0, 결과 동일.** 총괄이 그 이탈을 승인하며 자기 지시를 무름 —
「오늘 밤 제가 «한 판단에 철자 둘»을 여섯 번 판정해 놓고, 제 지시가 그걸 만들 뻔했습니다.
 그리고 당신은 «적고» 벗어났습니다 — 조용히 벗어났으면 제가 못 봤습니다」.

### 게이트가 «그 셋»이 아니라 «부류»를 잰다

브라우저가 싣는 것(최상위 페이지 + `src/`)을 걸어서
**「폴백 없는 `var(--x)` 가 아무도 선언하지 않은 이름을 부르는 일이 하나도 없다」**를 단언한다.
폴백은 «선언된 의도»라 일부러 세지 않는다. 대조 변이가, 게이트가 정상 코드를 빨갛게 만들지 않음을 보인다.

⚠️ **주석은 벗기고 훑는다.** 안 그러면 빨강을 푸는 제일 싼 길이 **「옛 이름을 설명하는 문장을 지우는 것」**이
된다 — 이 저장소가 한 번 걸린 함정이고, 두 번째 대조가 그것을 덮는다.

수리 뒤 실측: **참조 105 · 정의 135 · 미정의 0.** 참조 «수»도 같이 단언한다 —
빈 모집단 위의 성질은 참이고 아무 말도 안 한다.

수 말고 **보고된 증상 둘에 대한 이름 붙은 단언 셋**:
원의 `fill` 이 정의된 토큰을 부른다 · 값과 muted 가 «다른» 토큰을 부른다 ·
그 둘이 **모든 테마 블록**에서 다르다(어두운 쪽만 같게 만드는 변이가 잡힌다) —
한 테마에만 있는 차이는 다른 테마를 쓰는 사람에게 «보이지 않기» 때문이다.

## ⚠️ 첫 판이 «자기 자신»을 빨갛게 만들었다

하니스가 `client2/` 밑에 살아서 **자기 변이 앵커**(자기 결함 목록 안의 `var(--bg)`)를 세었고,
어떤 배포 파일에도 없는 미정의 토큰 «둘»을 보고했다. 모집단을 «브라우저가 싣는 것»으로 바꿨다.

🔴 레인의 문장: **「자기가 진단하는 모집단 «안»에 있는 진단기는, 자기가 진단하는 것을 «죽이는»
진단기와 같은 부류다」.** 총괄이 이것을 CLAUDE.md 계측 상설의 «다른 얼굴»로 받았다 —
사흘 장애가 그 절을 만들었는데 한 겹이 더 나왔다.
