## 🔴 배경 — 인과 체인이 «한 홉»에서 멈췄고, 예산 플래그는 전부 false 였다

`_expand_atom`이 주어에 `depth`, 목적어에 `depth + 1`을 **조건 없이** 줬다. 그건 원자가
**나가는 팔**로 도착했을 때만 맞다. `claims_for_entities`에는 팔이 둘이고, **들어오는 팔에서는
프런티어 엔터티가 «목적어»**다 — 그러면 먼 쪽은 «주어»이고 **이미 걸은 층에 내려앉는다.**
다음 프런티어에 합류하지 못하고 walk 이 멈추는데, **예산 플래그는 전부 false** 다 —
**빈 그래프와 구별되지 않는 침묵.**

`frontier_entities`는 **이미 함수에 넘어와 있었고 본문에서 한 번도 안 읽혔다.** 두 팔을
가르는 것이 바로 그것이므로, 이제 그것이 **어느 쪽이 나아갈지** 고른다. 다른 건 아무것도
안 옮겼다 — SQL 두 팔, `add_node`/`add_edge`, 예산 플래그, `follow`, value 목적어 갈래 전부 그대로.

```
씨앗 defect_kind{void} · follow=leads_to · hops=6
전   노드  8 · 엣지  7 · hops_reached 0 · depths {0: 8}         bond_pressure 없음
후   노드 21 · 엣지 21 · hops_reached 3 · depths {0:1,1:7,2:9,3:4}
     bond_pressure 가 깊이 2, interface_unfill 을 지나서

회귀 SYN-CX-BW-001 hops=6 both node_limit=1000 edge_limit=3000
     노드 1000 · 엣지 1612 · hops_reached 3 · 절단 플래그 · 타입 분포 · 술어 분포 «전부 동일»
     움직인 것은 깊이 히스토그램 하나 —
       {0:1,1:128,2:870,3:1}  ->  {0:1,1:128,2:377,3:494}
     들어오는 팔에서 찾은 다이 493이 «자기 진짜 거리»를 갖는다
```

## 순위가 「노드 전부」 위에서 돌아왔다 — 소유자 판정

`d0691587`. 모집단은 **walk 이 닿은 노드 전부에서 씨앗을 뺀 것**이고 타입 필터가 없다 —
소유자 원문 「노드 전부지 rcp 같은거 차이도 있잖아」. 마킹된 집합이 어느 레시피를 지났나 같은
**범주적 차이가 물리량과 같은 자격의 후보**가 된다.

`_rank_layers`는 **다시 쓴 게 아니라 복원**됐다. 그것은 「한 종류만 내는 walk 은 순위 매길
것이 없다」는 전제 위에서 아침에 나갔고, **판정이 그 전제를 만료시켰다.** 그리고 **동률을
동률로 두는 우세 층화가 «측정된» 규칙**이므로, 여기서 순서를 지어내면 **지어낸 것이 답을
정하게 된다.**

**reach 둘이 접히지 않고 나간다.** 이건 그날 아침의 「어떤 수도 안 나간다」를 뒤집는데,
추론이 틀려서가 아니라 **reach 둘을 한 점수로 접는 «판정된 방법»이 없기 때문**이다 —
수 하나는 **기계가 얻지 않은 평결**이 된다. docstring 이 반대를 말하던 자리에서 그렇게 말한다.

🔴 **지시서의 증명 씨앗이 아무것도 증명하지 않는다는 것을 원장이 말했다** —
`WF-LOT-A-05`는 `measures` 원자가 **0**이라 모든 방향에서 0을 답한다. 원자 16개가 있고
그중 그 술어가 없을 뿐이다. `SYN-BW-101-02`는 40이라 증명이 그리로 옮겼다.
**그 0은 이제 「이 웨이퍼에 기록된 측정이 없다」는 문장이지 못 보는 계측기가 아니다.**

그리고 그 커밋이 **거의 틀릴 뻔한 것 둘**을 적었다: 번들 grep 이 0을 냈는데 **minifier 가
템플릿 리터럴을 백틱으로 쓰기 때문**이었고 하마터면 「빌드가 변경을 안 실었다」고 보고할 뻔했다.
그리고 vite 가 dist html 셋을 다시 썼는데 캐리지 리턴을 무시하면 `map_editor.html`은 실변경이
없고 `map_editor2.html`은 **다른 레인의 미착지 소스** 두 줄이었다. 셋 다 복원하고 **바이트
수준에서 스크립트 참조 하나만 바꿨다** — 1,754줄의 줄바꿈 소음과 남의 작업을 안 내보내려고.

## 아키텍처 영향

- BFS 가 **어느 팔로 도착했는지에 따라 나아갈 쪽을 고른다.** 들어오는 팔의 노드가 자기 진짜
  거리를 갖는다.
- **ranked 가 닿은 노드 전부**를 모집단으로 한다. 후보가 **선언된 엔터티 타입**을 나른다
  (`node_kind`가 아니라 — 지금은 모든 노드가 같은 값이다).
- **reach 둘이 접히지 않고 나간다.** 접는 «판정된 방법»이 없기 때문.
