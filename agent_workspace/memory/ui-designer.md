# 교훈 파일 — ui-designer

> **운영 규칙:** 신규 교훈은 에이전트가 보고서에 **제안** → 총괄 검수 후 이 파일에 반영. (직접 추가 금지)
> 작업 착수 시 이 파일 전체를 로드할 것 (Pre-Flight 항목).

## 공통 (전 에이전트)

- **함정**: 시스템 python으로 실행하면 psycopg2 부재 등으로 거짓 실패한다.
  **올바른 방법**: 모든 Python 실행은 conda `assy_manager` 필수 — `conda run -n assy_manager python <파일>`.
- **함정**: Windows 콘솔은 cp949라 한글/유니코드 출력에서 인코딩 에러가 난다.
  **올바른 방법**: `PYTHONIOENCODING=utf-8`을 앞에 붙여 실행.
- **함정**: `conda run`은 멀티라인 `python -c` 인라인 코드를 처리하지 못한다.
  **올바른 방법**: 코드를 스크립트 파일로 저장 후 파일 실행.
- **함정**: `/tmp`는 Windows python에서 보이지 않는다.
  **올바른 방법**: 세션 스크래치패드 디렉터리를 사용.

## ui-designer 전용

- **함정**: 미리보기 pane은 비-compositing 환경이라 rAF/transition이 프리즈된다(이슈 #3) — 애니메이션이 "안 도는 것처럼" 보여도 코드 결함이 아닐 수 있다.
  **올바른 방법**: 미리보기 pane에서는 정적 렌더 확인까지만, 애니메이션 검증은 실브라우저에서.
- **함정**: layout/paint를 유발하는 속성(width, top, box-shadow 등) 애니메이션은 대형 그리드에서 프레임을 무너뜨린다.
  **올바른 방법**: 애니메이션은 `transform`/`opacity`만 사용.
- **함정**: flex/grid item은 `position: static`이어도 z-index가 적용되어 스태킹 컨텍스트를 만든다 — 낮은 z의 부모 컨텍스트에 갇힌 자손은 z:1000이어도 바깥 요소에 진다(`.app-header` z:10 vs `.split-resizer` z:100 드롭다운 관통 사례, 2026-07-25).
  **올바른 방법**: 오버레이를 띄우는 컨테이너(헤더 등)의 z를 본문 최고 z보다 높게. 프로젝트 z 스케일: 2 < 5~50 < 100(resizer) < 200(헤더) < 1000(팝업) < 2000+(모달) < 9998+(토스트).
