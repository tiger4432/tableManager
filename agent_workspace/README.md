# 에이전트 우편함

이 디렉터리는 **자리**입니다. 산출물은 여기 쌓이지 않습니다.

```
할당   agent_workspace/tasks/     (gitignore — 추적하지 않습니다)
보고   agent_workspace/reports/   (에이전트가 쓰는 자리. 비어 있는 것이 정상입니다)
지난 것 docs/_archive/agent_workspace_20260823/   ← 2026-08-23 까지의 209
```

🔴 **왜 비어 있나:** 2026-08-23 에 이 방식이 멈췄고, 그때까지의 209(리포트 179 · 메모리 10 ·
아카이브 7 · 프롬프트 4 · ui_preview 3 · 목업 3)은 위 아카이브로 «옮겼습니다» — 지운 것이
아닙니다(S-210, 판정 353). 이 저장소의 오래된 문장·주석 196곳이 아직 `agent_workspace/reports/…`
경로로 그 문서들을 인용합니다. **그 인용의 행선지가 위 한 줄입니다.**

⚠️ 디렉터리 계약(`.agents/skills/*` · `.claude/agents/*` 아홉이 적는 우편함 경로)은 **그대로**입니다.
그 프로토콜을 은퇴시키는 것은 청소가 아니라 운영 방식 변경이고, 이 라운드의 것이 아닙니다.
