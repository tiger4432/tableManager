🚫 맵 키가 로드한 맵과 다릅니다 — Push 차단 로드한 맵: BASE-77 / 현재 입력: BASE-78 이대로 Push하면 BASE-78의 기존 셀이 전량 삭제되고 지금 격자 내용으로 대체됩니다.

키 입력은 기본 잠금(readOnly)이라 이 상태에 들어가는 경로 자체가 좁습니다. 그래도 잠금 해제 후 변경했다면, 이 배너 + Push 비활성 + 툴바 칩 적색화 3중으로 막습니다.

변경 요지 한 줄 — 「전사 계획」이라는 개체를 없앴습니다. stage 선택·타깃 입력·plan_id·모드 A/B·페인팅 진입/이탈 버튼이 전부 사라지고, 남는 것은 ⓐ 무슨 맵을 열었나(좌) ⓑ 그 맵의 값들이 무슨 뜻인가 = legend = DOE(우) 두 가지뿐입니다.
